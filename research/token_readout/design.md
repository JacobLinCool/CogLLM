# 逐 token 閱讀讀出的首輪評估

同一篇只給正文和可選背景，執行一次因果 Qwen3.5-2B 前向。逐 token 保留可讀的表徵及對已讀位置的注意力，輸出局部疑問、所指上文及候選疑問的未解量。在固定的正文條件下比較凍結骨幹與第 24 層 Q/K LoRA，主要觀測是已配對的真人首次矛盾回報及指定問題的文字證據。每種觀測使用自己的計分單位。此輪產品驗收是從同一封存權重取得原文曲線、模型提出的候選片語，及可回到字元位置的發生與解除區間。 [逐 token 數學規格](../mathematical-formulation.md#每個-query-對已讀位置的關係) · [現有讀出診斷](../union_training/localization-results.md)

## 資料與來源隔離

- **Frick 首次明示矛盾。** 使用原實驗 20 組故事的兩種純文字版本、共 1,800 次真人試次。訓練 16 組、1,416 次。評估沿用模型選擇階段的第 8、10、11、14 組、384 次試次。每對在更早一個句子改前文，目標句逐字相同。首句依實驗指示按 K，從第二句起記第一次 D，到篇末仍未回報者按右設限。完整句是實際呈現與回報單位。這些四個家族已用於先前開發結果，新增評分是同材料再驗證。 [原始流程、呈現與對位](../semantic_tracking/frick-consistency-source.md) · [先前回溯門檻](../semantic_tracking/frick-conditional-protocol.md#評分)
- **ExpMRC 已知題目的文字證據。** 沿用 27 篇既有測試文章，與此前 66 篇訓練來源文章交叉比對時找到兩篇田野材料拷貝，與兩篇測試文章各共用 202、364 個不同的連續十二詞窗。移除這兩篇訓練來源後保留 64 篇訓練文章。每篇提供兩個已顯示的問題及不重疊的手標證據窗口。問題是這個任務的可見輸入，正解和支持位置留在獨立評分檔。觀測是讀完整篇的標註者認定哪段提供支持，不含讀者當下首次有把握的時間。這批資料的既有結果限於有指定問題的輔助任務。 [既有資料、授權及結果](../semantic_tracking/same-question-results.md#同一疑問的留出診斷)
- **新封存的三種續文。** 自編 12 組說明段落，對同一已讀錨點保留提前給線索、延後給線索及未給線索三版，共 36 篇。三版在答案可能出現前有相同的原文與 token，晚解與未解共享中間段。晚解與早解使用相同的解答句，三版本總 token 數相同。保留完整答案句及最後一個答案詞末的座標。素材由代理程式設計，評分在首次前向前固定，沒有真人讀後回報。 [資料建置與封存](data.py)

資料建置使用固定 tokenizer SHA-256。`stimuli.jsonl` 每列只含 `id` 和 `text`。`design.json` 留在研究端，包含既有來源雜湊、斷點、分割、作答計數和設計控制窗。所有文字位置為原文的 Unicode 半開區間，任何用來定義可見前綴的端點都用獨立編碼確認。`receipt.json` 封存兩份輸出的雜湊及十二詞窗隔離檢查。ExpMRC 採來源 CC BY-SA 4.0。Frick 採既有的公開補充材料，原始來源及歷史稽核已記錄在研究檔。 [來源核對](../semantic_tracking/frick-consistency-source.md)

## 模型與評分契約

**首次回報。** 讀出使用整句範圍內的所有因果 token，聚合為句末首次回報的 logit，並把原試次中依序看見各句的事件與篇末設限建成機率分布。句序基線在每一個呈現句序彙整訓練試次。令 $d_s$ 是該句首次回報數、$r_s$ 是進入該句仍未回報數，基線在該句的 hazard 為 $(d_s+0.5)/(r_s+1)$，在新試次上依次乘存續機率。從呈現第二句起算，基線不讀文字、條件、目標句或測試資料。模型和基線用相同留出故事及全數試次計算整篇位置負對數概似。另以兩組條件分開報告目標句前回報偏差、目標句首次回報差及尚未回報者的目標句條件差。開發判準沿用既有的目標對比及提前回報誤差 ±10 個百分點，並報告四家族的分項差距與相對句序基線的分數。四組開發材料只能判斷本輪工程改進，另需獨立家族支持推廣。 [Frick 原評分規格](../semantic_tracking/frick-conditional-protocol.md#評分)

**文字證據。** 首次落入各題的人標支持窗，以存續至窗起點乘窗內事件質量計算區間概似。保留同一正文與同一時間窗下較早有證據的原題，以及支持段尚未出現的另一題作配對。另對可得的前置等 token 長度區間報告相同問題的排序。缺少等寬前窗時保持缺失。以文章等權報告配對方向、觀測區間 NLL 和相同 token 步數的訓練集基準。這個端點支持「哪題先具備已標記的文字證據」。 [資料與等寬對照](../semantic_tracking/same-question-results.md#自然材料與真人對照)

**設計三聯版。** 選取三版共同前綴的同一錨點，並排查看其解除曲線。在同一模型與錨點下，由 `anchor_unresolved` 除以開啟機率得到條件未解機率，解除機率為其補數。在相同 tokenizer 位置，早解比未解的差應先在早線索窗上升，晚解比未解的差應留到晚線索窗才上升。報告每組首次分離、兩個線索末的符號與幅度，使用既有分析的 5 個百分點作首次分離門檻。共有前綴的機率差要落在數值檢查容差。目標是本次控制窗內的定位，估計曲線所指為同一錨點。無條件的整篇未解曲線保留供介面呈現和模型診斷。 [首次分離的先例](../semantic_tracking/same-question-results.md)

**同一權重進入介面。** 逐 token 分數、可見錨點、Unicode 位置及模型使用的時間窗都連到輸入原文。前向及切換的呼叫次數分開驗證。同一模型在共同前綴的截短、替換後文及右側 padding 測試通過後才進入最終評分。封存預測、訓練配置和資料收據，再接回本機評分標註。各測試不足的維度保留為待驗證訊號。 [既有 Gradio 前向測法](../gradio_app/README.md)
