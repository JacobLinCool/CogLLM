# 跨骨幹逐 token 讀出比較

本輪比較凍結的 Qwen3.5-2B、LFM3-1.7B-Base 與 Gemma 4 E2B。所有正式輸出都從單次因果前向取得。各骨幹提供中層、末層及在原生全域注意力層擷取的關係摘要。因果讀出可單獨使用隱狀態，其關係輸入必須明確指定。每個骨幹獨立擬合讀出。 [固定快照](../backbone_transfer/models.json) · [前次單次前向結果](../backbone_transfer/results.md)

比較同一批文字、原文字元窗口及可見前綴。各模型保留原生分詞。位置基線從各自訓練分詞計算曝光量，但不使用模型表徵。Frick 以句級首次矛盾回報作生存概似，ExpMRC 以已知問題的人工支持區間作區間概似。兩者各有配對項，分別對應同句不同上文與同一窗口支持哪一題。這兩份材料的區間依各自觀測方式定義。 [原始觀測與初次試驗](design.md)

同一骨幹擬合兩種讀出。單 token 錨點以雙線性配對為主，跨度版以錨點止於當前已讀前文的局部表徵和非線性配對訊號匹配後續線索。兩組用相同更新次序、損失和資源上限。在之前的訓練組內按故事／來源文章家族留出開發集，等權最小化兩個開發端點的概似來選擇權重，並用開發集為跨度版估計輸出縮放與解除偏置。校準保持因果性及同一前綴的相等性。正式測試標註留在本機，預測先封存。

除真人 Frick 和人工 ExpMRC 外，評估先前 12 組「早解／晚解／未解」的自編說明文，以及新增的同一前文留下兩個疑問的診斷材料。以相同原文區間計算首次分離，另檢查一條線索對兩個候選的區別。這些診斷沒有新增真人觀測。模型發布候選依開發端點決定。正式評分用於報告泛化，保留各端點實際表現與原始收據。
