# LFM3-1.7B-Base 的權重與文字前向

固定作者的 7bca5038823c0d0f14efe06439109354a10e014c 版。權重、原設定、tokenizer 和三個本機 Python 模組均核對 SHA-256。模型骨幹有 24 層、隱狀態寬度為 2,048。當中 13 層使用因果短卷積，5 層採滑窗注意力，6 層採全域注意力。讀出使用最後正規化後的隱狀態，關閉自回歸解碼與 KV 快取。 [作者模型與固定版本](https://huggingface.co/LiquidAI/LFM3-1.7B-Base/tree/7bca5038823c0d0f14efe06439109354a10e014c) · [檔案雜湊](models.json)

作者發布的設定標示 Transformers 5.12.1，但同版模型程式需要該套件在 5.12.1 尚未提供的 kernel 裝飾器。5.17.0 提供該符號。其通用設定驗證會把作者的 `conv` 改名為 `linear_attention`，也會在每種注意力已有完整 RoPE 參數時加入平面預設值。本研究在載入已核對的本機設定類別時，限定 RoPE 正規化只處理原有兩種注意力，移除套件自動插入的平面預設值，並由作者的架構驗證器檢查逐層名稱。載入模型前後，完整的 24 層順序及兩份原始注意力參數須逐值一致。作者的程式檔和 tensor 權重維持原始位元組。 [擷取及相容性檢查](extract.py)

所有候選的封存狀態以 FP32 做正文前向；每一篇只留一次前向的結果。LFM3 的卷積寬度為 7。作者程式可在支援時使用本機 Triton 的寬度 7 因果卷積，否則使用 PyTorch 深度卷積加左側可見範圍。執行程序離線運作並關閉 Hub kernel 載入。 [作者卷積實作](https://huggingface.co/LiquidAI/LFM3-1.7B-Base/blob/7bca5038823c0d0f14efe06439109354a10e014c/modeling_lfm3.py) · [權重與執行環境核對](extract.py)
