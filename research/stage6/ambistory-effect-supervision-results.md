# AmbiStory 結尾差幅監督的留出結果

沿用凍結 Qwen3.5-2B 特徵，在原訓練集做五折同形詞分組選模。符合門檻的權重係數為 1 與 4，依預定的折外更新 MAE 選定 4。較高的 16 與 64 雖降低折外更新 MAE，但逐票 NLL 分別增加 0.034 與 0.470 nats，超出 0.01 nats 門檻。Colab L4 執行個體上的 CPU 擬合階段耗時 52.8 秒。兩套權重與預測封存後才評分，已確認執行個體釋放。 [事先封存的規格](ambistory-effect-supervision.md) · [訓練折診斷](../results/ambistory-effect-l4/train-diagnostics.json) · [執行與釋放收據](../results/ambistory-effect-l4/run-verification.json)

專案留出取作者 validation 的 98 個故事家族、54 個同形詞群、2,952 票與 196 組同義項結尾對照。兩種結尾讀出共用同一份因果特徵，差別為是否在原訓練分布損失加入真人結尾差幅。 [封存評分](../results/ambistory-effect-l4/scores.json)

| 讀出 | 每票 NLL（nats） | 帶符號更新 MAE（分） | 平均絕對更新（分） |
| --- | ---: | ---: | ---: |
| 無差幅監督，結尾 | 1.59278 | 1.24198 | 0.118 |
| 差幅監督，共同前綴 | 1.59174 | 1.26088 | 0.000 |
| 差幅監督，結尾 | 1.58802 | 1.22015 | 0.164 |
| 真人評分 |  |  | 1.261 |

差幅監督相對同特徵的原結尾讀出，更新 MAE 差為 −0.02183 分，95% 區間 [−0.03275, −0.01071]。逐票 NLL 差為 −0.00476 nats，95% 區間 [−0.01152, +0.00163]，通過 +0.01 nats 的非劣門檻。候選結尾與自身共同前綴的 NLL 差區間仍跨零。候選的絕對更新幅度比真人少 1.097 分，90% 區間 [−1.234, −0.952]，超出 ±0.5 分等效界。五項固定條件通過三項，整體驗收未通過。

這個實驗支持直接監督差幅能降低兩種指定結尾間的更新誤差。平均幅度仍顯著偏小，現有權重適合作為下一輪讀出比較的基線。原 test 與 validation 的真人結果均已評過。若依結果調整模型，新的確證性測試需要另一份獨立留出。 [模型與真人對照](../results/ambistory-effect-l4/scores.json)
