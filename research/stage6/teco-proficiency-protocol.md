# TECO 英語閱讀能力與篇章難度對照

**研究假說。** 在未見讀者與未見文章上，加入讀前英語閱讀能力能改善 1–9 級篇章難度分布的預測。另檢驗這項背景何時改變文章的難度排序。此研究方案以 41 位日語母語英語學習者、30 篇 EIKEN 說明文與 1,208 筆即時讀後評分為範圍。閱讀能力使用獨立 19 題測驗的分數。 [原始研究](https://link.springer.com/article/10.1007/s11145-026-10888-0) · [來源及跨版本核對](../nahatame-teco-data-audit.md)

## 模型可見資料與留出

推論只讀經核對的文章正文及選填的 0–19 閱讀能力分數。每篇用固定 Qwen3.5-2B 做一次因果前向，以最後一個正文停點的 FP32 狀態作篇章表徵。句末和逐詞輸出仍沿用各自的既有量尺。真人是在逐段顯示和穿插是非題之後給分，因此這裡估計該實驗下的篇章評分，泛化到一次呈現整篇的閱讀情境待驗證。 [實驗曝光方式](https://tsukuba.repo.nii.ac.jp/record/2011041/files/RMAL_3-2-100123.pdf#page=5)

所有可用讀者與文章各自依固定雜湊分成五折。文章在每個 EIKEN 級別內等分。每個交叉格只以讀者折及文章折都不同的試次擬合。人在同一文章上的評分須留在同一文章折，文章與讀者識別碼僅供切分及評分。實際呈現順序、模型前的試題、受試者識別和任何作答表現不輸入讀出。並核對每個交叉格在兩個維度的 ID 皆無重合。

## 讀出、驗收和量尺

固定四個讀出，使用各訓練格的資料估計尺度、權重和閱讀能力分布。每個候選用相同九級機率輸出和帶 L2 的負對數似然，截距不懲罰。

| 讀出 | 輸入 |
| --- | --- |
| 文字基線 | 文章詞數、字元數及可重現的英文可讀性特徵 |
| 凍結文字狀態 | 相同文字特徵及因果篇末狀態 |
| 讀前能力 | 相同狀態及讀前能力主效應 |
| 能力與文字交互 | 相同主效應及讀前能力乘因果狀態 |

主要比較為讀前能力讀出相對凍結文字狀態的逐次 NLL 差。由讀者和文章成組重抽樣後，95% 區間上界須小於零。交互作用以相同方法比較能力主效應模型，獨立報告。空白背景以訓練格能力分布對已訓練的條件機率求邊際平均，並以相同留出逐次 NLL 與只看文字的模型比較。

另在每篇的已觀測試次，將讀前分數不高於訓練格下四分位和不低於上四分位的兩群作比較。以實際出現的各群試次為預測和觀測共用的評分分母。報告各篇低分群減高分群的平均難度差、成組區間、估計與實測差值。對兩群均有留出資料的篇章，以半個評分類別做預先固定的 ±0.5 分等效界，以 90% 成組區間檢驗整體幅度誤差。這個比較只衡量已觀測群體的關聯。文章主題知識、公眾讀者及詞級疑問均需各自的資料驗證。

此文件固定實驗問題與統計判準。仍須封存確切切分、執行程式、可讀性特徵版本和輸入雜湊，才進入模型擷取及擬合。
