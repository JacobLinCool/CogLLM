# OneStop 重讀條件的因果讀出

使用 OneStop 普通閱讀組。讀者在同一工作階段兩次閱讀相同版本的文章，首次作答後看過正誤回饋，重讀後回答另一道題。分析保留可由釋出紀錄核對正文、版本、順序及既有作答的配對。重讀狀態描述這項實驗經驗。是否熟悉其他主題、讀者背景知識的內容及首次察覺疑問的位置，需要各自的觀測。 [試次核對及重讀先驗](onestop-rereading-audit.md) · [原研究 Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC12727756/#Sec11)

以前兩批文章和讀者擬合，第三批的第 21–30 篇和 60 位讀者保留給評分。前一輪資料核對已重算群體差幅。本輪在任何模型預測產生前固定比較、模型輸入、資料分割和評分。完整正文依讀者實際看到的篇章順序串起來。每個不同字串做一次 NVIDIA L4 FP32 因果前向，使用 Gradio 候選的 Qwen3.5-2B 固定權重、原 tokenizer 和同一 CUDA 編碼器。標註停點保留在正文的段末。擷取時把每個已知原文段界的兩個換行一併視為可見，篇末也加同樣兩個換行。每個停點須與獨立編碼的可見前綴完全一致，且該位置的 token 未跨入下一段文字。另以截短前綴及更換後文重算少量控制，容許相對向量差的上限為 0.0002。主前向輸入只含正文和版面分隔符，無題目、選項、背景問卷、作答或讀者鍵。

讀出使用段末 2,048 維最後層狀態，向量除以其 L2 範數。以 0 或 1 表示初讀或重讀，分別產生兩種條件的機率。預設正文的參考條件為初讀。主比較預先固定五個讀出。

| 讀出 | 擬合資訊 |
| --- | --- |
| 共用先驗 | 開發集兩輪共用的答對比例 |
| 重讀先驗 | 開發集初讀、重讀各自的答對比例 |
| 正文 | 段末狀態 |
| 正文與重讀加成 | 段末狀態、重讀狀態 |
| 正文與重讀交互 | 段末狀態、重讀狀態、兩者乘積 |

兩種先驗使用 $(x+0.5)/(n+1)$，其中 $x$ 為答對次數、$n$ 為作答次數。三種正文讀出使用逐次 Bernoulli NLL 的總和，加 $\frac{1}{2}\lVert w\rVert_2^2$，截距不懲罰。正文的維度和懲罰係數不依留出結果調整。分開封存開發擬合的權重和兩種狀態的預測，再接上留出作答。

主要評分量是 Brier 損失，範圍 0–1、0 為最佳。將機率與實際 0 或 1 的平方差依可比較的段落版本×題號分組。只取兩輪都觀測到的組別，在組別內等權平均兩輪，篇章內等權平均組別，最後讓文章等權。次要報告具有同樣組別權重的逐次 NLL 和真人正確率的重讀差。用 10,000 次文章配對重抽樣，亂數種子 20261121，固定讀者及已封存的預測。

若要判定正文與重讀交互讀出通過驗收，它的 Brier 相對正文與重讀加成、重讀先驗、正文三者的差，各自 95% 區間上界須低於零。它的重讀平均預測差須與真人差同方向，且預測減真人重讀差的 90% 文章重抽樣區間須完全落在 ±3 個百分點。這個容許差反映這批資料上值得辨別的重讀幅度，既有結果提示實驗精度可能不足。結果按端點報告，並保留正文與重讀加成的結果。
