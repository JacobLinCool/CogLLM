# CogLLM 三項核心功能的首輪真人資料實驗

在既有真人資料中，Qwen3.5-2B 改善了候選詞彙區段的排序，以及讀者從哪個區段開始回讀的估計。回讀到哪裡與距離基線相近。提供標註者的母語背景後，每票圈選預測略有改善，兩組在各區段的實際差距仍難估。 [執行計畫](execution-plan.md) · [目標推論介面](training-protocol.md#模型輸入閱讀反應與分析)

## 資料與留出設計

**CWI 2018 WikiNews。** 原任務讓英語母語及非母語標註者在一批句子中圈出可能讓指定讀者群覺得困難的詞或片語。每個發布候選區段有兩組各 10 位標註者的圈選數。保留可依公開句序重建為單篇連續文字的評估段，依文章與重複句子連通群組重切。訓練、門檻選擇、測試各有 3,850、1,348、1,788 個區段，分屬 21、7、7 個互斥材料群組。原資料未提供可用的個人鍵供讀者留出。標註者可見整段，模型在候選區段末端以當時前綴讀出。詞彙端點評估發布過的候選區段及其明確零票，其他原文字元的觀測狀態未知。 [原始實驗 §3–4](https://aclanthology.org/I17-2068.pdf#page=3) · [資料及授權](https://www.inf.uni-hamburg.de/en/inst/ab/lt/resources/data/complex-word-identification-dataset.html) · [分割與對齊程式](core_features/background_prepare.py)

**BSPR 第一個實驗。** 使用 20 組英語語篇、每組的兩個實驗版本。從公開動作序列重建 1,786 次試驗的實際顯示區段。第一個端點以每個區段的首次到達為停點，計算下一個已驗證動作是否往回。第二個端點限於已觀測回讀，估計連續往回操作抵達的最早區段。前一區段的立即落點多由按鍵規則決定，所以另以完整往回序列形成可比較的目的地。以固定雜湊分配 15 組訓練及 5 組測試，兩版本同折。測試有 2,912 個首次到達的合格停點及 134 次回讀。模型只讀到決策位置。原事件量測可用來定位回讀行為，對同一語意疑問的首次察覺與澄清沒有供直接監督的欄位。 [原研究](https://doi.org/10.5070/g6011182) · [公開事件與材料](https://osf.io/54bda/) · [事件建置程式](core_features/readback_prepare.py)

**額外詞彙對照。** 使用 Stage 5 已封存的 CompLex 留出預測，找出同一測試句內的兩個已評、互不重疊且真人分數有差的區段。這個對照檢查罕見的同句排序案例。 [已封存的 Stage 5 結果](stage-5-complex-run.md#留出結果) · [同句重算](core_features/localization_complex.py)

## 模型與驗收

凍結同一版 Qwen3.5-2B。每段文字做一次 FP32 因果前向，不做逐 token 生成。使用原生分詞，只有在整段輸入的 token 前綴等於獨立分詞至該字元停點時取值。CWI 取候選區段末端的隱藏狀態。BSPR 一次取各個原始顯示區段末端的狀態。停止位置與所指區段保留各自的字元偏移。上傳的評估資料只有區段識別和分割資訊。讀者鍵與評估反應保留在本機。 [前綴及擷取程式](core_features/extract.py) · [訓練與評估輸入](core_features/prepare.py)

- **詞彙定位。** 以訓練文字的詞頻、區段長度、位置及字元型態做統計基線，對照加上 Qwen 狀態的無背景讀出。讀出估計每一票圈選的機率。比較同段正票與零票候選的排序。由開發組的 F1 定顯示門檻，再到測試組報候選區段的 precision、recall 和 F1。二元標準是至少一位標註者曾圈選，與每一票的機率是不同端點。遮罩只涵蓋已評候選。 [評分程式](core_features/localization_cwi_score.py)
- **主動回讀。** 比較全域先驗、位置與長度基線，以及加入 Qwen 的回讀事件讀出。目的地另比較距離、是否為前一區段、是否為開頭與區段長度的基線，及加上目前區段和候選區段的 Qwen 狀態交互特徵。目的地評分以實際發生回讀為條件，也單列有兩個以上合法候選的停點。 [評分程式](core_features/readback_score.py)
- **讀者背景。** 比較無背景的 Qwen、只用母語背景、加上背景的固定偏移，以及允許背景與文字特徵交互作用的讀出。檢查每票機率的負對數概似，以及同一候選區段的兩組真人圈選比例差是否預測得更準。母語狀態可在閱讀前提供。這裡的條件量測是標註行為，量尺仍是圈選比例。 [擬合程式](core_features/fit.py) · [群組分數](core_features/localization_cwi_score.py)

兩套資料的模型都以對應事件的似然與固定 L2 懲罰擬合。封存機率後才接本機評估反應。結果以固定讀出在留出材料上的表現解讀，配對重抽材料群組給出描述性 95% 區間。 [擬合與預測](core_features/fit.py)

## 留出結果

### 詞彙定位與高亮

在 21 個測試段、46,705 對不重疊且真人圈選率有高低差的候選中，Qwen 的排序一致率為 76.02%，比長度與詞頻基線的 72.98% 高 3.05 個百分點，配對材料區間 [1.72, 3.93]。用開發資料固定顯示門檻後，候選區段 F1 從 0.6501 升至 0.6651，差值區間 [−0.0007, +0.0240]。F1 是 precision 和 recall 的調和平均，範圍 0–1。以 Qwen 門檻高亮的 956 個候選中，568 個有人圈選，precision 為 59.4%。原有 752 個至少一票的候選，recall 為 75.5%。 [留出評分](results/core-features-first-run/cwi-scores.json)

已匯出 21 段的候選字元區間、二元高亮與各端點的圈選機率。原文 2,761 個詞彙單位中，1,618 個（58.6%）完整落在至少一個已評候選，其他位置的表現無從由這次測試估計。CompLex 的獨立重算有 25 對同句的已評目標，只看目標、讀到目標、完整句分別與真人排序一致 23、20、19 對。這項小型對照保留為指定詞與片語的結果。 [字元遮罩匯出](results/core-features-first-run/cwi-masks.jsonl) · [CompLex 同句對照](results/core-feature-localization/complex-within-sentence.json)

### 回讀起點與目的地

在 2,912 個留出首次到達停點中有 134 次往回。相較位置與長度基線，Qwen 把回讀的 Brier 誤差由 0.04087 降至 0.03694，差 −0.00393，配對材料區間 [−0.00501, −0.00285]。Brier 是事件機率與觀測二元反應的平均平方差，範圍 0–1。事件排序的 average precision 從 0.330 升到 0.460，固定先驗為 0.046。 [回讀事件評分](results/core-features-first-run/readback-scores.json)

在 123 次有兩個以上合法目的地的回讀中，距離基線及 Qwen 的目的地首選命中率同為 56.9%，固定選前一區段為 43.9%。Qwen 相對距離基線的目的地負對數概似差為 −0.0024 nats，配對材料區間 [−0.0262, +0.0250]。134 次觀測回讀中，有 84 次稍後推進到原發起區段之後。資料記錄的是回讀與閱讀推進，這些動作容許讀者在繼續閱讀時仍有未解疑問。 [回讀目的地評分](results/core-features-first-run/readback-scores.json)

### 母語背景與同文評分

| 讀出 | 每票圈選 NLL（nats，越低越好） | 每區段的兩組比例差 MAE（百分點，越低越好） |
| --- | ---: | ---: |
| 只用母語背景 | 0.289132 | 6.554 |
| Qwen，背景留空 | 0.265100 | 5.861 |
| Qwen，母語背景固定偏移 | 0.265088 | 6.671 |
| Qwen，母語背景與文字交互作用 | 0.264401 | 6.356 |

NLL 依每一票實際有無圈選的分配機率計算，下界為 0。兩組比例差的 MAE 為每一區段的觀察與模型差距相減後取絕對值再平均，完全符合觀察時為 0 個百分點。相對背景留空，交互作用讀出的每票 NLL 差為 −0.000700 nats，配對材料區間 [−0.000900, −0.000538]。但比例差 MAE 增加 0.495 個百分點，區間 [+0.399, +0.626]。在觀察的兩組比例有高低差的 650 個區段中，交互作用組的預測方向一致率為 62.0%，固定背景偏移為 55.1%。交互作用組的測試平均圈選機率為母語者 15.14%、非母語者 13.90%，真人分別為 8.71%、8.13%。分組結果有條件訊號，機率與兩組差幅的校準仍需改善。適用範圍是這個任務下的詞彙圈選及標註者背景。 [分組機率及配對結果](results/core-features-first-run/cwi-scores.json)

## 執行與重現

在 NVIDIA L4 一次擷取 131 段文字的 17,006 個非填充 token，6,517 個不同字元停點全數保留，12 項前綴及正控制檢查通過。前向與擷取耗時 6.84 秒，擬合程式內計時 3.67 秒，GPU 記憶體保留峰值 7.86 GiB。從配置到請求停止約 115 秒，已確認 L4 釋放。帳戶同時存在其他指派，讀數精度為 0.01 CU，本次前後皆顯示 765.88 CU。 [擷取](results/core-features-first-run/extraction.json) · [前綴檢查](results/core-features-first-run/causality.json) · [擬合](results/core-features-first-run/fitting.json) · [Colab 紀錄](results/core-features-first-run/manifest.json) · [用量](results/core-features-first-run/usage.jsonl)

依 `background_prepare` 和 `readback_prepare` 重建公開資料，再用 `prepare` 建立分離的訓練與評估輸入，依序在 L4 執行 `extract` 與 `fit`。以 GPU 行程記錄的機率檔雜湊封存後執行兩個本機評分入口。已獨立重算 CWI 每票誤差、比例差與遮罩混淆次數，以及 BSPR 事件誤差與目的地命中。評分與字元遮罩匯出重跑逐位元組一致。本輪交付研究程式、封存機率與匯出結果，獨立的已訓練權重包及通用正文 API 仍待封裝。 [資料與輸入雜湊](results/core-features-first-run/payload-audit.json) · [獨立核對](results/core-features-first-run/verification.json)

## 讀者背景的跨語料驗收

已對 Wikipedia 留出的 7,115 個候選區段擷取句內因果狀態，7,112 個通過精確停點檢查。加入背景交互作用後，兩組真人圈選比例差的平均絕對誤差從 7.061 上升至 7.662 個百分點。配對差 +0.601 個百分點，95% 區間 [+0.512, +0.691]。每票 NLL 從 0.30423 下降至 0.30343 nats，這個變動衡量對個別圈選票的機率分配。背景轉移未通過比例差和群組校準門檻，適用範圍仍為這個研究所指定的英語候選與標註群組。 [預先封存的規格](core-features-background-transfer.md) · [封存評分](results/cwi-background-transfer-l4/scores.json) · [擬合來源](results/cwi-background-transfer-l4/fit-manifest.json)
