# Stage 3 首輪 Colab L4 實驗

**首輪完成。** Qwen3.5-2B 在 Colab L4 通過 FP32 前綴檢驗，並以同一次因果前向取得每篇文章的特徵。PLABA-EVAL 五折的句級理解自評 MAE 從長度基線的 **0.732** 降到 **0.616**。文章家族與讀者在驗證折間均無交集。 [L4 指標](results/stage3-l4/float32/metrics.json) · [獨立重算](results/stage3-l4/float32/verification.json)

## 句級自評

凍結官方 Qwen3.5-2B 固定權重。模型輸入只有全文，每篇只進入模型一次。從末層取焦點句末及篇末的狀態，串接為 4,096 維向量後以 L2 正規化。兩個狀態用於模擬讀者可查閱全文後的評分。對應證據句、讀者 ID、正解與版本標籤未進入模型。另在長度＋版本基線提供已知的原文／白話版標籤，衡量該標籤能解釋的變異。 [讀出實作](stage3/run.py) · [固定模型版本](https://huggingface.co/Qwen/Qwen3.5-2B/tree/15852e8c16360a2fea060d615a32b45270f8a8fc)

將 1,826 筆評分彙整至 609 句，使用 Stage 2 的新版五折。39 個文章家族含 78 個版本、220 位讀者。每一折只以訓練折估計平均值、長度標準化及固定係數 `λ=1` 的 ridge 權重。以下是 1–5 分量尺上的逐句平均絕對誤差，越低越好。 [五折與評分](results/stage3-l4/float32/metrics.json) · [逐句留出預測](results/stage3-l4/float32/predictions.jsonl)

| 輸入特徵 | 處理容易度 MAE ↓ | 理解自評 MAE ↓ |
| --- | ---: | ---: |
| 訓練折均值 | 0.737 | 0.813 |
| 長度 | 0.632 | 0.732 |
| 長度＋已知版本 | 0.613 | 0.687 |
| 凍結 Qwen | 0.660 | 0.658 |
| 凍結 Qwen＋長度 | **0.593** | **0.616** |

固定留出預測後，以 25 個共用讀者相連的文章群組做 10,000 次配對 bootstrap。Qwen＋長度相對於長度的 MAE 差為處理容易度 −0.039（95% 區間 [−0.072, −0.005]）、理解自評 −0.116（[−0.152, −0.080]）。相對於長度＋已知版本，理解自評仍低 0.071 分（差 −0.071，區間 [−0.110, −0.030]）。處理容易度的差異區間跨零。重抽樣使用已固定的預測，未重新訓練各折。以 Colab 下載的特徵在本機重擬合，所有 MAE 的最大差為 1.22×10⁻¹⁵ 分。 [重抽樣與覆核](results/stage3-l4/float32/verification.json)

在 265 組原文與白話版的句子對齊位置上，真人的平均理解自評差為白話版高 **0.723** 分。Qwen＋長度的留出預測估為高 **0.529** 分。預測差減真人差的 95% 區間為 [−0.431, +0.006] 分，尚不足以確認改寫幅度的校準。這個比較將一對多的白話句先取平均，最後對齊位置等權。這兩個端點分別回答句級分數和同一來源的改寫差。 [改寫差重算](results/stage3-l4/float32/verification.json)

## 前綴測試與資源

三組前綴為同一篇 216-token 測試文的前 32、65、97 個 token。比較同長後文替換、截短和同批右補齊。檢驗量是共用前綴中最大的逐 token 相對 RMS 差，門檻分別為 0.002、0.02、0.02。同長替換的後文另作正控制，確認新內容確實改變後文狀態。使用固定 tokenizer 另驗證 609 個句末的分詞前綴和正文偏移。

| 運算精度 | 後文替換 | 截短最大差 | 右補齊最大差 | 處置 |
| --- | ---: | ---: | ---: | --- |
| BF16 | 0 | 0.02416 | 0.02174 | 高於既定門檻，在正式抽取前停止 |
| FP32 | 0 | 4.24×10⁻⁶ | 2.66×10⁻⁶ | 通過同一門檻，完成抽取及五折 |

兩次使用 NVIDIA L4（約 22.0 GiB）、PyTorch 2.14.1＋CUDA 13.0、Transformers 5.17.0 和 SDPA。FP32 把官方 BF16 權重值轉為 FP32 運算，矩陣運算採最高 FP32 精度，cuDNN TF32 關閉。差異縮小與低精度下的形狀依賴數值誤差相符。因果驗收適用於前綴的骨幹狀態，句級讀出另外使用全文完成後的狀態。 [BF16 原始檢驗](results/stage3-l4/bfloat16/causality.json) · [FP32 原始檢驗](results/stage3-l4/float32/causality.json) · [運算環境](results/stage3-l4/float32/environment.json)

FP32 以最多四篇為一批，20 次批次前向讀取 78 篇、共 17,140 個非 padding token。同步抽取與擷取特徵耗時 7.33 秒，約 **2,339 token/s**，不含安裝、下載和定期寫檔。CUDA 峰值配置 **7.23 GiB**，保留 **7.60 GiB**。兩次從配置完成到送出停止請求約為 74 秒和 83 秒，均驗證已釋放。Colab 帳戶用量顯示兩次前後均為 768.80 CU，取樣時的單一活動指派費率為 1.94 CU／小時，單次扣款無法從帳戶截點辨識。 [抽取量測](results/stage3-l4/float32/extraction.json) · [BF16 用量](results/stage3-l4/bfloat16/usage.jsonl) · [FP32 用量](results/stage3-l4/float32/usage.jsonl) · [FP32 釋放紀錄](results/stage3-l4/float32/manifest.json)

在 L4 以 PyTorch 和 Transformers 5.17.0 執行。準備 [Stage 2 PLABA-EVAL 資料](stage-2-data.md)，遠端資料以專案指派的本地磁碟路徑為準。以下可直接執行抽取與讀出；Colab 工作階段使用的封裝入口另附。 [封裝入口](stage3/colab_entry.py) · [已訓練讀出權重](results/stage3-l4/float32/head.npz)


本輪支持在同一英語生醫摘要語料評估未見文章家族、未見讀者的全文句級自評。公開資料並行查核找到 ROAMM 的按鍵回報與回溯圈選，端點是自覺注意力中斷。疑問發生、跨句指向和解除的語意定位仍需對應的真人觀測。 [並行資料查核](stage-1/data-selection.md#stage-3-並行查核的閱讀中回報資料)

## 快取特徵的後續實驗

固定同一組開發五折，以同一份 L4 快取的前 2,048 維取句末、後 2,048 維取篇末。個別或合併後使用既有的 L2 正規化與 ridge 評估，長度特徵由各折訓練資料標準化。

| 使用的 Qwen 特徵，均加長度 | 處理容易度 MAE ↓ | 理解自評 MAE ↓ |
| --- | ---: | ---: |
| 句末 | 0.577 | 0.604 |
| 篇末 | 0.623 | 0.664 |
| 句末與篇末 | 0.593 | 0.616 |

句末的點估計較低。句末減合併的理解自評 MAE 差為 −0.011，依 25 個讀者連通群組重抽樣的 95% 區間為 [−0.027, +0.002]。同一篇文章內，兩句的真人理解自評有高低差時，句末＋長度給出相同排序的比例為 69.0%，僅用長度為 63.0%。每次預測同分計半，分母為 1,829 個句對。這組結果讓句末特徵成為下一輪可用的起點。 [句末與篇末對照](results/stage3-l4/float32/feature-ablation.json)

**句級疑難回報。** 另以 858 筆結構化回報（452 筆有疑難、406 筆明確無疑難，來自 286 句）擬合二項 logistic ridge，每筆真人回報等權，L2 係數為 1，截距未受懲罰。未施測結構化回報的 968 筆自由文字介面資料沒有進入此端點。沿用同一份五折，句末＋長度的折內平均 AUROC 為 0.757，Brier 為 0.201，相應的長度基線為 0.685 與 0.226。句末和篇末合併時為 0.758 與 0.199。Brier 是逐次機率和真人二元回報的平均平方誤差，越低越好。這是可用於 App 句級疑難實驗的同語料開發結果。 [疑難回報實驗](results/stage3-l4/float32/issue-diagnostic.json)

後續已用同一分割完成「有無疑難」及「術語不清」的 surprisal、中間層 logits 與注意力對照。正式發布的適用範圍需由獨立資料驗證。 [特徵對照報告](stage-3-feature-ablation.md)
