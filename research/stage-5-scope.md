# Stage 5 局部定位與擴大條件

下一輪擴大真人量測的涵蓋範圍。沿用固定 Qwen3.5-2B 及線性讀出，先建立有位置對齊的詞與片語端點。並行工作是從既有研究補齊語意疑問的回報停點、上文區段及後續更新。兩條工作各有自己的真人證據及驗收。 [整體執行計畫](execution-plan.md)

## 為什麼先做定位

目前的三任務共享 adapter 可一起更新。加入兩個文獻效應後，句級理解自評與逐次指涉誤差改善，兩個共享留出效應誤差差值的區間仍跨零。Zhan 共享組在訓練材料估為 +24.32 個百分點，留出材料只剩 +8.45。線性頭在首輪共享訓練的各逐次誤差上仍是較低的參照。這些比較支持先核對新的量測與留出條件，也留下表徵與訓練容量待檢驗。 [首輪共享結果](joint-first-run.md) · [聯合效應對照](joint-effects-run.md)

## 第一個詞與片語實驗

使用 CompLex 固定版。讀者看過整句再評指定詞或片語的詞彙難度，發布值是 0–1 的平均評分。原文字元範圍採 Unicode 半開區間，未獲評分的區段為未觀測。保持固定句子留出，並分開報單詞與片語。 [原始量測](https://aclanthology.org/2021.semeval-1.1.pdf#page=3) · [原始資料稽核](results/joint-first-run/complex-audit.json)

已完成 CPU 資料建置。先保留官方測試，其次調整，最後訓練。跨單詞及片語任務，以 Unicode 正規化、大小寫摺疊和空白統一後的句子分組，移除跨分割重複句的 461 筆評分。原文字元及偏移保持原樣。留下 10,279 筆評分，各分割的句子群組交集均為零。 [建置與資料版本](results/stage5-readiness/preparation.json) · [重跑程式](stage5/complex_prepare.py)

| 分割 | 可唯一定位的字元區段 | 目標 token 齊邊且停止前綴相同 |
| --- | ---: | ---: |
| 訓練 | 8,680 | 8,667 |
| 調整 | 503 | 503 |
| 測試 | 1,096 | 1,094 |
| 合計 | 10,279 | 10,264 |

原生 Qwen tokenizer 的 15 筆其餘目標有 token 跨越非空白的標註邊界，三種讀出均排除。對 10,264 筆齊邊目標，完整句的 token 前綴與獨立分詞至目標字元末尾均相同。分詞核對使用 token ID，抽取時另在 L4 實測模型前綴狀態。正式比較共使用 9,166 個句子及 5,437 種獨立目標字串，輸入合計 333,423 個非 padding token。句對評分以完全相同的目標字串配對，獨立計數真人同分和有高低的句對。 [分詞稽核](results/stage5-readiness/tokenization.json) · [正式輸入稽核](results/stage5-complex/input-audit.json) · [前綴檢查](results/stage5-complex/features/causality.json)

| 對照 | 要檢驗的事 |
| --- | --- |
| 只看目標詞或片語的 Qwen 狀態 | 獨立目標字串能解釋多少真人難度。 |
| 同一句一次因果前向，在目標末 token 取狀態 | 讀到目標時可見的前文提供多少訊號。比較目標停止後分詞與全句前綴的一致性。 |
| 同一次前向的目標與句末狀態 | 整句可見時的回顧，符合 CompLex 的量測情境。 |

主要分數使用留出 MAE，另報同一目標在不同句子中的難度排序，以及訓練見過及未見目標的誤差。對留出句子群組做配對重抽樣估計 MAE 差值。抽取和擬合皆用 Colab L4，先以長度分層的小批實測。兩種句子讀出都從同一次前向取位置狀態。若在留出文本上有可重現的定位增益，再測把此端點加入原來三任務能否共享訊號。 [一次前向與位置定義](mathematical-formulation.md#2-一次因果前向運算)

## 語意定位與擴大條件

已核對 INQUISITIVE 句末圈選的公開紀錄、DCQA 同源的答案位置，以及 TED-Q 每兩句一停的同疑問追蹤。INQUISITIVE 完整文章需另行申請，TED 逐字稿作模型用途需有相應授權。在 TED-Q 的 1,257 個同時追蹤兩疑問的停點，有 88 次只有較舊的疑問被評為至少部分得到回答。這個端點可驗證兩句區間的更新，句內首次觸發仍無法由這批資料辨識。 [語意定位與疑問更新的稽核](stage-5-semantic-run.md)

CompLex 已在 L4 完成 25%、50%、100% 巢狀句子抽樣的三種讀出。只看目標在三種資料量的留出 MAE 均最低，三種讀出的 MAE 從 50% 到 100% 都繼續下降。可利用上下文的讀出對同一目標的跨句排序一致率約為 51–52%。這個詞彙分數可作定位工作的輔助端點，語意疑問的位置與更新仍依上面的獨立觀測驗收。 [CompLex 實驗報告](stage-5-complex-run.md)

Currie 跨句矛盾端點已在 L4 完成。用 24 套近／遠矛盾材料及 4,248 筆既有篇末判斷，完整篇章及只看末句均優於訓練折的平均回報比例。完整篇章相對只看末句的 Brier 差區間跨零。矛盾句是作者在實驗中的位置錨點，仍需有讀者所選位置及區段的資料驗收語意定位。 [跨句實驗與留出結果](stage-5-semantic-run.md#留出結果)

模型規模的比較安排在可對照的資料與評分固定後。若增大同端點資料仍有增益，優先增加該端點的材料。若表現趨緩，且仍有清楚的留出差距，才用相同資料、步數、損失與評分比較適配 Qwen 或 4B 骨幹。若主要落差出現在外部研究，優先增加同端點的獨立材料家族。全程沿用既有真人資料。
