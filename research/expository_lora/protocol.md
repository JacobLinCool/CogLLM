# 說明文句級讀出與末層 LoRA 對照

PLABA-EVAL 提供生醫摘要原文及專家白話改寫的逐句閱讀容易度和理解自評。沿用原先 39 個材料家族、78 篇刺激、609 個句末、1,826 次雙量尺評分及 265 個原句／改寫句群對齊。沿用以文章家族和讀者交集形成的 25 個連通群組及五折，保留材料、讀者和改寫對齊的隔離。每次折外擬合只讀該折的訓練評分及改寫對齊。收齊折外預測後另以全部 PLABA-EVAL 擬合兩個模型，轉移至既有 Kerwer 研究。 [PLABA-EVAL 原研究與作業](https://lrec.elra.info/lrec2026-ws-readixtsar-04) · [原始資料](https://github.com/SDS-NLP/PLABA-EVAL) · [既有開發對照](../stage-6-holdout-plan.md)

## 訓練和收斂

固定 Qwen3.5-2B revision、詞元表和 Transformers 版本，以英文摘要作純文字輸入，讀取經獨立詞元化確認的因果句末。兩個模型共用句級讀出。每一量尺用線性 softmax 頭輸出五級機率。前向輸入是最終 RMSNorm 向量再取單位長度，以及僅按訓練折標準化的字元長度與詞數的 log1p。長度特徵除以 √2。兩臂皆不輸入文本版本、研究條件或讀者身分。 [模型與套件登錄](../backbone_transfer/models.json)

句級損失等權合併每句的人類五級評分分布交叉熵。在每個作者對齊位置先平均同一臂的多句期待評分，再算白話版減原文。訓練時在對齊位置間平均此差，加入兩個量尺相對訓練真人的平均效應平方誤差，各乘 1/2。讀出頭非截距參數使用 L2，係數為每折訓練句數倒數。先以凍結骨幹收斂讀出頭，再以該讀出頭初始化 LoRA 臂。LoRA rank 4，alpha 4，僅作用於最後一個 MLP 的 down_proj，兩個低秩因子皆訓練並採相同 L2 係數。保留兩個固定的 A 初始化種子 12、29，B 初始為零。以訓練正則化目標較低的收斂解代表 LoRA 臂。種子選擇與收斂檢查只使用當折訓練目標。 [擬合程式](fit.py)

使用單張 Colab L4，先以 FP32 快取 102 篇文章所有句末的最後 MLP 經 gating 後輸入 X 和 final RMSNorm 前狀態 Y。這個 LoRA 位置允許將 Y 精確替換為 Y + X Aᵀ Bᵀ 再套用原本的 RMSNorm，後續計算為逐位置運算。使用 FP64 全批次 L-BFGS 和 strong Wolfe 線搜尋來擬合小型參數，不重複運行整個骨幹或保存其反向圖。全批次梯度的最大絕對值 ≤ 3×10⁻⁷、L2 範數 ≤ 10⁻⁵、相鄰檢查點的相對目標變化 ≤ 10⁻⁹，三項均成立才算收斂。凍結臂每 40 次迭代檢查一次，最多 720 次。LoRA 臂每 80 次迭代檢查一次，每個種子最多 12,000 次。首輪未改良座標的 LoRA 在 720 步停止時仍未收斂。重跑以訓練折 X 的薄 SVD 選取 A 的行空間座標，再依奇異值相對其中位數縮放。正交補空間只會增加既有 L2 懲罰。最佳化採等價的原始損失，驗收把 A 梯度轉回原參數座標。第二輪只靠這個預條件的 L-BFGS，折 0 第一個起點到 12,000 步時仍有超標梯度。僅加聯合 Newton–CG 的第三輪在折 0 第一個起點完成 20 次更新後，最大梯度仍超標。第四輪交替使用精確 A 區塊 Newton 步與原聯合 Newton–CG，通過前兩折，折 2 的第一個起點仍超標。第五輪使用精確 A 區塊預條件的聯合 Newton–CG，通過四折，折 4 第一個起點的目標下降時梯度反而增大。最終求解至少做 1,200 次 L-BFGS 迭代，並在相對目標變化 ≤ 10⁻⁹ 且原參數梯度 L2 範數 ≤ 3×10⁻³ 時切換。若 A 梯度佔全梯度 L2 至少 90% 且其餘梯度 L2 ≤ 10⁻⁵，優先使用 A 的精確區塊 Newton 更新，最多 24 次。聯合 Newton–CG 使用精確 A 區塊、讀出頭正定對角和 B 的 L2 曲率作預條件，最多 64 步，每步最多 256 次 Hessian–向量乘積。Armijo 回溯使用同一正則化目標。聯合試探點的原始梯度 L2 也不得超過步前的 1.25 倍或 3×10⁻⁶，以較大者為準。單段精修最多八次嘗試，之後從接受點繼續 L-BFGS，跨段共用預算和原收斂門檻。第六輪的受保護流程通過折 4 與折 3，折 2 未達標。正式執行在同一張 L4 先以受保護流程擬合折 4，其餘四折和全資料先用通過折 0–3 的聯合流程。聯合流程依原順序從無阻尼開始，每起點只進入一段精修。若任一起點未通過收斂條件，同一執行用另一個已驗證的流程重擬該切分。這項分派及重試只根據訓練收斂紀錄。兩種流程共用資料、模型、正則化目標、初始化、收斂門檻及基於訓練目標的種子選擇。若某切分用完兩種流程仍超標，收回已完成的封存輸出並記錄缺項，整組評分仍要求全部通過。直到三項原收斂條件皆成立才封存。保存實際迭代數、目標評估數、每個檢查點梯度和目標值。LoRA 的判準是已找到穩定駐點。 [訓練與前向驗證程式](run_l4.py)

兩臂均用實際模型重跑所有封存的預測。LoRA 於末層原 Linear 上實際加上低秩更新。每一篇文本在每個模型內經一次因果 forward 輸出全部預定句末，無自迴歸解碼。最終預測與快取計算的逐格機率最大誤差須 ≤ 5×10⁻⁵。另用凍結及全資料 LoRA，分別驗證裁切或替換後文不改變共同前綴的隱狀態，最大相對 RMS 差須 ≤ 0.001。Colab 工作者在 36 分鐘總期限內收件並釋放本次 L4。

## 評分與解讀

PLABA-EVAL 報告相同折外句的閱讀容易度及理解自評 NLL 和 RPS，兩者皆越小越好。另報作者對齊的改寫幅度及其與真人差距。LoRA 減凍結的配對差以固定折外預測在 25 個連通群組重抽樣。逐句機率評分與改寫效應幅度分別解讀。

Kerwer 有 12 組有／無小標的配對摘要，正文相同。每篇模型分數只平均對回同一正文位置的句末理解自評，等權並線性映到研究的 1–8 分，保留小標對因果前文的影響。估計有小標減無小標的篇末自評差，對真人及兩組模型按相同 DOI 加權，對真人不確定性同時重抽 DOI 和讀者。估計兩模型各與真人的絕對差，以及 LoRA 減凍結之誤差差。沿用既有幅度等效範圍 ±0.5 分。Kerwer 真人評分留在本機，訓練與封存預測均不讀取。此研究先前用作凍結模型的外部診斷，這一輪對照的是新增 LoRA 是否改善該既有外部端點。PLABA-EVAL 評分時全文可見，Kerwer 評分是篇末自評。句末輸出支援比較這些可觀測反應，兩份研究的設計均未測量逐 token 的心理負荷曲線。 [Kerwer 原研究](https://doi.org/10.1525/collabra.18898) · [既有外部分析](../stage-6-holdout-plan.md) · [評分程式](score.py)
