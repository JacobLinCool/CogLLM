## 重建

在專案根目錄，以 Python 3.11 或更新版執行。轉換器使用標準函式庫和 CPU。

```bash
python3 -m research.stage2 \
  --cache-dir .cache/cogllm/raw \
  --output-dir .cache/cogllm/stage2-rebuild
```

程式按來源固定版本或發布 ID 下載並核對 SHA-256。已備妥來源時可加 `--offline`。現有輸出目錄須換成新路徑，來源快取放在輸出目錄外。原檔版本不符或缺檔時，程式回報原因，輸出資料在驗證結束後才落到指定目錄。首次執行已實測從公開來源取得全部八個原檔。離線連跑兩次，九個輸出檔和總稽核檔的雜湊一致。以本機快取重建單次約 0.20 秒，三套 JSONL 及五折名單合計約 7.0 MB。 [轉換入口](stage2/__main__.py) · [來源版本、授權及雜湊](stage2/sources.json)

## 輸出與訓練介面

- **`stimuli.jsonl`** 保存逐版本的精確正文、文件／刺激家族、語言及已查核的原文區段。偏移為 Python Unicode 字元的半開區間 `[start, end)`。PLABA-EVAL 使用發布句界。Zhan 的 `np1`、`np2` 為兩個候選角色；有供給代詞時另標出提示字符。OneStopQA 只有實驗所見段落的區段。
- **`trials.jsonl`** 保存刺激、讀者識別鍵、來源檔及從表頭後開始的 1-based 資料列、任務、可見範圍、目標區段及觀測。正文輸入取 `text[:visible_end]`，研究任務可以讀取該任務的 `task_context`。純正文模型使用選填的閱讀前背景，這三批無可直接接入的前測背景。作者正解、作答與證據句留在觀測欄，身份鍵、版本和 Zhan 的動詞類型可用於分組及有明確設計的對照。
- **觀測狀態。** `observed` 有實測值。PLABA-EVAL 有 452 筆勾選至少一項疑難，以及 406 筆明確選無疑難。其餘 968 筆來自自由文字介面，結構化類型為 `unobserved`。`missing` 表示該欄對應的值未能用於分析，例如作答指向一個不存在的句序。缺標遮罩應依觀測欄及任務產生。選項或證據句屬該題的回應與材料資訊，分數應保留在相應的題目端點。
- **`splits.json` 與 `audit.json`** 保存開發五折、訊號用途、原始來源、各任務分母、重算結果及輸出 SHA-256。原始與逐次資料留在本機忽略目錄，專案保留程式、來源鎖和不含逐次反應的稽核檔。

### PLABA-EVAL 證據句訂正

原先開卷排序基線使用作答表的單一句序索引。935 筆作答中，932 筆依舊索引可連到句子，其中 **213 筆連到了題目表證據範圍以外的句子**。另 3 筆舊索引無法對齊。Stage 2 依 `mcq_items.csv` 記錄證據清單，932 筆有證據，其中 126 筆指向多句，並保留舊索引供追查。 [歷史基線紀錄](training-protocol.md#已完成的首輪基線)

已用較新的因果句末序位讀出與訂正證據清單完成開卷答錯排序。932 筆可計分作答中有 133 筆答錯。各題證據句的理解分數取平均，AUROC 為 0.557。相對同一證據的句長基線差 −0.008，95% 區間 [−0.067, +0.061]。相對整篇模型分數差 +0.005，95% 區間 [−0.022, +0.029]。資料未支持把現有理解自評直接當作局部答錯風險。這項對照沿用讀者與文章隔離的開發折及固定讀出，沒有用作答重新擬合。 [評分規格](stage6/plaba-corrected-evidence.md) · [實際結果](results/plaba-corrected-evidence-scores.json)

11 筆作答原文字串與選項表不一致，已用 `metadata.selected_text_matches_item_option` 標記。按發布來源可保留正誤，用選項文字作目標時須遮罩這些列。PLABA-EVAL 的原始顯示順序未取得，匯出採發布順序，158 題有 153 題正解為 A，評估前需控制選項位置捷徑。

### OneStopQA 材料版本

固定 HF Parquet 有 1,458 列，包含段落、題目、選項及作者證據區段。以難度類別、原段落、題幹和來源選項順序做精確對照，真人試次中 648 個題目版本只有 **32 個**能唯一對到同一材料。因此這批直接使用作者實驗 TSV 的實際呈現文字，按 `new_options` 保存選項順序。STARC 片語未接到真人試次。HF 固定檔的 SHA-256 保存在來源鎖。 [HF 固定材料](https://huggingface.co/datasets/malmaud/onestop_qa/tree/1df9aea8c9532045bc55c001d7c588372de2d723) · [作者真人試次](https://github.com/berzak/onestop-qa/tree/7a058755e1ff0d3f835a67109c669c7e294d4239/human_experiments)
