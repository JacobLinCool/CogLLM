# IIRC 段內上文證據定位

## 留出評分前的設計

已知讀者選定的錨點，模型估計段內在它之前的支持區間。真人金標來自 IIRC 回答者選定的 `main` 證據區段，且能逐字對回原始段落。可用資料涵蓋 533 題訓練和 65 題官方 dev 留出，分別有 438 和 51 個來源文章家族。兩組文章、段落及問題識別碼皆無交集。留出推論只讀正文、問題識別碼及錨點座標。 [作者實驗 §2.3](https://aclanthology.org/2020.emnlp-main.86.pdf#page=4) · [資料稽核](results/iirc-seed-evidence-audit.json)

兩組共用原文錨點以前的候選區間，每個候選最多 28 個連續詞段。形式基線使用片語長度、離錨點的距離、段中相對位置、大小寫、標點數字及和錨點的字詞重疊。Qwen 組加入固定 Qwen3.5-2B 的區間首尾表徵及各自和錨點表徵的交互項。每段正文只有一次 FP32 前向。錨點末端必須經過獨立前綴分詞核對，候選表徵只來自錨點起始前的 token。兩組以題目等權擬合，損失為金標重疊候選的條件負對數機率，ridge 係數為 0.005。 [封存實驗實作](semantic_tracking/iirc_seed_pointer.py)

主指標是排名第一的候選和金標字元區段的交並比至少 0.5 的比例。分母包括錨點無法認證等未產生排序的題目。按來源文章做 10,000 次配對重抽樣，Qwen 減形式基線的差值區間下界大於零才算通過。另報排名第一的平均交並比、前五覆蓋率及候選集合的覆蓋上限。這批資料只有一對嚴格可交換的 dev 上文區段，主指標的改善無法單獨證明同段多個疑問的身分辨別。 [主指標程式](semantic_tracking/iirc_seed_pointer.py) · [配對數量](results/iirc-seed-evidence-audit.json)

## 留出結果

**排名第一的主指標未通過預定門檻。** 原始交並比範圍為 0–1，下表數值越高表示覆蓋較多已標註的上文。全部 65 個留出錨點可認證，且每題在候選集合中都有交並比至少 0.5 的區段。 [封存預測的正式評分](results/iirc-seed-pointer-run/scores.json)

| 評估 | 形式基線 | 加入 Qwen | Qwen 減基線與 95% 配對區間 |
| --- | ---: | ---: | ---: |
| 第一候選覆蓋率 | 18.46%（12/65） | 30.77%（20/65） | +12.31 個百分點 [−1.56, +26.15] |
| 第一候選平均交並比 | 0.2065 | 0.3418 | +0.1353 [0.0213, 0.2543] |
| 前五候選覆蓋率 | 27.69%（18/65） | 53.85%（35/65） | +26.15 個百分點 [11.48, 40.33] |

次要指標支持增加候選時能找回更多上文。主結果保留為未驗收，且評估餵給兩組的都是已知錨點。貼文後先預測錨點再找上文，以及讀者在何時察覺解答，仍需要各自的驗證。 [完整指標與驗收](results/iirc-seed-pointer-run/scores.json)

## 執行及重現

本機 Metal 用 FP32 Qwen 擷取 489 段共 135,576 個 token。531 題用於擬合，一題錨點末端分詞無法認證，一題缺少達重疊門檻的候選。三個獨立截短前綴檢查的投影最大絕對差均為 0。擷取、擬合及封存共 98.04 秒。 [執行與權重封存](results/iirc-seed-pointer-run/manifest.json)

使用 `iirc_seed_pointer` 的 `prepare`、`forecast` 和 `score` 依序固定輸入、封存預測及啟用留出金標。獨立重讀作者公開檔核對兩組共 598 個錨點與區段，重算指標及配對區間。資料建置和封存評分的輸出重跑逐位元一致。 [封存權重](results/iirc-seed-pointer-run/heads.npz) · [獨立核對](results/iirc-seed-pointer-run/verification.json)

## 同段稍後的證據區間

另以作者原始檔核對 260／22 個錨點之後的支持區段，來自 239／19 個訓練與留出文章家族。dev 的證據末端出現在錨點之後 91–953 個字元，其中位數為 271.5。這個 dev 沒有符合嚴格條件的同段交換配對。已選入的題目皆至少有一個符合規則的稍後支持區段，因此間距分布以有稍後證據為條件。 [官方檔重建](results/iirc-seed-later-audit.json)

可重用的評分路徑從錨點末端向後，以每 16 個 token 的固定間距找可經精確分詞核對的前綴。每一停點估計證據完整出現的區間機率，最後一格保留超過目前觀測範圍的機率。模型候選以錨點及當時前綴的投影狀態評分，形式對照只用已經過的 token 及區間長度。以合成權重檢查機率正規化、區間與右設限的負對數分數，以及截短和改寫後段時先前機率的一致性。稍後證據的真人留出尚未擬合或評分，資料中的區間對應支持文字首次能被看見的停點。 [區間 API](semantic_tracking/iirc_seed_later.py) · [合成檢查](results/iirc-seed-later-synthetic-checks.json)
