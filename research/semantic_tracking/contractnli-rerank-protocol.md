# 用詞彙與 Qwen 命題表徵重排證據

上一輪在 ContractNLI 官方測試分割的 47 篇 EDGAR 文件中發現，BM25 擅長把證據帶進排序前段。扣除文章內多個命題共用的分數後，Qwen 在兩套已給定的證據之間更能區分命題。這一輪用上述 47 篇已分析的文件訓練輕量讀出，在官方驗證分割的 23 篇 EDGAR 文件上做新留出。後者用於本實驗前未執行模型評分。研究目的為確認詞彙比對加上 Qwen 命題訊號，能否改善新文章的整篇證據定位。 [上一輪結果](contractnli-evidence-results.md) · [原始分割及證據定義](https://aclanthology.org/2021.findings-emnlp.164.pdf#page=2)

## 資料與因果條件

兩組文件皆使用同一凍結 Qwen3.5-2B 快照及先前 QASPER 逐 token 讀出。每篇文章擷取一次因果狀態。17 個官方命題各獨立擷取一次並共用。資料保持完整原文及來源候選句或清單項目。以指定 tokenizer 核對可精確對回前綴的候選停點。只評可對齊的候選，正例須能對齊整套人工證據。稽核兩組識別碼、SEC 來源位置、逐字及正規化正文。另以正規化正文的 5 字元及 5 詞集合 Jaccard 係數檢查跨組相似度，任一種達 0.80 的配對不能跨組。全部 70 篇材料均按上述規則通過。模型分數在接合留出證據標註前先封存。 [原始資料與索引規格](https://stanfordnlp.github.io/contract-nli/#dataset-specification)

詞彙特徵用固定訓練候選庫的 IDF 與平均候選長度計算 BM25，固定 \(k_1=1.2\)、\(b=0.75\)。詞彙取 NFKC、casefold 後的 Unicode 英數詞，命題詞去重。每個停點只讀該候選開始到可見的末端，去掉末尾不可見的空白，計算 \(\log(1+\mathrm{BM25})\)。Qwen 特徵為原逐 token 讀出的 hazard logit，以及在同一停點扣除 17 個已知命題 logit 平均的差值。兩組詞彙統計與三個特徵的均值及尺度均只用訓練文件估計。讀出各候選位置時只用當下與已讀正文，命題與詞彙統計在閱讀前提供。

## 讀出及驗收

三組可訓練讀出使用兩個特徵及相同正則化。對每個有完整對齊證據的訓練命題，記候選分數 \(s_j\)、證據集合 \(A\)。損失是 \(\log\sum_j \exp(s_j)-\sum_{j\in A}s_j/|A|\)，使每一份人工證據都進入比較。群組等權，群組內文件等權，同篇合格命題等權。平均損失加上 \(0.05\lVert w\rVert^2/2\) 的 ridge。加法截距對排序無影響，因此只有係數。所有候選的輸出是排名分數。

| 讀出 | 輸入 |
| --- | --- |
| BM25 | 單用固定訓練候選庫的詞彙分數 |
| Qwen 原分數／減共用分數 | 分別使用原 logit 和扣除共用分數的 logit |
| 只用 Qwen 擬合 | 原 logit 和扣除共用分數的 logit |
| 詞彙加 Qwen 原分數 | 詞彙分數和原 logit |
| 詞彙加 Qwen 減共用分數 | 詞彙分數和扣除共用分數的 logit |

主要候選是最後一組。預先要求三個差值的 95% 配對區間下界都大於 0。整篇證據 AP 要同時高於 BM25 及只用 Qwen 的擬合讀出。同篇支持／反駁兩套不重疊證據的互換排序也要高於 BM25。AP 與互換分數皆為 0–1，越高越好。互換排序比較每套完整證據在各命題下的平均原分數，兩個方向平均，平手給 0.5。依文件群組同時重抽所有方法 10,000 次，種子 735972。另報與詞彙加 Qwen 原分數的差、支持與反駁分項、資料排除及前綴測試。 [第一輪的排序判定](contractnli-evidence-protocol.md#順位與效應)

這個測試使用固定命題與作者給定的候選區段。模型分數能檢驗指定命題的證據位置，也能核對命題變動引起的區段排序變化。開放命題和自發疑問的觸發或解除時間需要另外的觀測與留出。
