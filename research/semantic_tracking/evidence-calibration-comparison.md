# 證據到達讀出的對稱校準對照

ExpMRC 的第一次分析發現，逐 token 讀出比題幹基線更能排列同文問題的證據先後，但給出的絕對機率較差。後續回溯分析校準了逐 token 讀出，保留其配對順位。本次使用同一批材料及相同五折，將相同的校準彈性也給每一組基線，檢查逐 token 表徵是否仍有額外價值。 [原分析](expmrc-transfer-results.md) · [原回溯校準](expmrc-calibration-results.md)

位置、題幹、段落交互及逐 token 交互共四組，各自從同一組凍結 QASPER 預測開始。每組都在四折最小化兩份參考終點等權的區間 NLL，使用相同的兩參數單調累積強度轉換及最佳化器，再於剩下一折計分。使用原分析的 165 篇、555 題，按文章分折。另把四組以全部 165 篇估出的參數固定存檔，供其他語料的獨立驗收。全部擬合參數的樣本內表現不作泛化證據。

主比較為校準後逐 token 減校準後題幹的逐題區間 NLL，95% 文章群組配對區間上界須低於零。次比較為校準後逐 token 減校準後段落的區間 NLL 及四組累計 Brier。另查核同文同停點的 698 組累積強度順位在轉換下是否改變。沿用原 ExpMRC 的 10,000 次文章群組重抽樣及種子。此回溯對照評估指定問題的參考證據何時完整出現。使用者自行察覺疑問的時間及理解是否因此改善仍缺真人觀測。
