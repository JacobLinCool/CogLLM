# Frick 的跨句因果特徵對照

原七特徵讀出在 Frick 的目標句明顯低估同一句在一致與不一致前文下的真人首次回報差。本輪在相同凍結 Qwen3.5-2B 的已封存句末表徵上，擴充讀出在當句與全部已讀句之間的詞形重合及表徵關係。兩個模型使用同一巢狀分割、損失、選模及驗收規則。材料已用於前次開發與誤差分析，這是回溯對照。 [原條件概似](frick-conditional-protocol.md) · [目標句診斷](frick-target-hazard-diagnostic.md)

## 從單篇已讀文字計算的七項新增特徵

在第 $t$ 句末，以 $W_t$ 表示當句的正規化詞形集合。沿用原讀出的 Unicode NFKC、大小寫折疊及至少四個字元的詞形規則。用 $n_t(w)$ 計算前 $t-1$ 句裡含有詞形 $w$ 的句數。對每個較早句 $j<t$ 計算

\[
\begin{aligned}
\operatorname{idf}_t(w) &= 1+\log\frac{t}{1+n_t(w)},\\
a_{tj} &= \frac{\sum_{w\in W_t\cap W_j}\operatorname{idf}_t(w)}
{\sum_{w\in W_t}\operatorname{idf}_t(w)},\\
\pi_{tj} &=\frac{\exp(4 a_{tj})}{\sum_{i<t}\exp(4 a_{ti})},\qquad
u_{tj}=\frac{1}{t-1}.
\end{aligned}
\]

空詞集合的重合定義為零。令 $v_t$ 為正規化後的完整前綴句末表徵，$v_0=0$。定義 $d_t=v_t-v_{t-1}$，再取 $e_t=d_t/\lVert d_t\rVert$。零差向量的 $e_t$ 定義為零。這個相鄰差使用較早句的狀態，首句從零開始。令 $\ell_{tj}=(t-j)/(t-1)$。以下各項均在當句末計算，範圍包含所有 $j<t$。

| 特徵 | 算式 |
| --- | --- |
| 最大詞形重合 | $\max_j a_{tj}$ |
| 平均詞形重合 | $\operatorname{mean}_j a_{tj}$ |
| 詞形加權的相對前文距離 | $\sum_j(\pi_{tj}-u_{tj})\ell_{tj}$ |
| 最大句末更新相似度 | $\max_j e_t^\top e_j$ |
| 詞形加權的句末更新相似度差 | $\sum_j(\pi_{tj}-u_{tj}) e_t^\top e_j$ |
| 詞形加權的全文狀態相似度差 | $\sum_j(\pi_{tj}-u_{tj}) v_t^\top v_j$ |
| 當句前後的表徵更新幅度 | $\lVert d_t\rVert$ |

所有詞數統計與取回權重隨已讀範圍改變。這些特徵用已出現的詞形和模型表徵描述文字關聯。語意相似度屬模型的內部表徵量，資料的觀測是逐句真人按鍵。每篇預測只讀自己，配對另一版、目標句位置和真人反應只供訓練及評分。

## 共用訓練與驗收

兩個讀出完整沿用前一輪的條件概似、逐句風險集概似、四類位置交叉熵及 0.10 ridge。七特徵與十四特徵各自重建所有內層訓練方向和特徵尺度，各用相同 ${0,0.25,1,4}$ 網格及規則選兩個損失權重，再以 20 組外層故事的留出預測評分。七特徵讀出須重現前次封存的預測。前次等權與原完整前綴比較也沿用封存預測。 [固定損失、家族留出與選模規則](frick-conditional-protocol.md)

主要驗收沿用目標句效應方向、與真人幅度 ±10 個百分點等效、兩條件提前回報偏差各自 ±10 個百分點等效，以及對兩個原比較的整篇 NLL 非劣界 +0.05 nats／篇。新增對照報十四特徵相對七特徵的目標句絕對效應誤差與整篇 NLL。欲判定新增特徵改善，前者的減少量須有完整正值的 95% 區間，後者相對七特徵的差值區間上界須低於 +0.05 nats／篇。沿用 10,000 次讀者及故事交叉重抽樣，種子 735972。另報每種前文下完整的首次回報位置分布，與兩個模型的特徵及預測前綴一致性。
