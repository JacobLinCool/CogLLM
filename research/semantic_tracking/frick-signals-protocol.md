# Qwen 的逐詞預期與前文注意力能否改善首次矛盾回報預測

Frick 與 Schüler 的純文字實驗每次呈現一個完整句子，讀者判斷該句是否與前文矛盾。每個故事的兩個版本共用同一句目標句，只改動較早的一句。既有七特徵讀出低估目標句的首次回報差。本對照檢查加入同一 Qwen 前向中可計算的逐 token 預測分布和注意力統計，是否改善**句末**首次回報率和整篇位置分布。 [原研究實驗一](https://doi.org/10.3758/s13421-026-01900-7) · [原始配對與端點](frick-consistency-source.md) · [七特徵留出結果](frick-conditional-results.md)

## 模型輸入及訊號

使用原 40 份完整德文故事、相同 Qwen3.5-2B checkpoint、tokenizer 與 FP32 SDPA 推論。研究者指定的目標句、改動位置、前文條件和真人資料不進擷取封包。每份正文做一次因果前向，另以縮短前綴、替換後綴及前綴一致性對照查核。每個 token 對齊原文半開 Unicode 座標。各原始句界以先前封存的 tokenizer 證書定義，並在 GPU 端再核對。

對位置 $t$ 的原文 token，從第 $t-1$ 個位置的最後層狀態，乘以模型共用的輸入和輸出詞表權重。保留當前 token 的 surprisal 及整個預測分布的 Shannon entropy，單位都是 nats。第一個 token 無歷史預測，儲存零值並排除於預測量的彙整。詞表投影分塊計算，模型不生成文字。

在最後一個 full-attention 層，以相同前向的 query 和 key 重建八個 head 的因果 softmax，對 head 取平均。對各 query 位置，先將早於當句的 attention 質量相加，再減去可見前文 token 的均勻質量。另一個特徵在各已讀句分別計算實際質量減該句均勻質量，取最大的帶符號差。每個均勻項的分母都是該位置可見的 token 數，包含當前 token。沒有前句時，兩項均為零。保留各句末狀態以核對原擷取。 [注意力及輸出定義](../mathematical-formulation.md#2-一次因果前向運算)

## 讀出及驗收

每句的五項加入特徵是當句 surprisal 的平均和最大值、預測 entropy 的平均、兩項 attention 差量各自的平均。主組將五項全數加到原七特徵。分別只加三項詞表訊號或兩項 attention 訊號作拆解。各組保留原先的配對表徵方向、訓練材料、損失及權重選擇規則。沿用 20 個外層故事折及固定四個內層材料折。每折用自己的訓練資料正規化特徵和選擇權重。兩版一同留出。做留出預測時每篇只看自己的正文前綴。

主組相對原七特徵的目標句首次回報差絕對誤差必須下降，讀者與故事交叉重抽的改善 95% 區間下界須大於零。全篇首次回報 NLL 的相對增加量區間上界須小於 0.05 nats／篇。另沿用目標效果幅度及提前回報的兩條件 ±10 個百分點門檻。10,000 次交叉重抽沿用種子 735972。比較三組新特徵時，拆解結果單獨報告。 [配對擬合及原門檻](frick-conditional-protocol.md)

這是既有故事家族的回溯比較。模型可在每個 token 產生訊號，這筆真人資料的回報仍只有句末。如果某個句子出現較高的 surprisal，研究觀測可以驗證同句回報的機率差，還無法辨識讀者究竟在哪個詞首次意識到矛盾。
