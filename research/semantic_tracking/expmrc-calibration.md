# ExpMRC 到達機率的回溯校準規格

本實驗檢查同一個單調轉換能否降低已封存的逐 token 讀出在 ExpMRC 的絕對機率誤差，並保留同文同停點的題目順位。使用已完成評分的 ExpMRC 主分析集合。保留 165 篇、555 題及 1,110 份人工參考，並沿用兩篇 RACE 關聯材料的排除。兩個固定對照為原逐 token 讀出（`token_rank`）與原題幹讀出（`question_only`）。 [原評分規格](expmrc-transfer.md) · [封存預測](../results/expmrc-transfer-l4/seal.json)

將模型在停點 $t$ 的累計強度記為 $A_t=-\log S_t$，其中 $S_t$ 是完整證據尚未出現的預測機率。只擬合全域兩參數轉換 $A'_t=\exp(a)A_t^b$，$b>0$ 且 $A'_0=0$。從相鄰停點強度差還原離散條件到達機率。其依據是該停點已累積的模型輸出。相同文章的任兩題使用同一組轉換參數，同停點順位應保留。

先以字串 `expmrc-calibration-v1:` 加文章 ID 的 SHA-256 排序，依順位循環指派五折。每折的兩參數只由其餘四折估計。擬合最小化兩份原始參考終點等權的平均區間 NLL，L-BFGS-B 自 $(a,\log b)=(0,0)$ 起始，$a$ 限於 $[-12,12]$，$b$ 限於 $[1/4,4]$，`maxiter=300`、`ftol=1e-12`、`gtol=1e-8`。沒有依文章長度、題型或尾文進行額外調整。

主要比較為逐題區間 NLL 的兩個配對差，校準後逐 token 減原逐 token 及校準後逐 token 減原題幹。次要比較使用相同的逐題累計 Brier，並檢查第一停點平均預測機率與參考出現比例。NLL 以 nats 計，Brier 介於 0 與 1，兩者皆以 0 為佳。以文章為單位重抽樣 10,000 次，沿用 ExpMRC 評分的兩側 95% 描述區間，將已擬合的折外預測視為固定。另在 698 組原期定配對核對同一停點順位與勝負平手。

分析規格寫於此次運算前，既有 ExpMRC 真人標註已用於前次轉移評分。本次提供文章分組的回溯折外估計，進一步的機率驗收仍需要新文章與真人觀測。
