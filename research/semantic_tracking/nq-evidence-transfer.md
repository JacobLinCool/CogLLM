# 證據到達讀出的 Natural Questions 獨立驗收

固定 Natural Questions 官方 validation 的 Hugging Face 發布版本 `e8103d566bef4154c2c12b17c6095ec5275840cc`。從前次核對排除 IIRC 原文和可見連結標題的無標註索引，按 `cogllm-nq-v1:` 加 Wikipedia revision ID 的 SHA-256 排序，取前 72 個頁面版本。逐一確認同一版本的各題共享原文及來源 token，保留真正異題的頁面。模型使用原文件中非 HTML token 的文字順序及和 ExpMRC 相同的分句與停點認證。完整文章須符合共用介面的 16,000 Unicode 字元限制，且不超過 6,144 個 Qwen tokens。所有文章及題幹預算上限為 120,000 tokens，依固定順序保留完整合格材料，遇下一組超出總預算即停止。資料或停點不合格均列明，這些篩選依賴原文和題幹。 [無標註索引查核](nq-evidence-source-audit.md) · [官方資料](https://ai.google.com/research/NaturalQuestions/download)

四組模型完全沿用 QASPER 的固定頭和 ExpMRC 擬合後封存的校準參數。Qwen3.5-2B FP32 對每篇正文一次因果前向，共用該篇的正文狀態。指定題幹做各自的編碼，再使用封存讀出。原始預測先封存，真人標註留在評分端。主要端點是完整的人工長答案支援區段何時可見，五份標註各自等權。未選出足夠支援區段的標註以觀測窗之後的機率評分。正例以原始 token 和 byte 坐標核對，再放入首個包含完整區段的已對齊停點。座標無法對齊時，記錄原因和分母。 [原量測](https://aclanthology.org/Q19-1026/) · [封存校準](evidence-calibration-comparison-results.md)

- 主要驗收為校準後逐 token 減校準後題幹的逐題區間 NLL，95% 配對文章群組區間上界須低於零。亦比較校準後段落和位置、各組累計 Brier 及首停點機率，並重報原始未校準分數。
- 同文同停點的比較至少需要早、晚各兩份非空參考，所有非空參考區段嚴格分開。只在所有早期區段完整到達、晚期區段尚未開始的已認證停點比較。以早期問題的累計強度較高為勝，平手計半。相對同樣校準的題幹讀出報文章群組配對差。沒有可配對的文件仍計入有效區間評分。
- 由正規化 Wikipedia 標題分群，保留同文章的題目和所有相關修訂於同一群。沿用前次已固定的 10,000 次群組重抽樣與種子。含表格或清單的長答案維持其原始座標對應，但另報文本表示的適用範圍。此評估檢驗給定題幹時的參考證據到達。
