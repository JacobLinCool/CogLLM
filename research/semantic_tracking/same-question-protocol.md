# 同一疑問的解答線索驗收

這一輪檢驗已知有兩個問題時，讀到線索後是否只降低得到答案的那個問題的未解分數。一次凍結的 Qwen3.5-2B 因果前向取得原生 token 表徵，讀出同時追蹤兩個已在正文或題幹中可見的問題。測試候選以原文區段給定，未測自動發現疑問。回答、測試條件與評分位置留在本機評分檔。

## 三個證據層級

1. **真人首次答對。** ACT 有同一讀者對同一個指定目標，按原作者固定次序逐一看到線索詞，並在首度答對時停止。以前封存的 Qwen 前向重擬合，維持原來五個詞表留出折。用二項風險集合的逐步似然，預先以只看第幾步、加文字長度及加三項因果 Qwen 狀態變化比較。主要是完整 15 步（含右設限）的留出 NLL，附同經過步數和同新增 token 長度的配對排序。兩種續文由同一讀者看到的因果比較未在此發生。 [來源與觀測窗](act-source.md)
2. **人標文本證據。** ExpMRC 保留同一篇文章中參考證據在前後兩個互不相交區域的兩題，沿用各文章在上輪的分割。用同一個已讀內容、同一個 token 停點，比較人標支持屬於前一題還是後一題。兩題原文同時可在榜首呈現，置於文章前，順序按無關答案時間的雜湊固定。此讀出量測人標可見證據，問題呈現與其逐詞認知狀態未於原實驗觀測。 [既有證據稽核](expmrc-transfer.md)
3. **等長雙問題續文。** 自編題材明示兩個尚未回答的問題。每個前文接 A 或 B 的續文，兩續文用固定 tokenizer 對齊相同前綴和等長解答線索。對 A，回答 B 的續文是無解答對照，對 B 則對調。題材成簇留出。帶入模型的只有兩問題都已可見的正文和其中一種續文。作者標註及配對兩種續文檢驗模型行為。

## 讀出與驗收

在每個已知問題的觀測時間窗開始時，未解質量設定為 1。讀到第 $t$ 個 token，條件解除率為 $h_{r,t}$，未解量為

$$
S_{r,t}=\prod_{j \le t}(1-h_{r,j}).
$$

訓練以窗內的首次事件機率及右設限的存續機率擬合，未到評分窗的時間只在可確認的前綴範圍才納入。某個線索的起訖固定於提取表徵前，訓練及留出的切分皆按題材或來源文章，課程外的錨點由給定的可見問題決定。模型不能查閱此問題的參考解答。

使用同一批表徵，分別比較經過步數、步數加當下 Qwen 表徵、步數加問題與文字的詞面重疊、以及加上已知問題與當下 Qwen 表徵的交互特徵。純步數及當下 Qwen 的讀出不接收問題身分，同一版本同一位置的兩題因此應得相同分數。問題交互讀出讓相同 token 可對兩個舊問題產生不同解除率。

以答案窗的下降差驗收。每個自編家族在兩條續文各算「有答案的問題減另一個問題」的下降幅度，再平均。ExpMRC 採用早到的人標支持窗，對比同一窗口的兩問題，另核對後到問題自己的支持窗供訓練。只用步數的保留量受窗長所影響，配對比較對兩題使用同一步數和相同窗。另報首個分差位置、解答窗前的過早下降，和有解及無解的留出 NLL。材料等權，95% 配對重抽樣以題材或文章為單位。原文共享前綴時，比較對應 token ID、原文字元座標與曲線數值。

在 Colab L4 對新輸入各擷取一次原生 token 表徵。所有計分組共用封存表徵，讀出在 CPU 擬合。新擷取採用和未解曲線第一輪相同的 160 維固定投影、FP32 官方權重及因果驗收。用單張 L4，依舊使用 24 分鐘的含清理硬上限。ACT 讀出直接沿用先前封存的前向表徵。
