# 逐 token 未解疑問曲線的首輪對照

固定的 Qwen3.5-2B 官方快照在 Colab L4 以 FP32 對每個原文做一次正式因果前向。保存每個原生 token 的字元座標及最後層 160 維固定亂數投影。截短或後文替換另作因果驗收。GPU 封包含正文與不含條件資訊的 ID，標註、切分與控制條件留在本機。各訓練條件共用一次擷取。用同一張 L4，配置、下載和釋放共以 24 分鐘為上限。讀出擬合用封存表徵在 CPU 執行。

## 三種觀測各自計分

主要監督是人標的 SCARECROW 矛盾圈選涵蓋與 ExpMRC 文字證據位置。Blott 2023 有可核對的句末辨義反應，作第三種觀測。SCARECROW 是事後圈選，模型的開啟分數是以這個訊號訓練的疑問候選。ExpMRC 的答案範圍由真人標註，是文字證據的時間代理。用至少兩個不同題幹內容詞與先前原文的吻合區段作訓練錨點。正文測試時不輸入題目、答案、真人錨點或人工分歧位置。Blott 的句末反應只用於自己的二元讀出。ExpMRC 公開 dev 按文章雜湊固定 70／30，屬回溯留出。原定的 QASPER 在長度及可對齊錨點的預檢各只有一條訓練與留出例，留作資料統計。所有子集的原始分割、觀測類型及缺失遮罩列在資料收據。

每個資料集除以各自有效的觀測權重。矛盾圈選和句末反應用二元負對數似然。把證據範圍投影到原文 token，以首次提取證據機率的區間質量之負對數擬合，並保留錨點已可見的條件。第一個區間質量事件前的每步存續機率與區間內至少發生一次的機率合乘。所估端點是標註證據，不能從該似然推回真人主觀解開的時間。

## 讀出與匹配條件

每個觀測頭從相同的 Qwen 投影計算一層寬度 24 的 tanh adapter。頭可有固定特徵和線性跳接。證據頭另用逐位置對照已讀錨點的向量餘弦及經過的 token 數。對照 A 每個任務擬合獨立 adapter，對照 B 共用 adapter、讀出頭分開，另報 B 只共享圈選與證據兩頭的消融。初值使用 21、47、101，正則化、主要任務資料與最佳化預算一致。報各端點留出負對數似然，以材料家族配對重抽樣。訓練分割以來源文章為群，留出預測以已封存的權重計算。先前已看過的原留出屬回溯比較。

首輪的曲線以每個有字元的 token 作疑問候選位置，以只依賴已讀內容的圈選頭提供開啟質量。相鄰候選共享有限區間的開啟機率，避免把連續圈選的每個 token 全權計入。每個候選之後的未解質量由證據頭的逐位置存續機率累乘，逐位置加總得到曲線。由於候選是疑問位置代理，存在多候選同題，曲線報模型未解質量。鏡像重疊、題目識別及真人量尺留給後續檢驗。這一版採用第一次結束後維持結束的簡化狀態圖。

## 同前文的三種續文

固定 12 個題材，每題三種寫法。段內解開版與延遲版互換一模一樣的解答句及維持疑問的句子。突然換題版與延遲版在段落分隔前共用原文，後面才換題。所有題材獨立於人類訓練集，控制材料與事件座標在首次模型輸出前固定並留雜湊。控制文字不作訓練，也無真人資料。

前綴相同的 token 座標及分數須相同，在分歧前不應出現由續文造成的曲線差。另計共同前文中已開啟候選截至每個時點的剩餘質量，以排除換題後新增的候選。主要比較段末早解與延遲、共同第二段結尾之後突然換題與延遲解開、最接近解答或轉換的窗口。各自報方向、大小、配對區間，以及位置是否符合事前指定線索範圍。轉換位置以控制原文作參照，這輪曲線直接驗收舊疑問是否仍在，獨立的真人轉場機率屬下一個端點。
