# 未解疑問續文對照

12 個自編英文題材各有三個版本，共 36 篇。敘事、實驗紀錄和作業公告各四個題材。每篇五句，第三句後分段。前兩句建立相同的未解問題。早解版與延後解答版只互換第三句與第五句，解答句逐字相同，第四句保留與原疑問相關且未給答案的內容。突兀轉場版與延後解答版共用首段和段落分隔，下一句改談不相干的主題。這些材料是預先設計的模型行為對照，沒有真人評分。 [原文與建置](load_curve_controls.py)

```sh
python3 -m research.semantic_tracking.load_curve_controls --output /path/to/controls
```

| 檔案 | 用途 |
| --- | --- |
| `inputs.jsonl` | 前向只讀 `id` 與原文 `text`。原文含實際分段。 |
| `controls.jsonl` | 封存預測後以 `id` 對齊。含題材、版本、疑問說明及預先指定的字元位置。 |

位置是 Python Unicode 字元索引。片語使用半開區間 `[start, end)`。`opening` 為引出疑問的片語，`cue` 是提供解答的線索，`shift` 是另一主題的提示，後兩者依版本可為空。`common_prefix_end` 為第二句末端，`paragraph_end` 為第三句末端，`continuation_start` 為下一段第一字前，含此前兩個換行。`before_cue_end` 停在線索前最後的非空白字元後。`sentence_ends` 保存五個句末，`late_comparison_end` 等於第五句末。經固定 Qwen tokenizer 核對，所有句末、分段、線索前後及轉場片語末端都可精確對齊。片語起點可能切入包含左側空白的 token，前綴停點須使用已核對的字元終點。 [對照評分](load_curve_control_score.py)

## 比較定義

逐方法報全部 token 的負荷分數。若有相同前綴中已出現疑問的存續質量，一併以 `cohort` 報告。全部分數可檢查轉場後的整體高低。要解讀為原先疑問仍未解，須有固定疑問群 `cohort` 的結果。相同前綴上的 token ID 及位置須完全一致，數值允許絕對差 `1e-6` 加相對差 `1e-5`。各題材比早解對另外兩版的首兩句，以及延後對突兀版的整個首段和換行。技術核對未過時，該方法的效果門檻皆視為未通過。

| 比較 | 預先指定的差值 |
| --- | --- |
| 段末是否仍未解 | 第三句末的延後解答版減早解版。 |
| 後文解答與突兀轉場 | 第五句末的突兀轉場版減延後解答版。 |
| 下降是否出現在解答線索 | 延後解答版在第五句解答線索的降幅，減同篇第四句結尾等多 token 的降幅。第四句仍圍繞原疑問。 |
| 遇到突兀轉場是否仍保留未解疑問 | 第四句自轉場片語末端至句末的最低值，減第三句末值的 80%。各題材的第三句末值須大於零。 |

各差值在題材內配對，以題材為單位等權重抽樣 10,000 次。95% 百分位區間的下界須高於零。80% 是此對照採用的檢驗門檻。另報各成對曲線首個超過數值容許誤差的位置與線索的相對距離。兩條續文變更後的同序號 token 可以是不同詞，這項距離用來描述何時發生分歧。這組刺激和重抽樣只衡量自編題材上的行為。 [比較實作](load_curve_control_score.py)

## 既有真人資料可核對的範圍

- **Onea 等人。** 原工作簿的開啟與解答為不同標註者讀完後核對的原文行。讀者的逐詞懸疑分開量測，同屏可先看到多行。座標可用來核對疑問間的並行關係，故事譯本的模型重用權仍待確認。 [研究 §§3–4](https://doi.org/10.1017/langcog.2025.10057) · [資料](https://osf.io/m524v/)
- **Frick 與 Schüler。** 同一位讀者逐句判斷目前句和上文是否一致。下句回答一致只評下句。完整軌跡可核對首次句級回報，工作表及刺激的重用條件待確認。 [實驗 1](https://doi.org/10.3758/s13421-026-01900-7) · [既有來源核對](frick-consistency-source.md)
- **Blott 等人。** CC BY 4.0 的材料與作答可核對詞義重解的句末接受度。解答線索有原文座標，真人沒有在前後各評一次，也沒有同題存續曲線。這些材料先前已用於本專案評估。 [實驗 1](https://doi.org/10.1080/23273798.2022.2159992) · [既有來源核對](blott-format-source.md)
