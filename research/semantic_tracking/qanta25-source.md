# QANTA25 human buzz source audit

QANTA25 contains 193 human buzzes that align to the published clue boundaries of English quizbowl questions, including 155 correct responses. The records support an analysis of **where and whether a recorded human buzz was correct in mixed human–AI competition**. The game summaries omit question-by-question presentation histories, and the tournament protocol combined live speech with on-screen clue presentation. These design features define the population and risk set to which the observed response positions apply. [Gor et al., §2.1 and Appendix H](https://aclanthology.org/2026.findings-acl.422/) · [Published dataset, revision 86abe068](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387)

## Released observations and coordinates

We read all 140 tossup rows and 827 buzz rows from the author's Hugging Face release. The tossup table has `qid`, source `question`, `clue_spans`, `clue_token_indices` and `run_indices`. The response table has `response_id`, `qid`, `game_id`, `question_number`, `buzz_number`, pseudonymous player and team fields, `buzz_pos`, `buzz_clue_index`, `correct`, and the activity and muting state at the logged event. All response IDs are unique and all responses join to one question by `qid`. Every published question has a first clue starting at character zero and a final clue ending at the Python Unicode length of the question. [Tossup materials](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387/tossup_questions) · [Response records](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387/tossup_responses)

A buzz position maps to the earliest published clue whose token boundary equals or exceeds that position. We require a positive position within the published terminal token boundary and agreement with the recorded one-based clue index. This check passes for 825 of 827 events. The two exceptions are human buzzes in the final clue, one correct and one incorrect. Each position is one token beyond its published source question, and each equals the terminal token count in its own event metadata. We retain the discrepancy in the audit and exclude these two buzzes from exact position analyses. Among the 195 human buzzes there are 156 correct and 39 incorrect responses. The exact coordinate subset has 155 correct and 38 incorrect responses, spanning 21 pseudonymous human players, 28 games and 104 questions. [Response records](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387/tossup_responses) · [Aggregate audit](../results/qanta25-source-audit.json)

The published clue spans give character endpoints for the corresponding source clues. The question table's token indices differ from whitespace word counts on all 140 questions. We verified the clue bins using the author's token boundaries. An analysis that uses the precise character of a buzz within a clue would also need the original token-to-character map. [Tossup materials](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387/tossup_questions) · [Aggregate audit](../results/qanta25-source-audit.json)

## Presentation and the observed risk set

The tournament used a live moderator who read questions aloud. The application also provided real-time clue-by-clue question display, and the moderators shared the application screen in online sessions. Humans and AI systems could buzz, and teams could mute AI teammates. The human observations are competitive buzz decisions with contemporaneous text and speech. They do not establish the onset of uncertainty or resolution during ordinary silent reading. The separate bonus task compares initial human and final answers after AI assistance, with the same question. That transition involves added suggestions rather than progressively presented source clues. [Original procedure §2.1–2.2 and Appendix H.2–H.3](https://aclanthology.org/2026.findings-acl.422.pdf)

The response table has 827 events across 636 observed game–question pairs and 32 games. Each observed game joins to a single packet with 20 released questions. Thirty games log buzzes on all 20, one on 19, and one on 17. Four potential packet entries have no response record. The released 32-row games table contains teams, rosters and scores without presentation or no-buzz events, so it cannot establish whether the missing questions were shown. We leave those four entries unobserved. The event table also omits never-buzzing player-by-question records and the full sequence of each player's opportunity to buzz. We use the observed human buzzes as the denominator for conditional correctness, and the coordinate-verified subset for location analyses. [Games table](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata/tree/86abe0689c7560ccaa685723b926bbc38fa3c387/games) · [Aggregate audit](../results/qanta25-source-audit.json)

All 827 buzzer-event rosters contain three or four AI players. The 13 events with zero active AI occur within those mixed rosters. Muting and prior game events can change which participants remain active. These moments do not identify an independently assigned human-only condition, and they cannot supply a human-only exposure denominator. [Muting design](https://aclanthology.org/2026.findings-acl.422.pdf) · [Aggregate audit](../results/qanta25-source-audit.json)

## Provenance and written alternative

The pinned Hugging Face dataset card declares no data license. The paper describes release of anonymized gameplay. The audit receipt records the revision and hashes of the three downloaded Parquet files. We checked the rows through the release's Hugging Face Dataset Viewer and recorded hashes of its returned records separately. We retained the raw source material in the local cache for verification. [Dataset card](https://huggingface.co/datasets/qanta-challenge/qanta25-gamedata) · [Data release, Appendix H.3](https://aclanthology.org/2026.findings-acl.422.pdf)

The QANTA project also links an older Protobowl gameplay file, which would offer a written browser setting. The official S3 object returned HTTP 404, and a checked institutional mirror returned HTTP 403. The public author parser identifies question text, a question key, guesses, rulings, user key and elapsed/remaining times in the original log. Its position feature is computed from times. We could not inspect original word-display events or independently recover their exact position and no-buzz inventory. The separate MIT-licensed CAIMIRA release provides questions and progressive clue text without human response rows in either configuration. [QANTA gameplay link](https://sites.google.com/view/qanta/resources) · [Author parser](https://github.com/Pinafore/qb/blob/a5216348fadc0f2bee7d0d7919068a34a311e2cf/qanta/datasets/protobowl.py) · [CAIMIRA text release](https://huggingface.co/datasets/mgor/protobowl-11-13)

The 2018 ACF Regionals open-data archive is a separate oral competition source with an ODbL 1.0 release. Its downloaded tossup TSV has 16,854 buzz rows and 15,336 numeric buzz locations. An inspected annotated packet contains numbered word tags for canonical English questions. A complete event-to-word join and the spoken delivery history remain unverified here. [Pinned open-data archive](https://github.com/quizbowl/open-data/tree/5d86399bda90b6d7af514b6d035419016816f378)
