# Core Vocabulary marginal first-correct protocol

The endpoint is the first exposure at which a reader correctly guesses the masked target in a cumulative six-sentence task. Each released trial identifies the target, terminal exposure and correctness. The release supplies the pool of possible sentences separately from the reader's realized sequence. We evaluate prediction of the distribution over exposure ordinals for a target under the author's cue-sampling design. The protocol needs no new participants. [Experiment 1](https://doi.org/10.1525/collabra.160142) · [Source audit](core-vocabulary-source.md)

## Material split and sampled inputs

The author assigned six different targets from each of four 24-target conditions to each reader. Given a target, the client independently chose one of six sentences from each of six bins and presented the bins in ascending predictability. The potential cue paths for one target have equal probability and are distinct from the reader's previous guesses, trial order and feedback. Readers in the analysis passed the author's catch-trial rule. The planned comparison uses the design distribution over potential texts and the observed outcomes of that screened cohort. It cannot test dependence of catch-trial retention on exposure to particular cues. [Procedure](https://doi.org/10.1525/collabra.160142) · [Pinned author sampling code](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/main.js#L19-L62)

We freeze the target split from the author's released target table, which contains no accuracy or response records. Within each of the four author conditions, we order target-family IDs by SHA-256 of the fixed split seed and ID. The first 16 targets train the readout and the last eight evaluate it. The same target and all its possible cue paths stay together. This gives 64 training and 32 held-out targets. Readers can contribute outcomes to both word sets, so the split tests transfer across targets in this cohort. Neither the target key nor the split role appears in the model input. [Grade-free target list, revision 1](https://osf.io/download/rqz6h/?revision=1) · [Split and evaluation implementation](core_vocabulary_marginal_score.py)

The pilot uses eight distinct equiprobable paths drawn without replacement independently for each target by a fixed, outcome-blind hash sampler. The eight paths approximate the design average over 46,656 possible paths per target. They are independent of each reader's original assignment and are never matched to reader records. The model sees each masked sentence as an original line of text and reads six causal sentence-end states in one forward pass per path. The input contains only the text, its opaque ID and stop coordinates. No labels, guess history or answer tokens are sent. This is a text-only assay of an explicit lexical guessing task at sentence exposures. ## Distribution and score

Let $h_{wdj}$ be the predicted conditional probability of the first accepted guess at exposure $j$ for target family $w$ and cue path $d$, given failure through $j-1$. Each path supplies six finite hazard logits. We score seven mutually exclusive outcomes. For $j=1,\ldots,6$, $p_{wdj}=h_{wdj}\prod_{i<j}(1-h_{wdi})$. The unresolved outcome has mass $p_{wd7}=\prod_{i=1}^{6}(1-h_{wdi})$. The mixture is $\bar p_{wj}=\tfrac18\sum_{d=1}^{8}p_{wdj}$. This order of operations accounts for changes in the composition of the population still at risk. For example, paths with higher first-exposure success contribute fewer readers to the second-exposure risk set. A hazard for the mixture, if reported, divides the mixed event mass by the mixed survival immediately before that exposure.

Each released row with `correct == 1` enters the event count at `guesses`. A row with `correct == 0` enters outcome 7 and must end at exposure 6. The scorer aggregates counts $n_{wj}$ by target. With $N_w=\sum_j n_{wj}$ and split $W$, the score is

```math
-\frac{1}{|W|}\sum_{w\in W}\sum_{j=1}^{7}\frac{n_{wj}}{N_w}\log \bar p_{wj}.
```

Lower log score indicates higher assigned probability for observed outcomes. Units are nats per trial under equal target weights. Each target contributes its average trial score, so targets with more historical reader trials receive equal weight. A perfect categorical forecast scores 0 nats and a seven-way uniform forecast scores $\log 7$ nats. The scorer uses log survival and log-sum-exp to retain small event and censoring probabilities. ## Baseline and model comparison

The position-only baseline fits one common seven-outcome distribution by averaging the within-target empirical outcome proportions over the 64 training targets. This is the maximum-likelihood position-only model for the specified equal-target objective. Its hazard at each ordinal divides its event mass by its remaining mass. We fit it on training counts before aggregating the held-out scoring counts. Its features consist of the current exposure ordinal. It provides the same predictions for every text and reader.

Any subsequent material-based readout uses the same split, sampled texts and score. Fits use training-target responses only. A surface comparator can use visible cues such as ordinal, current and cumulative word count. It supplies a matched comparison for a readout that adds the causal CogLLM state. A downstream comparison should compute paired score differences over held-out targets, preserve the four target conditions when resampling materials, and account for repeated readers when reporting intervals. Estimates from eight sampled paths describe this pilot mixture. A claim about the full cue distribution needs a sensitivity check across independently seeded path panels.

The existing public release audit had already enumerated overall Experiment 1 hazard counts. We fixed this deterministic material split and scoring rule before computing its target-level baseline, and no model forecasts were evaluated in the baseline run. The aggregate historical findings therefore motivated this assay. The held-out split constrains fitting within this assay.
