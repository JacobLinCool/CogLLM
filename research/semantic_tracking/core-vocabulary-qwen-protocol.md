# Qwen 前綴表徵與逐句首次答對的群體分布

Core Vocabulary 的公開試次表記錄第幾次曝光首次答對，缺少讀者每次實際看到的線索 ID。本實驗用已封存的 768 條可能路徑，檢驗凍結 Qwen3.5-2B 的句末狀態能否改善歷史讀者群的首次答對分布。先用作者的四個條件取固定的 64 個訓練詞與 32 個留出詞。每詞以封存種子抽八條不同路徑。同一讀者可能在兩個材料分割均有答覆，所以主要泛化單位是新目標詞。 [抽樣和端點](core-vocabulary-marginal-protocol.md) · [固定分割](../results/core-vocabulary-marginal-pilot/split.json)

## 特徵與擬合

每條路徑只提供作者的遮蔽正文，使用一次 Qwen 因果前向。同一 Gradio 候選的 IIRC 投影提供六個句末各 128 維狀態。用固定 tokenizer 核對原文座標與六個前綴。讀出只看當下與先前線索。路徑的隱藏目標、條件、真人猜測及其正誤不送入 GPU。

| 讀出 | 可見特徵 |
| --- | --- |
| 步數 | 依訓練目標的經驗分布估計六個步數的條件機率。 |
| 字面 | 六個步數截距、當句和累計空白切詞數的 `log1p`、當句詞形曾在前文出現的比例。 |
| 字面加 Qwen | 相同字面特徵，加上目前句末的 128 維投影狀態。 |

詞形重疊使用 NFKC、casefold 後的 Unicode 英數單位。第一句重疊比例為零。字面變數在訓練路徑及停點上估計均值和標準差。Qwen 向量先做逐列單位正規化，再以訓練均值置中，整個區塊以置中向量 L2 範數的均方根縮放。兩組 logistic hazard 以訓練目標等權擬合，六個步數截距不懲罰，所有特徵係數加固定 0.10 的 ridge。每條路徑先算六個首次答對機率與第六句之後仍未答對的機率，再按目標在八條路徑取平均。損失為真人七類結果在這個混合分布的負對數概似。目標詞組合、係數及超參數均在接合留出標註前固定。 [混合分布的定義](core-vocabulary-marginal-protocol.md#distribution-and-score)

## 留出門檻

主要門檻是字面加 Qwen 的留出 NLL 同時低於步數及字面讀出，且兩個改善的 95% 配對區間下界均大於零。另檢查第一、三、六句的累計首次答對率。模型減真人的 95% 區間須各自完整落在 ±5 個百分點內，判定群體分布的幅度達到實務容許差。每個差值用同一次叢集重抽比較。按四個作者條件分層重抽留出目標，共 10,000 次，種子 735972。若跨讀者和目標的重抽可按發布的去識別讀者鍵重現，併報其區間。只按目標的區間條件於這批讀者。

本實驗使用每個目標的八條可能路徑近似作者的抽樣分布。可驗證跨這些路徑的群體首次答對曲線。因真人的個別路徑缺失，單一原文句子的解除機率仍未獲直接觀測。一至六句的額外文字是固定提示任務的一部分，沒有量測自發疑問何時出現。 [資料欄位及限制](core-vocabulary-source.md)
