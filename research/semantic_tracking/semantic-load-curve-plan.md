# 逐 token 未解語意負荷的訓練與驗收

這一輪要檢驗正文能否提供足夠的訊號，讓 CogLLM 逐位置估計有多少疑問仍未得到解答，以及哪些可見線索使同一疑問解開。人類端點取自公開的既有觀測。預設只輸入正文，讀前背景是可選條件。延續 Qwen3.5-2B 和 Colab L4。整篇一次因果前向後，所有讀出共用這次取得的表徵。

## 曲線與單次前向

令 $h_t=f_\theta(x)_t$ 為讀到第 $t$ 個 token 的因果表徵。先在凍結的 Qwen 上訓練讀出。對每個可區別的疑問候選 $r$，用當時可見的原文區段建立錨點表示，並以 $h_t$ 和該錨點評估疑問在 token $t$ 的狀態轉移。首輪使用尚未出現、已出現且未解、已解三種狀態。暫擱和重開保留在既有狀態層，待有能區分相應狀態的觀測時驗收。

$$
p_{t,r}=p_{0,r}\prod_{j=1}^{t} K_{j,r}, \qquad
L_t=\sum_r p_{t,r}(U).
$$

$K_{j,r}$ 是轉移矩陣，$U$ 表示仍未解。所有可見位置的轉移可同時計算，再用既有矩陣前綴乘積求各 token 的狀態機率，全程無自回歸解碼。首輪的 $L_t$ 是模型在已定義候選範圍內估計的未解疑問個數，每題權重為一。兩個同時存在的疑問可各自更新。讀到換行或段末時，轉移仍依正文及候選狀態決定。詞彙難度、閱讀容易度與懸疑感各自保有原量尺。 [現有狀態掃描與似然重播](question-states-run.md)

錨點分兩組評估。給定當時已出現的真人疑問錨點，檢查該疑問何時解開。正文組則只從當時可見的詞或片語提出候選，獨立評估候選命中及閉合。候選在首次可見時取得穩定識別，同一疑問的重複指向在可判定後去重，同一區段的不同疑問保留各自識別。候選預算按當時前綴決定，正式分數無全文排序的候選裁切。真人錨點和答案範圍保存在評分檔。有限候選的漏失另報，避免把低召回當成低負荷。上升與下降由各題的開啟及解開機率分解，可回指原文區段。

令 $T_r$ 為疑問 $r$ 的首次開啟或解答位置，依資料定義。區間標註以 $-\log\Pr(a<T_r\le b)$ 計分，至最後可觀測位置 $b$ 仍無事件時用 $-\log\Pr(T_r>b)$。缺標保留觀測遮罩，粗粒度的區間保留原長度。所有資料把字元範圍對回 tokenizer，觀測窗邊界需與實際可見前綴核對。本輪的公開觀測尚未在同一名讀者、同一疑問上同時量到逐詞開啟、持續、解開和突然換題。因此主要結論按各端點及原觀測粒度報告。多個事件可在同一位置互相抵銷，驗收保留各題的變化及其總和。

## 換題讀出及對照

曲線估計未解疑問是否仍在。讀到新內容時，另由前綴讀出估計事件或話題是否換了，以及當下內容是否仍接續同一個疑問。斷層候選需同時有前一位置偏高的未解量、當前位置的轉換訊號，以及該疑問缺少當下可見承接。換題前的分數須保持共同前綴一致，即使不同版本會在後文走向不同結果。伏筆回收出現後才可下調同一疑問的未解機率。作者意圖由編輯或讀者結合原文判讀。

把同一前文接到三種事先固定的後文，分別給足解釋、突然轉到別題、承接後延遲解答，用來檢查讀出是否保留問題身份、偵測有證據的轉場位置、只在續文可見後分岔。這些對照的改寫若沒有相配的真人資料，只計入模型行為驗收。在 Frick 比較相同目標句、不同前文的首次回報和效應幅度。用 Hippocorpus 驗有事件無事件的分布及可核對的意外標註。兩者各自提供可否對準句級人類端點的證據。

## 聯合訓練實驗

1. 固定方案後，先以同一批因果表徵做線性或淺層讀出，以及有相同表徵的無追蹤單點頭。曲線狀態組以開題、相關區段和首次解答或存續的監督擬合。位置／題齡、段落結尾、只看局部詞和 surprisal 是位置及表面對照。
2. 同型讀出比較獨立 adapter 和共享 adapter。每個任務保留讀出頭，針對自己的標註、時間窗和量尺算損失。固定每任務的樣本及更新次數、種子、訓練預算和開發搜尋範圍。調整共享容量時，另報參數量並加入匹配對照。先比較語意相關端點，再逐一加 CompLex、PLABA 或正文證據。跨任務的同源文章、近重複、改寫版和不同衍生標註必須落在同一折。既有讀出程式、快取和訓練設計可重用，讀出權重按這次的折各自擬合。只有能核對訓練來源與新留出無重疊的權重可作暖啟動對照。
3. 固定架構後，對有匹配真人條件的資料比較加入配對排序或人體研究效應的可微損失。只用訓練折估計效果方向、幅度和資料權重。初輪使用監督式讀出及區間似然。LoRA 作第二輪架構變因。配對與區間目標可端到端微分，足以直接檢驗首輪假說。

聯合收益逐端點驗收。先前 BSPR／SCARECROW／Onea 的共享組讓 BSPR 的留出 Brier 增加 0.00198，SCARECROW 的改善區間跨零，Onea 解答區間 NLL 略增。Onea 當時只用行與經過時間座標。這是新結構必須超越的先例。 [語意三任務先前結果](../semantic-joint-first-run.md#留出結果) · [可微文獻效應先前結果](../joint-effects-run.md)

## 主要驗收與執行

- **累積。** 在確有觀測的相鄰停點，以配對的未解疑問及開題監督比較上升方向、各題機率或問題數。報首次出現的區間誤差、提前報警率，以及上文區段命中。以能判定同一題身份的標註為主要來源。無真值的句內形狀保留為估計。
- **解開。** 比較同一題正確線索和無關但等長線索，以及兩題同時未解時先解開哪一題。報右設限區間 NLL、已知停點的校準、配對排序與效應幅度。人類證據與同一讀者主觀解開分開評估。
- **轉換。** 報直接可驗證的事件轉換或矛盾首次回報位置、早報率、假警報與效應幅度。對換題仍有未解疑問的複合標記，分別驗收兩個組件和同篇對照。逐 token 的複合標記需要相同位置的真人證據才能作直接效度聲明。
- **一次前向。** 相同前綴的新增／替換後文測試，需使曲線、候選、來源座標和斷點在共享可見位置一致。每篇正文只呼叫一次骨幹。時間及峰值顯存分開記錄骨幹、候選轉移與評分。先以舊特徵做可以重播的對照，新的逐 token 擷取在 L4 進行。

開發資料包含既有已看過的結果。主驗收使用預先封存、未用於設計的材料族，能做時另留研究。共同材料以故事或文章為單位配對重抽樣，有讀者連結時保留相同群組。每一輪先固定主要端點、最低增益和容許退步幅度，再封存預測連接留出標註。段首末差、峰值和下降位置可用於待驗證的效應分析，無預設的段末歸零條件。
