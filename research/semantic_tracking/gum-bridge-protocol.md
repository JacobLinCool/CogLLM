# GUMBridge 跨段前文定位

這個實驗檢驗，讀到一個需要從上文理解的新指涉時，Qwen3.5-2B 的因果表徵能否在已讀文字中找出人工標註的前文位置。例如「門」可以指前段提到的房子的門。GUMBridge 的人工端點是橋接指涉與其前文實體。原資料的讀者未在逐步揭露時回報困難，也無同一疑問的解除紀錄。 [GUMBridge 定義與標註 §3](https://aclanthology.org/2026.lrec-1.543.pdf#page=4) · [前文位置與顯著性的語料分析 §4](https://aclanthology.org/2026.codi-1.7.pdf) · [不限定候選的前文定位](https://aclanthology.org/J18-2002/)

## 材料與可評位置

使用 GUM v12 的 GUMBridge 人工標註，固定為 UD English GUM r2.19。正式評估沿用該版本完整的 `test`，`dev` 供診斷。用忽略 fragment 的發布來源 URL 分組。若出現跨切分同源網址，保留官方測試篇章，其次保留開發篇章，從訓練排除和任一原始留出有同源網址的文章。兩套留出標註在訓練權重封存後才用於評分。主要子集要求新指涉與前文片語各自完全落在可辨識的正文段落內，而且所有可接受前文位置位在更早段落。整篇分割保留同一材料的閱讀順序。無法對齊、與當前段相交、未能確認自然段界的標註各有排除計數。語料來源涵蓋書面原文與口語逐字稿。 [原研究切分及人工標註方式 §3.1](https://aclanthology.org/2026.lrec-1.543.pdf#page=4) · [固定版本格式與授權](https://github.com/UniversalDependencies/UD_English-GUM/tree/e92f501b037ebd38387d7479b99aa2a0c45b779e)

模型輸入只有正文和每個原文詞元的通用讀取座標。GPU 對每篇正文做一次 FP32 因果前向，取凍結 Gradio 候選的骨幹及 IIRC 頭原有的 128 維投影，逐座標輸出單位向量。停點須與獨立編碼同一可見前綴完全一致。真人座標和關係僅在 CPU 擬合與評分時連接。分析將人工標出新指涉的末端，當作從哪裡發出前文定位的控制停點。候選為已讀且完全位於新指涉起點之前的可對齊詞末。評分保留當前段的合格候選，因此跨段的主結果須在全前綴競爭下成立。允許多個人工指涉目標，分數採模型分給任一正確末端的總機率。

## 事先固定的比較

| 讀出 | 可用資訊 |
| --- | --- |
| 距離 | 已讀詞的倒數排名，依距離單調遞減 |
| 字面 | 距離、段距、詞長、開頭大寫、可見前綴詞頻、與新指涉片語的字面重合 |
| 字面與 Qwen | 同一字面特徵，以及新指涉末端與候選詞末的因果向量餘弦 |

兩個擬合讀出皆用相同的條件式 softmax，以文章等權的負對數概似加固定 0.05 L2 懲罰擬合。保留所有在詞元及停點層級完全可對齊的案例。每種方法在同一個案例使用同一批候選。主端點是每篇等權的平均負對數概似，單位為 nats，越低代表給人工標註末端越多機率。驗收要求官方 `test` 至少有 20 篇可評文章，且字面與 Qwen 減去僅有字面的 95% 文章配對 bootstrap 區間上界小於零。第一名是否命中人工位置及平均倒數名次作輔助指標。所有配對區間固定以文章為重抽樣單位。檢查各 split 的精確停點覆蓋、每組候選數和多標註分母。

定位起點在此實驗由評分程式給定。即使主比較通過，也只驗證「讀到這個標註片語後，能否回指人工選定的前文」。例如讀者可能順利連起「門」和「房子」，整段未曾感到困難。這個資料不含可推得主觀卡住時間或疑問解除強度的評分。 [人工標註的分歧與適用範圍 §4](https://aclanthology.org/2026.lrec-1.543.pdf#page=7)
