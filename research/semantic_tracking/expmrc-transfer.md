# ExpMRC RACE+ 的凍結讀出轉移

用 ExpMRC RACE+ 公開開發資料檢驗，先前用學術論文訓練的 QASPER 讀出，能否在英文測驗文章區分同篇的兩個指定問題需要哪段證據。ExpMRC 標註者在全文可見時選足以支持答案的短片段，並由另一組作答者檢查充分性。資料有每題兩個參考片段。主要端點是讀到哪一處時，某一個由人標出的完整片段已經可見。答題者首次認出證據的時點沒有記錄。 [作者版本與 CC BY-SA 4.0](https://ymcui.com/expmrc/) · [原研究 §3](https://doi.org/10.1016/j.heliyon.2022.e09290)

封存 167 篇文本、561 題及 1,122 個參考片段。與本機 QASPER 材料核對未見實質文字重疊，另有兩篇和先前評過的 RACE 材料部分重疊。主要評分排除這兩篇（`0c4f08f3`、`1b332837`），全數另作敏感度分析。推論包只有逐字正文、題幹與識別碼。選項、答案與參考片段留在評分端。沿用 Gradio 候選的凍結 Qwen3.5-2B FP32 因果骨幹，每篇正文前向一次。依已封存的英文 Punkt 分句，在切短後能獨立重現同樣原生 token 的句末讀取狀態，完整篇末作為最後停點。若有句末無法對齊，合併到下個可對齊停點並記錄。使用當段 token 投影與既有的 log-mean-exp 交互。每個已指定題幹另行編碼一次，共用該文章的正文狀態。此實驗採題幹已知的控制設計，估計標註證據在閱讀前綴中的可見性。

沿用 QASPER 已封存的四個讀出及原先的投影、幾何尺度、係數。四組為位置、題幹、段落交互及逐 token 交互。後兩組皆採原實驗加入排序監督的權重。固定檔案 SHA-256 為 `5bf54b491e1d1be375a12fa1e2e1dbc8c5c5127ed242d203465f1c1fee679ec7`。使用同一份狀態與座標重用兩種正文讀出，沒有用 ExpMRC 資料更新權重。 [原 QASPER 讀出與封存](../qasper-factorial-run.md)

每份人類證據以其結束字元對回第一個涵蓋它的停點。兩份參考證據各自計區間 NLL 與逐停點累計 Brier，再給同一題的兩份參考等權。NLL 對被標註區間分到的機率取負對數，0 為最佳。累計 Brier 為已讀到完整證據的機率與二元標註之均方誤差，範圍 0–1、0 為最佳。

同篇配對只用兩個問題的兩份參考證據都能完整排定先後、範圍互斥的情況。比對截點為第一個涵蓋較早問題兩份證據的停點；在此仍須看不到較晚問題任一完整證據。對同一正文及停點比較兩個問題的累計機率，較早者較高得一分，平手半分。用各自與交換的兩套機率分布評分兩題的參考區間，計每對平均的原題減交換題 NLL。以文章群組配對重抽樣 10,000 次，種子 20261121，同一抽樣中保留該文章的題目及配對。報告逐 token 讀出與位置、題幹、段落讀出的差。只有逐 token 的同停點排序改善相對位置與題幹的 95% 配對區間下界皆大於零，且原題減交換題 NLL 的上界小於零，才支持跨語料辨別不同疑問的證據。另報整體區間 NLL、Brier 以及兩份標註的結束位置一致率。
