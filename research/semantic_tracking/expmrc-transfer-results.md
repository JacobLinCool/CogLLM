# ExpMRC 新文章的證據位置留出

**用原 QASPER 權重，逐 token 交互讀出通過跨語料題目特異性的三項順位驗收，絕對到達機率的誤差仍大。** 在 698 組同篇、同停點的題目配對上，逐 token 讀出有 62.3% 的配對把較高累計機率分給證據已完整出現的問題。位置對照全數平手，得分 50.0%；題幹對照為 54.0%。逐 token 讀出相對兩者的增益分別為 +12.32 個百分點（95% 區間 [7.88, 16.82]）及 +8.31 個百分點（[1.25, 15.32]）。原題減同文交換題的區間 NLL 差為 −0.0910 nats（[−0.1050, −0.0771]）。區間以 158 篇文章為群組重抽樣。 [預定規格](expmrc-transfer.md) · [完整評分](../results/expmrc-transfer-l4/scores.json)

| 凍結讀出 | 同停點順位 | 每題區間 NLL（nats） | 累計 Brier |
| --- | ---: | ---: | ---: |
| 位置 | 50.0% | 5.949 | 0.496 |
| 題幹 | 54.0% | 3.196 | 0.194 |
| 段落交互 | 62.6% | 5.116 | 0.449 |
| 逐 token 交互 | 62.3% | 5.090 | 0.450 |

順位越高越好，平手計半。兩項誤差以 165 篇的 555 題計算，皆以 0 為最佳。逐 token 減段落交互的順位差為 −0.29 個百分點，95% 區間 [−1.54, +0.99]。逐 token 報出的第一停點證據可見機率平均為 0.09%，真人參考片段有 4.23% 在此之前已全文出現。這兩個端點共同限制目前的解讀。固定正文時，正確題幹能提高相應證據的排序及分到的機率，但輸出的絕對機率跨語料仍偏離真人標註。 [分項基線、原題與交換題差](../results/expmrc-transfer-l4/scores.json)

主要分析依事先記錄的文字重疊排除兩篇曾部分用於 RACE 評估的文章，共六題。保留全部 167 篇時，逐 token 讀出在 705 組配對得分 62.7%。主要分析的 555 題中，351 題的兩份參考片段原文字元終點相同，518 題落在同一個已驗證停點。終點以標註者在已知題幹、選項與答案後選出的支持片段為準。原研究描述了對片段充分性的再次檢查，公開檔只有選取區段。這項結果支持指定問題下的文字證據排序。閱讀者自己產生疑問和認出答案的確切 token 仍缺直接紀錄。 [原研究 §§3.1–3.2](https://ymcui.com/pdf/expmrc.pdf#page=3) · [材料與重疊查核](../results/expmrc-transfer-l4/assay.json)

在單張 NVIDIA L4 上以同一 Gradio 候選的凍結 Qwen3.5-2B 擷取 167 篇文章、561 個指定題幹及 61,181 個有效 token。每篇正文只做一次主幹前向，四組權重重用正文表徵。3,749 個已驗證停點完整擷取，另有 14 個句界併到下一可對齊停點。12 項因果檢查皆通過，前綴投影狀態的最大相對均方根差小於 0.000003。模型前向與讀出擷取共 27.3 秒，整個 ExpMRC 階段為 77.1 秒，Colab 執行個體已核對釋放。評分重跑逐位元一致，並另以直接連乘存續機率重算四組 NLL 與 Brier。 [前向與座標收據](../results/expmrc-transfer-l4/extraction.json) · [預測封存](../results/expmrc-transfer-l4/seal.json) · [執行與釋放](../results/expmrc-transfer-l4/run-verification.json)
