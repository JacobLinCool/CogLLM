# A discrete human composition choice as a third observation model

This secondary analysis fits models to observed ordering choices. The original wholly independent transfer remains frozen and is evaluated separately. This analysis was specified after the program obtained the 88 randomly displayed source units, before any individual order file was fetched and before native Columbia feature collection completed. No training hyperparameter will be changed after grading. [Original transfer](columbia-order-protocol.md) · [Existing bilingual observation models](discourse-state-readout.md)

In each held event family, train only on the other event families’ observed orders. Group both El Salvador topics together because they share source wording. Remove each event's fixed single-human reference order from all target labels at both fitting and evaluation. At each real choice with at least two possible remaining alternatives, assign conditional softmax probability to each alternative. Minimize negative log probability of the actual choice, divided by the log of the number of alternatives, with each topic, writer within topic and nontrivial position within writer equally weighted. One is the expected score of the uniform probability rule. Keep the same material weighting for held estimates. Fit four prespecified models, conserving a single forward per candidate passage.

1. A target-supervised reference uses eight features, the raw average Qwen word surprisal (higher ease orientation), word TF–IDF similarity, cosine of contextual sentence means and the English source form model. Each has raw and candidate-centered versions. Scale each feature using the unlabeled eligible pairs of the fitting topics. Estimate eight slopes from true composition choices, penalized by 0.01 times half their squared norm.
2. An additional transfer model adds the raw and candidate-centered outputs of each of the frozen bilingual reading and order-augmented models to the same reference. Keep the same slope penalty.
3. The independent native choice model adds an 86-feature direction to the eight reference features. Standardize the native features using the pre-existing English training reference. Subtract the candidate-specific mean across eligible predecessors, then subtract the resulting linear disruption score from the choice logit. Penalize both coefficient vectors as above. This model learns its native direction only from composition choices in the fitting topics.
4. The jointly trained model uses the identical choice predictors. In addition, the same 86 native slopes predict the source English observed boundary marks and source Italian published passage ratings with their existing likelihoods and distinct intercepts. Give each of the three original observation losses one third after normalizing to its own null loss. Use the same slope penalties and Italian scale limits as the original readout, with free source intercepts. No constructed source-order examples are used in this fit. A language pair and a task type are confounded in the two original collections. Extending results across additional domains requires independent data.

Fit with deterministic L-BFGS, verify analytic gradients by central differences, and require maximum absolute projected gradient below 5 × 10⁻⁶. Freeze the improvements in normalized held log loss of (2) over (1) and (4) over (3) as a two-comparison family, giving nominal and simultaneous 95% topic-cluster intervals and exact sign-flip tests across nine clusters. Report mean log loss, within-choice ordering, top-one choices, event-specific scores, calibration scale, training convergence, and all source-only model outcomes. The held-out sample tests transfer to new topics within this group of writers. Individual IDs are not verified across all ten pages. The original published human preference is one observed ordering amongst other acceptable word-identical orders. This test does not measure subjective strain or the quality of a whole scientific paper.
