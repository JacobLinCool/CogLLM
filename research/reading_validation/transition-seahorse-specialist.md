# Comparison with the released SEAHORSE Q1 specialist

Use the authors’ actual mT5-Large Q1 checkpoint, pinned to revision a39a2c372923817c2a857b7953cb10827ec0e810. It was trained across six languages on subjects' scale-specific responses. The published input is “premise: ARTICLE hypothesis: SUMMARY” and 2,048 native input tokens. Use the first decoder step for the two original labels 0 and 1, comparing their log probabilities. No new SEAHORSE article or grade enters the specialist's weights or threshold. Verify each official source article by GEM ID. Check exact whitespace-normalized agreement in every case with a SEAHORSE-released reference summary. Include all test articles with public exact IDs regardless of text score. Preserve the original 2,048-token right truncation and report how often the summary was fully visible. A separate complete-summary sensitivity quantifies this potential disadvantage. The Q1 rater and CogLLM see the summary alone. The specialist has the source text as additional evidence. Primary matched comparisons measure difficult-summary AUROC and within-article concordance on the same definitive votes. Report article-resampled uncertainty on paired differences, as well as rare-negative average precision and log loss with the original two-class normalization. Direct comparison uses official test rows with both predictions, no refit on held data, and no substitution of source text. One encoder pass and a single decoder step for each original document-summary pair suffice. Compare the registered native head, registered lexical/word-probability head and character-plus-native combination, preserving each head's original source calibration.
