# Does a learned conflict signal predict the first reported inconsistency?

A large change in topic can occur without a contradiction. We train a causal readout on explicitly distinguished contradictions, entailments and neutral transitions, then test whether its scores improve predictions of human inconsistency reports. The question is whether incompatible content explains the location and size of a human response beyond sentence position and lexical change.

Use the [authors' XNLI release](https://github.com/facebookresearch/XNLI). Both the English and professionally translated German versions of each pair from the public development partition enter training. Hold 512 pair IDs from the official test partition, selected by a deterministic hash independent of the labels, for an NLI-only check. Exclude any training pairs with a normalized test premise. The two language forms share labels and are evaluated as translations of one unit. Each input contains only the original premise, two newline characters, and its hypothesis. A logistic probe learns contradiction versus the union of entailment and neutral on the frozen Qwen3.5-2B state at the end. Use a fixed ridge penalty 0.02 on mean logistic loss with source-training feature moments. A surface comparator uses the current sentence's words, their length, lexical overlap with the preceding text, and simple negation indicators. The classifier provides a semantic readout. Its labels are human entailment judgments, which differ from online decisions while reading.

Apply the fixed semantic direction at all sentence stops in Frick and Schüler's existing 20 story families. The 1,800 trajectories have already informed historical method design. This is a retrospective, leave-one-story-family-out outcome evaluation. Each fold uses only the other 19 families' response counts to calibrate a conditional first-report probability given no prior report. Compare a position-and-surface model to the same model plus the independently learned conflict score. The primary Frick contrast is paired change in whole-path negative log-likelihood in nats per reader-trial (lower is better, equal weight per story). Also report the inconsistent-minus-consistent first-report probability at the identical target sentence, its signed error against human percentage points, and premature first-report probabilities in both conditions. The readout runs at every observable sentence regardless of the target annotation. Story condition and target position are available only at scoring. Position and lexical features include the count of earlier words, sentence length, and overlap with earlier text. Fit the existing regularized causal hazard comparator identically for both arms. Report material-family bootstrap intervals and distinguish them from new population or study uncertainty.

If the independent [CoheSentia](https://aclanthology.org/2023.emnlp-main.324/) release includes incremental sentence annotations and reason codes distinguishing contradiction with prior text, also test the frozen XNLI conflict score on that specific reason against all determinate negatives. Report prevalence, average precision, AUROC and whole-document paired intervals against the XNLI surface comparator, with real-world knowledge codes analyzed separately. Use the human categories as supplied. If reason codes are only recorded after full documents, describe the endpoint accordingly. Exceptionally sparse categories will be reported descriptively with their counts. A passage which changes topic naturally need not contain an inconsistent statement. These results concern the specified type of coherence failure.

Neither XNLI accuracy nor a successful Frick sentence-level result identifies the token at which a reader first noticed the inconsistency. The selected Gradio curve, the new local-difficulty endpoint, and this conflict readout have distinct interpretations. All use a single causal backbone pass. We fixed the specification before producing new conflict scores on any human study.
