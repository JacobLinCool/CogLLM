# Does a later causal explanation selectively update its earlier statement?

In an earlier diagnostic, a question-specific matching readout chose both supporting paragraphs on nine of eleven new QASPER papers. It selected the correct earlier issue on neither complete pair of branches in eight authored two-issue families. Half of its sixteen branches had a positive sham-adjusted preference. Only one produced the prespecified 0.05 increase compared with the matched sham at the decisive cue. Many of these phrases share little vocabulary with their explanations. We will test a different supervision target: human judgments about which earlier event has a plausible causal connection to an arriving event.

## Sources and unit of observation

We train on the public e-CARE training release. We select at most 10,000 original items by a fixed hash; rank or polarity never affects selection. The official e-CARE development observations are reserved for internal evaluation. We use the public COPA development and test sources as independent cohorts, seal forecasts on both, and score the official COPA test once. No COPA response enters fitting or calibration. These sources contain human-authored reference answers for causal plausibility. They do not contain individual time-resolved reports of confusion. The original author's requested cause/effect direction is retained for separate scoring. The plain-prose model sees only statements in reading order. [e-CARE](https://aclanthology.org/2022.acl-long.33/) · [e-CARE data and license](https://scir-sp.github.io/) · [COPA release and evaluation instructions](https://asgordon.github.io/copa.html)

We render both alternatives as earlier statements and the original premise as the final statement. The model must identify which earlier statement relates to the premise. Each training item has one hash-randomized alternative order. We use both orders at evaluation and report whether both predictions are correct. A second training view presents the premise and one hash-selected original alternative, with its status as the endorsed alternative or the human-designed foil. A hash-selected fifth of training items also receives an additional view that repeats the earlier statement verbatim; a repetition alone supplies no causal explanation. These constructed presentations have no human reading trials. Text, zero-based Unicode coordinates and passage identifiers define the GPU inputs. Official test grades stay local. We remove cross-split duplicated triples and identify lexical overlap separately. No benchmark text will be sent to an external language model.

## Causal readout

The backbone reads each stimulus in one causal forward. A sentence becomes an eligible antecedent when it ends and the next sentence begins. By default each earlier complete sentence is eligible. The scorer uses the earlier sentence's pooled and terminal middle/final hidden states, the new sentence's pooled and terminal states through the currently available token, and their interactions. Fixed shared random projections compress the language model states. The learned head uses a pairwise logistic loss on the two candidate antecedents and a binary logistic loss on single-antecedent endorsements, human foils and repetitions. Linear coefficients with a squared-norm penalty permit an objective gradient check. This method needs no generation or per-candidate backbone passes. Supplying annotated antecedent extents is a separate assay. We report document-only versus supplied-extent results separately. The default candidate inventory is coarse; it supplies one antecedent per sentence and cannot separate two issues in a single sentence.

For timing, each new sentence contributes increases in its causal-relatedness score relative to the state just as the sentence begins. The score is transformed into a bounded resolution estimate; taking the running maximum for a given antecedent retains a successful earlier explanation. A source-side calibration partition from e-CARE training is used to set the null threshold. We report all thresholds and the upper-bound behaviors at the registered authored cue windows. A spontaneous human question, its exact onset and its complete resolution require additional observations. The point estimate from this head represents textual explanatory evidence for a candidate antecedent.

## Evaluations and decisions

The external primary endpoint is the proportion of the 500 official COPA test questions where the same causal alternative is selected correctly in **both display orders**. This requires more than always preferring the most recent antecedent. Compare to a lexical overlap model on exactly the same units and report the paired 95% item bootstrap interval, with documentation of ties. A second comparator uses a trained readout of the alternatives alone, before either model sees the premise. We additionally report per-order accuracy, change in probability after the premise, calibration loss, the subset without direct content-word overlap, and ask-for-cause versus ask-for-effect breakdowns. We inspect the previously scored eight authored A/B families and twelve early/late families using the same cue windows and scoring gates after freezing the model. We report complete hits, within-window alerts, non-target alerts, and change at the decisive cue. Accurate selection on COPA can support generalization of causal attribution. Passing the authored tests can support computational localization under those constructions. Neither alone establishes human token-level reading dynamics. Any subsequent model change after scoring COPA uses this test as a retrospective diagnostic.
