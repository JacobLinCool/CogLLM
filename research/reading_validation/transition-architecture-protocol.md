# Does the human character-introduction effect transfer across backbones?

## Target and status

Compare frozen Qwen3.5-2B, LFM3-1.7B-Base and Gemma 4 E2B on the same English SNaC book-to-movie transfer. The primary event is whether any human annotator marked a word as part of an unexpected or insufficiently introduced character. The prior Qwen movie scores and the prior named-entity comparison were known before this protocol. Movie characters and source labels are unchanged. This is an architecture replication on a known benchmark. [SNaC data and annotation paper](https://aclanthology.org/2022.emnlp-main.29/)

## Common source and causal exposure

Start with the previous 149 public book and movie summaries and their group assignments. Require the full original summary to fit within 2,048 native tokens in each model. A word is eligible only if its final token ends at the original word end and the complete tokenizer ID sequence through that point equals the tokenizer output for the isolated original prefix. Use the common retained word positions to construct every architecture's word history, with identical word and segment indices. Exclude the entire document if it fails the context limit for one architecture. Record missing documents, words, and changes in human-label coverage for this common cohort. Each encoder processes the original complete article exactly once. A technical confidence check may independently run documented validation text outside the scientific cohort. The human observation marks a reading segment retrospectively and the released anchored character string identifies the word membership.

## Estimators and control

Use the three archived span readouts from the same earlier Frick–ExpMRC joint training protocol. These projections precede SNaC training for every architecture. Give each observed word its 16 existing surface predictors and one summed native autoregressive word surprisal, two previously learned layer projections at its last token, and the 15 frozen cosine and global-attention antecedent features used in the Qwen study. LFM and Qwen yield 48 coordinates per layer. Gemma yields 64. For exact readout dimensionality the primary comparison keeps the first 48 coordinates of each middle and final projection in every architecture. Report the complete native 64-coordinate Gemma feature set separately. The previous Qwen model and its released weights remain the historical comparator.

Fit the original ridge logistic estimator (penalty 0.01, unweighted words) separately to the same training-book outcomes and choose each threshold at the 95th empirical percentile among negative development-book words. Fit three primary arms for each architecture: (1) pretrained full-segment NLTK POS and named-entity types, mention history, surface features and native word surprisal; (2) surface, surprisal and projected current-word states; (3) arm 2 plus the earlier-word cosine and native global-attention summaries. Freeze all estimators and thresholds before calculating architecture scores on movies. Use both within-architecture NER comparisons and the re-estimated Qwen NER comparator for every model. Full-segment NER can see subsequent words; the contextual heads cannot.

## Metrics and decision

Report all evaluated words, NLTK PERSON words, and first mentions of a complete NLTK PERSON entity. Main metric is average precision (AP). Also report ROC AUC, sensitivity, false positives per 100 negatives, precision, and Brier score. Compare AP for native relations vs NER and vs current word state and between architectures. Use the same 10,000 paired movie-cluster bootstrap draws within each stratum. Report point differences and percentile intervals without selecting architectures by outcomes. Report subgroup denominators. The word-level direction replicates across architectures if, in each, the feature set with antecedents beats its own NER baseline both overall and within first PERSON mentions. Evidence of directional replication is stronger when every architecture's paired interval exceeds zero. Claim a native-antecedent increment only if its paired interval vs local states alone exceeds zero. Results on a single known narrative benchmark cannot establish general-reading or causal cognitive alignment.
