# Can a causal reading model attach new evidence to the right earlier question?

## Target and data

We test whether a frozen Qwen3.5-2B with the selected CogLLM readout can assign a supporting paragraph to its original question when the same prefix contains two questions about the same paper. A human annotator's evidence judgment identifies a supporting paragraph. It leaves the timing of a reader's understanding within that paragraph unknown. The question is supplied in this experiment. The result can support conditional evidence attribution in scientific prose.

QASPER provides questions written by people who had not previously read the paper and answers with evidence selected by readers. We use the official train, development and test article splits. We apply the existing QASPER eligibility function to find questions for which all available annotators cite the same single uniquely mapped paragraph. We take two distinct questions with different targets per paper, using a fixed hash order. We present their original wording in hash order followed by their evidence paragraphs and eligible immediate neighboring paragraphs in paper order. Paragraphs must have 8–192 Qwen tokens. Inputs have at most 1,536 tokens. Questions longer than 60 tokens are excluded. A paper contributes at most one unit. Split limits are 400, 120 and 200 papers, respectively. Historical project QASPER paper IDs are excluded from the new test. The test score therefore refers to a passage selection task with two known questions, a pair of target paragraphs and original surrounding prose. This protocol describes historical ExpMRC and authored diagnostics as retrospective. The new QASPER test is paper-disjoint from training. All three partitions come from the same published study. We report source coverage and annotation multiplicity. [QASPER](https://aclanthology.org/2021.naacl-main.365/)

## Model, graded comparisons and model selection

The backbone processes a document once with a causal mask. A token can accrue evidence for several earlier questions separately. Our additional features match each earlier question's content-bearing tokens to the current token, and pool recent past matches. We use aggregated native attention, similarities in the middle and final layers and input embeddings, normalized word identity, and the selected readout's resolution logit. The features can be computed for any earlier span in the same forward pass. No model feature uses the evidence window or incomplete future words. We predict question-specific conditional hazards as a linear function of these features. Training compares human-supported versus competing question–paragraph assignments and limits early first hits using an interval-censored likelihood. The human paragraph label gives equal eligibility to all positions inside its span. The loss makes no point labels. Features are normalized only with training inputs.

Training uses eligible QASPER training documents and the existing training splits of ExpMRC and IIRC. Each corpus has equal total weight where its observations apply. Use a deterministic quasi-Newton fit with L2 regularization and check numerical stationarity. The candidate and lexical-only comparator use the same solver and training observations. The latter uses causal word matches only. Additional comparisons use the frozen joint CogLLM and a position-only hazard whose per-step rate is estimated on training data. Training and development labels remain separate from the new test and the retrospective diagnostics. We freeze weights and export forecasts before loading test outcomes for scoring. The procedure has one registered candidate and one lexical comparator. Development results may diagnose implementation errors. They will not select a new test-set model.

## Primary and secondary tests

The primary endpoint is the fraction of held-out QASPER papers where the model correctly assigns both supporting paragraphs, ranking the correct question above its rival within each individual paragraph. The score for a question in a paragraph is its conditional first-hit probability there, given survival to paragraph entry. Ties receive half credit per decision and multiplication gives joint tie credit. We compare the candidate with the frozen joint readout and the lexical comparator on identical papers using paired 95% article-bootstrap intervals. Superiority requires the lower limit to exceed zero for both comparisons. Report all four arms. Secondary outcomes include average correct assignment per paragraph, per-question interval log loss, a split by question/evidence order, and the number of test papers with multiple annotators for both assignments. We report the historical early/late control and A/B identity pass counts under their original scoring rules and sham comparisons. These stimuli carry no human response observations. A positive primary result alone would not establish spontaneous question opening or a token-level human reaction.

We lock all paper identifiers, study-selection rules and code hashes in the result package. The encoder receives text and earlier anchor coordinates. Local evaluation alone receives the held-out evidence mapping. We verify prefix invariance by comparing full and truncated technical texts, record counted backbone passes and numerical tolerance, and preserve eligibility counts, assigned geometry, per-paper forecasts, baseline definitions, optimizer status, and all outcomes. No editorial or deployment claims depend on a failed gate.

### Coverage amendment before feature extraction or model fitting

The source screen produced 11 previously unselected official test papers under unanimous annotation. We retain every original primary decision. To improve precision about within-study reproducibility, we will also report out-of-fold predictions on the 162 official training papers from five deterministic paper-disjoint folds. Each fit includes all non-QASPER training observations and four of the QASPER training folds. Normalization and model weights are recomputed in each fold. The bootstrap over papers conditions on these fitted folds. We report the 34 official development papers separately as a descriptive sample. Neither supplement replaces the official primary comparison.
