# TellMeWhy support coordinates

The authors' dataset guide defines helpful sentence indices as one-based in a five-sentence story. The original task form displays all five sentences, including the source of the question. The Hugging Face training file has no codes for the fifth sentence under this convention. The form and the prose documentation alone cannot establish which options the release retained. [Dataset guide](https://stonybrooknlp.github.io/tellmewhy/) · [Task form, Figure 1a](https://aclanthology.org/2021.findings-acl.53.pdf#page=5)

We checked the coding before fitting the model or scoring test outcomes. On training responses with a single reported support, we identified a source sentence other than the queried action with a uniquely strongest exact three-word match to the worker's written answer. The raw code usually equals the **zero-based** position of that independently located sentence. It usually disagrees with the documented one-based position. The first position is never emitted under the zero-based interpretation. These observations leave the meaning of an empty support list uncertain. The numerical audit is reproducible from the author files. [Training coordinate audit](../results/reading-validation-events/coordinate-audit.json)

Keep the originally specified one-based result. Report the same analyses assuming zero-based codes on positively annotated responses, excluding the unavailable first candidate. In addition, recover a high-specificity subset independently from the text of the human answer. Admit a vote when a unique answer trigram match identifies an eligible source sentence and the stored single support code agrees with that sentence under either of the two conventions. Every such vote identifies one selected source sentence. Untraceable votes remain missing. Require at least two traceable votes for a majority support or a determinate rival exclusion in the selective attribution assay. These restricted results describe explicit source overlap in retrospective answers. We will report all three analyses with coverage, and withhold a general interpretation of the raw index scores. All alternatives were specified from training data before scoring any held-out predictions.
