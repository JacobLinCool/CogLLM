# Does a new narrative goal reduce access to the old one?

Linderholm and colleagues had 84 retained participants read 32 short narratives. After an original goal appeared, a second paragraph either rementioned the goal, introduced a new one or provided neutral material. The sentence at the end of this paragraph, the original first paragraph and the old-goal probe were held fixed within each story. Readers then indicated whether the probe word had occurred in the story. Mean correct-response latencies were 713 ms after a remention, 834 ms after neutral material and 908 ms after a new goal. First-paragraph latency was 714 ms. This is a post-paragraph word-recognition task. New-goal and neutral conditions differed in latency but not reliably in recognition errors. The published human contrast is known; we found no released participant-by-item ballots or latencies. The experiment predates current language models. Each Qwen input ends exactly where the original second word-recognition trial began. The probe, condition label and questions are excluded from the input. Compute scores both after the identical first paragraph and after each condition using the one forward over that article prefix. Record every excluded item, including any material in which an original variable cannot be recovered. Test equality of the original prefix's token IDs and all primary scores across the three suffix variants. Verify neither neutral nor new-goal paragraphs contain the old probe, and report exceptions.

The **primary accessibility score** is the log attention mass to all earlier printed occurrences of the original probe, averaged across the final native token of each complete lexical word in the unchanged final transition and across native global attention heads. Normalize each occurrence for the number of native pieces and normalize total retrieval by the number of visible prior lexical words up to the beginning of the transition. The primary contrast compares neutral minus new-goal accessibility across the same 32 item families. Predict positive values, and greater accessibility after an explicit remention than after neutral material. Native attention is an independently measurable candidate retrieval mechanism; comparison with recognition speed here uses direction across conditions only.

Compare with a uniform visible-word observer and a lexical-recency observer, whose weight for each occurrence is inverse distance to the query word with the same source spans and normalization. Predeclare three control words per original story: choose printed content words of the introduction absent from all three final transition sentences and the competing-goal and neutral manipulation, excluding the target and stop words. Choose by smallest difference to the old target in count, relative location of its last occurrence in the first paragraph, and character length, breaking ties lexically. In a specificity test subtract the mean log accessibility of the three fixed control words from the old probe's score before computing the neutral–new contrast. Report the analogous ratio for recency and uniform controls. A separate sensitivity restricts all target/control key occurrences to the original introductory region.

As a secondary observation, read the existing trained CogLLM token observer's unresolved mass attached to each of these same old words, using the original source question-mass update and its fixed prior parameters. Report it separately from native memory retrieval. Memory accessibility and unresolved reading difficulty can diverge when an issue is abandoned. The original study measured neither a probability of felt difficulty nor its token-level time of onset. One scalar per family contributes to each interval and exact sign test. Estimate 95% intervals with 10,000 whole-family bootstrap draws, paired difference relative to recency and interval for the primary and word-specific effects. Record all four group means in their original units. Raw condition effects from model features cannot be converted to milliseconds with these data.
