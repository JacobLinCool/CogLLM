# T5-Large specialist on the same book-to-movie split

## Question

Can a single-forward causal word scorer match the practical word-level precision and recall of a supervised sequence-to-sequence character-span specialist that sees the entire target sentence? This within-source comparison tests a known failure mode of the research claim. The source authors already localized character references using T5-Large. Their movie training membership is unavailable. This is a new training run adapted to the designated CharE outcome, separately from their historical result. The existing Qwen predictions, operating point and movie labels were known before this design. [Original system and source audit](transition-snac-prior-model.md)

## Material and outputs

Use the existing 88 training book summaries (44 titles), 22 development book summaries (11 different titles), and 39 evaluable movie summaries. Within each released segment use the English NLTK Punkt boundaries, with exact original Unicode coordinates recorded. Split data before generating training rows. For book fitting and development, train only on unambiguous CharE segments, with the same word labels used by the causal Qwen readout. Convert each sentence’s marked contiguous words to one or more original span strings. The target is “true” for absence or “false character” followed by the marked strings separated with a T5 sentinel. This CharE-only target and Punkt sentence reconstruction are adaptations from the original multicategory study. Include all movie sentences in the outcome-free GPU packet; score the already specified subset of unambiguous movie words externally. No movie annotations enter the L4 training payload.

Provide the complete target sentence, plus at most 921 preceding whitespace-delimited context words and a separating T5 sentinel; cap the result at 1,024 model tokens as in the public authors' scorer. Limit generated labels to 80 tokens. Fit the official google-t5/t5-large pretrained checkpoint, revision 150ebc2c4b72291e770f58e6057481c8d2ed331a, with Adam, beta values 0.9/0.999, epsilon 1e−8, learning rate 1e−4, no warmup, linear decay, effective batch size eight and five epochs. Set seed 4703. Use dynamic padding, mixed BF16 forward, full-precision parameters and Adam state, and gradient checkpointing on one Colab L4. Bucket training samples by similar lengths within shuffled pools. Monitor held-out book teacher-forced, token-weighted NLL after every epoch; choose the epoch with the lowest development NLL, with no movie scoring during selection. Preserve all training and development losses and the final relative change. Include the initial development loss, best-to-initial change, and last-epoch gradient and loss diagnostics for interpretation. Keep local weight downloads off the host.

## Common movie score

Decode with greedy T5, as in the public inference script. Convert each generated character string to consecutive normalized word forms within its source target sentence. Mark every exact word-form match if it occurs repeatedly. Count unmatchable strings and malformed outputs. A generated character word outside the original ambiguity mask contributes no true or false positive. A missing or malformed forecast yields zero marks plus an explicit format count. No heuristic replacement of generated characters or fuzzy matching is allowed.

Report char-word precision, recall, F1, false alerts per 100 negative words, coverage, exact contingency counts, and 10,000 paired movie-bootstrap intervals. Compare to the locked historical Qwen production threshold and its already-trained NER control, using the same complete movies and human word coordinates. Report a token-end/complete-sentence visibility distinction and wall time; summarize error overlap and the subset of named PERSON first-mentions as secondary observations. Do not compare T5's thresholded set with Qwen's area under a ranking curve. The target comparison is a specialized full-sentence model with book-only training.
