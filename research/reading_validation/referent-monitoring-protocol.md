# Does an incoming word displace an already established referent?

One earlier version of a story introduces an oboe; an unchanged later sentence refers to a cello. A model can know both instruments while missing the reader's report that a particular object has changed. The previous temporal calibration learned from a consistent versus inconsistent manipulation. Its evaluation instead compared an unspecified (neutral) detail to an inconsistent detail. These are different experimental controls. Learn the readout using both kinds of control actually recorded in the public source; keep every test family and all readers of the third experiment outside its training fit. This is a follow-up using an already reported target cohort, not a first blind study of those twelve families. [Original experiments](https://doi.org/10.3758/s13421-026-01900-7) · [Earlier calibration](memory-results.md)

The first experiment's 20 paired source families identify a potential displaced object by an independently checkable property. A content word occurs in the changed part of the earlier consistent premise and in the unchanged target, and is absent from the changed part of the inconsistent premise. Train the word selector only where this rule points to a unique source word after excluding grammatical function words. Do not use that family’s pair, any experimental marker or a content-word list when forecasting its later passages. In particular the model must choose the candidate word by reading the single article. An optional diagnostic supplied the relevant location cannot count toward the article-only result.

Estimate how likely a sentence is to be a designated comparison in this experimental paradigm from the empirical source distribution of sentence length and ordinal position. Use a floor from the pooled background frequencies and source-only priors. This provides a strong design-aware reference: the source showed all comparisons at sentence positions 12–15, with 7–9 words. Report precisely what the model can recover from this structure alone and avoid extending a paradigm-specific role predictor to unrestricted prose. A separate word selector among the visible sentence's lexical words learns from source-derived referent identities with a within-sentence conditional likelihood. Inputs include article/nominal context, position, frequency, repeat history, static WordNet similarity to preceding content nouns and the native lexical expectation evidence from the same single Qwen pass when available. Estimate compatibility from the posterior-weighted word evidence. A genuine previously mentioned term, a competing related term and an unspecified earlier detail can then receive different scores. Compare a role-and-position model, the position and independent lexical-taxonomy model, and the same model plus native Qwen word expectations on identical folds. Without the native job the role and lexical part remains independently evaluable. [Princeton WordNet](https://wordnet.princeton.edu/) · [Lexical expectation definition](expectation-protocol.md)

For each held family, use its disjoint counterparts from original Experiments 1 and 2; keep the number of readers, first-event risk set and task-specific control rates as observed. Fit the source event probability, including background reports, with likelihood on both the complete first-event path and the observed source role/condition strata. Use all trajectories only from eligible other families, equalize source study and family contributions, and keep the human reporting scale in probability units. Scoring the wholly external Experiment 3 reader group is the primary comparison. Any score for Experiment 2 uses only other experiment-2 families and can reuse the same readers; identify it as material-held rather than reader-held. Baseline operating points and error bars use the registered crossed twelve-family and participant bootstrap. The deployment claim requires a reduction in magnitude error and an upper bound of +.02 nats on path log loss compared with the original frozen predictor. Show human and model effects, early alarms, total trajectory error and direction consistency. Include a comparator trained with identical paired word supervision but only Experiment 1 human rates to distinguish adding the missing neutral response from adding a lexical selector. Keep the first word of subjective recognition distinct from the recorded sentence-end response.
