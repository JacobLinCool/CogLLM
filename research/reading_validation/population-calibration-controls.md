# Controls for target calibration and absolute-error scoring

The one-offset model and the target constant were fitted to the mean full-spelling response in 32 calibration readers and 64 designated stimuli. Absolute error is minimized by a median. A reference-set median should therefore be included alongside the frozen mean comparator. A second control supplies the native, untrained Qwen word distribution at the same reading position, maps it to the identical vocabulary, and fits the same one-coefficient log-odds calibration using only the same reference readers/stems. Both controls are evaluated on the originally fixed disjoint people and stems, with no change to the existing trained forecast or primary outcomes. Also report squared error for the original mean-based procedures. This is a sensitivity specified after their initial test results were known.

For uncertainty, resample calibration readers, calibration stems, test readers and test stems in their existing roles exactly as in the primary report. Recompute all fitted constants and offsets in each draw. Use a deterministic frequency-weighted median of the calibration stems, taking the midpoint of the two middle observations when the number of valid draws is even. Compare the unchanged UCL-informed calibrated forecast with the target median and native calibrated forecast using simultaneous intervals for these two additional contrasts.
