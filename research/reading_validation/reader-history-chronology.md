# Separating past assignments from choices on a questionnaire page

The external GitHub release has 6,510 anonymized questionnaire assignments, each with a recorded acceptance and submission time. Individual item response times within a page are unavailable. Before comparing independent answer probabilities, define a strictly prospective cohort using twenty nonempty choices from a person's earliest completed assignment. Forecast choice on novel sentence stems in later assignments accepted after that first assignment was submitted. Among ties or a single page, there is no demonstrated order of answering the individual fields. Select the history sample inside the earlier page with a fixed material hash. Exclude previously exposed stems in later assignments. Participants with only one assignment can separately support the prespecified cross-item conditioning analysis, described explicitly as such. Match the shuffled control to other histories with maximum overlap in available earlier stems, breaking ties with an anonymized stable numeric order. In aggregate, the source inventory contains 311 public anonymous respondent codes before the authors' exclusions. No held full answer distributions, preferences or predictions informed this timing definition.
