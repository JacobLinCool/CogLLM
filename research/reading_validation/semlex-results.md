# A model can move toward the easier word when context changes

Across 907 comparisons in which five English learners' consensus reversed for **the same two words**, CogLLM shifted its predicted preference in the observed direction in **62.7%** of cases (95% interval 57.4–67.9%). Any rule that always assigns a word the same score gets exactly 50% on this comparison. The original adaptive n-gram comparator reached 52.2%. A strong readout using lexical cues and the language model's own word probabilities reached 63.5%. The difference between CogLLM's mixture and that readout was −0.8 percentage points (−5.0 to 3.2). The new result establishes a context-sensitive signal on a separately collected panel. The evidence points to native predictability as an effective source of that signal. | Shift toward the simpler word when the judges saw identical *entire* candidate lists | 67 context comparisons, 59 contexts, 21 lexical targets | 57.6% | 55.1% | 61.2% | 54.5% |

A change in preference strength can occur even if the selected word stays the same. For example, a model could favor A strongly in the A-preferred context and favor A only slightly in the B-preferred context. It moved in the human direction but selected only one correct winner. The 95% interval for selecting both was 12.1–21.4% for the mixture, compared with 24.6–35.6% for raw target-word probability. Two independent fair coin flips would select both with probability 25%. A fixed deterministic ordering would get neither pair of answers jointly correct on these reversals. The mixture alone therefore provides a poor basis for recommending two different winners. The complete-list result has an interval of 39.7–73.9%. On the larger primary set, candidates outside the measured pair can change across contexts. The original judges ranked a provided list while seeing the sentence with a placeholder. We encoded the complete printed sentence once per candidate. The 2012 test's five university-educated, highly proficient second-language readers each rated the complete set. The original study reports test-panel pairwise kappa 0.398. Published aggregate ranks reveal which ordering the panel favored. They leave individual variability, reading time and the onset of difficulty unresolved. Inference resamples lexical targets and conditions on the five judges. [Original participants, task and agreement](https://aclanthology.org/S12-1046.pdf)

## Source roles and independent replay

The source mixture used weight 0.219 on a shared word-report and substitution-preference model. The remaining weight went to the source lexical and native-probability readout. This weight used 7,335 previously reported votes from 296 material families in the Paetzold study. Those families consequently serve as calibration for the SemEval transfer. The independent test spans 171 target lemma–part-of-speech combinations from the older English Web corpus. Of 1,710 original contexts, 1,234 passed source eligibility; 359 contained a target with unmatched inflection or case. After native feature and historical baseline checks, 11,155 pair forecasts were locked. All had unambiguous human consensus endpoints, including 358 panel ties. No screened original or generated source string matched an audited earlier supervised item. Language-model pretraining exposure remains unknown. [Material, training and development overlap](../results/reading-validation-semlex/material.json) · [Source calibration](../results/reading-validation-semlex/source-calibration.json)

The NVIDIA L4 encoded 5,633 distinct rendered sentences (169,739 Qwen tokens) in 353 batches in 96.0 seconds. A single causal pass through each rendered sentence supplied both its internal features and the word probabilities. The extraction retained original character boundaries and passed three prefix checks. The primary effect over the static control was +12.7 percentage points and over the published n-gram +10.5. The respective 32-comparison adjusted intervals are +4.1 to +21.0 and +1.4 to +19.5. Against the stronger native comparator the adjusted interval is −7.4 to +5.3 points. The single forward is a property of each finished candidate sentence. Comparing several proposed drafts evaluates each distinct draft once. In an isolated directory with five listed repository files, that procedure independently reconstructed 907 context comparisons for 344 distinct target-and-alternative-pair combinations and matched the registered outputs to 10⁻¹².
