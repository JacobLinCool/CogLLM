# Can one printing of the same word be harder to read than another?

A predictor can correlate strongly with response measures across a passage by recognizing which word appears. For authoring, the more informative comparison holds the printed word fixed and changes its preceding context. Test every pair of the identical, case-sensitive original English word appearing in different held sentences. Use the published English human data and fixed sentence folds, retaining the 1,546 positions whose original exposure matches across cloze, ratings and EEG. Include all eligible word types, report the number of types, positions, distinct sentence pairs and individual occurrence pairs. For each type form all cross-sentence pairs with a finite endpoint. Score whether predicted ordering agrees with observed ordering (half credit for a tied forecast, exclude tied human values from that endpoint). Average pairs within type and types equally. Use estimates from new three-backbone source fits and their matching surface-plus-surprisal comparators. For a current comparison reproduce earlier Qwen cross-validation with its registered bottleneck/checkpoint. Retain only the predictions generated by each item’s held-sentence fold. A secondary analysis requires identical original displayed word index as well as word identity. Another restricts type pairs to the same held fold, removing variation between fitted coefficients. Record the number excluded in both. No new adjustment, selected word type, or fit uses held responses.

Primary tests are the new three encoders’ contextual-minus-matched-surface concordance for each endpoint. Weight each eligible lexical type equally to prevent a few common function words from determining the result. Quantify shared occurrence dependence with 2,000 paired Bayesian bootstrap draws, with independent unit-exponential weights on lexical type and on source sentence. The weight of a cross-sentence pair is the product of the two sentence weights, and its lexical type's share is determined only by its type weight. Draws are shared across all methods and endpoints. Provide 95% intervals and a simultaneous envelope for the three endpoint contrasts within each backbone. Different sets of readers supplied the aggregate outcomes and genuine printed-word comparisons use different natural contexts. Relative behavior on this observational assay can expose lexical confounding and does not identify a causal effect of editing the context. The overall English correlations and Spanish paired-word EEG effects were known before registration. The English per-type contrasts and new backbone exposures were unscored at registration.
