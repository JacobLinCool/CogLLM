# Retaining reliable information from word count or source coverage

In a development-only, source-held-out check, a supervised edit model agreed well with ASSET meaning preferences, while the shorter-candidate rule retained an advantage on ASSET simplicity. This motivates one secondary calibration. The registered edit/Qwen interpolation remains the primary model. SimpDA target responses remain unopened at this stage.

For simplicity, give the calibration the fixed score for log source word count minus log candidate word count. For meaning, give it the source-relative, frequency-weighted stem-coverage F-score already used as a baseline. Preserve the primary score for fluency and for the overall auxiliary endpoint. For each of the two calibrated endpoints, obtain the previously specified model's held-family development predictions and its fixed prior score. Standardize each coordinate on development candidates. Fit nonnegative coefficients to source-balanced paired development preferences using the same fractional logistic loss and an L2 penalty of 0.02, with coefficient prior (1, 0) on the standardized learned and fixed scores. The fixed prior can be retained when it explains systematic variation in held-family judgments. Each test source is evaluated exactly once by both frozen decision rules. Report both models even if the correction reduces external accuracy. The external 2022 test evaluates whether the development-informed correction transferred.
