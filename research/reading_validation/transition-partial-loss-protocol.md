# Learning from human span strings whose occurrence is ambiguous

The training archive supplies the highlighted character-reference string and the source segment. If a string appears twice, assigning both occurrences a positive label or choosing the first occurrence would introduce supervision the annotator did not provide. For segment s, enumerate all distinct word masks C(s) consistent with one literal placement per released record. For a single-forward, prefix-conditioned word probability vector p, let P(z|p) be the product of its wordwise Bernoulli probabilities under mask z. Train with the observable-set log loss −log Σ_{z∈C(s)} P(z|p). This models recorded responses under a product measurement assumption. It does not assume that real choices by a reader are conditionally independent. When the set contains one mask the expression is standard wordwise binary cross-entropy.

Fix the existing 88/22/39 book-training, book-development and movie-test split, original single-pass Qwen contextual and antecedent features, L2 slope penalty .01, unpenalized intercept and source-only feature standardization. Compare three source likelihoods on exactly the same features. (1) Retain only segments with one exact mask. (2) Use identifiable individual words in every segment and omit ambiguous words. (3) Use all segments with the exact marginal likelihood. Give each training title equal influence; within a title normalize by the number of words having a contribution in that arm. Fit all three using monotone updates to maximum absolute gradient at most 1e-7. Start the marginal fit from the identified-word model and require convergence from the zero-slope initialization to comparable predictions. Fit one causal numeric readout per policy with no second backbone call.

The primary score is mean held-out observed-set negative log likelihood per word, with equal movie groups. Paired uncertainty uses 10,000 whole-movie resamples. Also report cross-entropy on guaranteed labels only, AP on the previously identified common words, and attainable precision/recall for source development thresholds set to the 95th percentile of guaranteed negative-word risk. Report per-movie gains and per-ambiguous-segment differences. The earlier held-out word results and the count of permissible source placements are known. This experiment is a new use of old data and does not create a fresh movie holdout.
