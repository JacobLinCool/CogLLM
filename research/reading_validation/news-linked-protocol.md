# Can the article alone locate a self-contradiction *and* point to the earlier wording?

People marked a continuation's problematic span and linked it to earlier text. The new premise-retrieval model could identify the earlier sentence when given a held marked location in 69.8% of responses, compared with 57.5% for learned lexical matching. On its own, the same model ranked marked words worse than a text-form detector. We test the mechanism implied by this dissociation: local detection of a marked span and binding that mark to a source are separate conditional events. Both should be forecast at every reading position when no target or source coordinate is supplied. Previous performances for this source are known. The simultaneous endpoint and training objective in this document were set before scoring their predictions. [Original annotation study](https://aclanthology.org/2022.acl-long.501/) · [Native source readout](retrieval-protocol.md)

Use the existing prompt-group train/test split, literal continuations, original UTF-16 span conversion and certified word endpoints. For each annotator, distinguish an observed unmarked word; a marked word with one or more permissible earlier source sentences; and an observation that cannot be scored because its source is missing, outside the continuation or in the current sentence. Mask the last case. An overlapping valid and unlocatable mark is masked for that annotator. Include every eligible word after at least two completed earlier sentences, including passages with no mark. If a reader's valid highlighted source crosses several earlier sentences, allow each indicated sentence at evaluation. Group split and externally trained retrieval weights are fixed.

At every eligible word, estimate the probability of the observed annotator state. State zero is no marked contradiction. Each positive state identifies a particular earlier sentence. Estimate the transition into a mark from the first eligible word of a mark after a known unmarked predecessor. Estimate exit from a mark using adjacent observed word states. For conditional source selection, normalize scores over all earlier sentences and train using the probability assigned to the set of source sentences specified by the training annotator. The frozen external contradiction scorer and native attention provide prior source evidence. Give text-only baselines access to the same length, sentence distance, lexical overlap, and punctuation. Retain a contemporaneous binary mark model trained on all available word votes using identical features. A temporal model carries forward its distribution over sources while a mark persists, and opens new sources using that word's conditional pointer. Every article estimand is computed forward in original word order, with no human status, target boundary or annotation identity supplied at inference. The model may find multiple distinct problems in a passage.

Source inputs are the same saved Qwen states, word surprisal and native attention from the complete, original article. One hundred percent of test-group rows are excluded from parameter fitting and centering. Give each source document equal total loss; conditional transitions and links contribute according to the number of eligible annotator decisions within document. Report trained lexical and contextual models, temporal and pointwise versions, and an independent prior word-trained detector combined with the unchanged external source readout. The latter requires both native projections from the same encoder activations; offline assembly of pre-existing score files cannot check one-pass serving by itself. Report convergence of each convex head. All choices apply calibrated probabilities; no threshold search on held events.

The primary loss is the word-by-reader negative log probability of the observed allowed state(s), averaged within document and across held prompt groups. It penalizes false alarms and wrong sources. Also report word-mark average precision on mixed passages, proper log loss separately among positive and negative decisions, and top-ranked joint word/source accuracy over all eligible candidates for each passage with a positive event. Source overlap alone earns no credit on that last measure. Compare methods at identical positions and use 10,000 paired resamples of held prompt groups. Present both prompt-equal and all-observation summaries. The scientific endpoint is retrospective annotation of a model-generated news continuation. It does not give the timing of a reader's own first experience of difficulty.

Each binary transition fit is convex under a fixed quadratic penalty. The log probability of a *set* of interchangeable earlier sentences can have multiple local optima when the response spans several sentences. Fit the low-dimensional source weights from two prespecified initializations (all zeros, and a positive weight for the corresponding frozen prior) and retain the smaller converged source objective. Record the two objectives and gradients. In a switch between disjoint annotated source sets, train an exit and an immediate new opening. A word following an unlocatable annotation supplies no observed transition. This preserves different supervision strengths without converting uncertainty into a fabricated point label.
