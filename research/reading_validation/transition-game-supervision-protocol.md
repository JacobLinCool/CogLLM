# Learn reader-pair disagreement on silver texts and forecast independent gold texts

## Independent human quantity

At a particular personal pronoun, sample two different readers who each selected an earlier referent. The outcome is one if their chosen antecedent entities differ. For a mention with n eligible readers and counts nₑ after collapsing interchangeable mentions of each entity, its unbiased observed disagreement is 1 − Σₑ nₑ(nₑ − 1)/[n(n − 1)]. Assign each mention a fractional binary cross-entropy target. This avoids treating all n(n − 1)/2 dependent pairs as independent observations. The primary transfer set and aggregation remain the gold audit specified before the native SNaC experiment. No model–gold association had been computed when this extension was registered. ## Held-out texts and people

Use the authors' official silver training and development files. Their MPA-aggregated entity identities weakly identify which antecedent mentions refer to the same entity. Use the separately expert-adjudicated entity identities on gold. For both, use only independent original player choices, collapse identical choices by a single anonymous player, discard conflicting repeats or an unmappable earlier-entity choice, and require four eligible readers. Apply the same original-word and personal-pronoun certification to every partition. Use every eligible complete passage of at most 2,048 base tokens. The gold set preserves the original 44-document common support.

Remove from silver training/development any Gutenberg volume also represented in gold, matching the released work ID before its alphabetic excerpt suffix. Exclude exact reused article IDs and any silver text sharing 20 consecutive normalized lexical tokens with gold. Apply analogous exclusions from training relative to retained silver development texts. Audit retained source document and work counts, extractions excluded and exact overlap. Compare the encrypted player IDs from independent original responses in retained training documents against gold. Document transfer is primary. Repeat on gold pronouns with at least four eligible antecedent votes from players never seen anywhere in the retained training documents. Report new-reader coverage even if insufficient for a stable estimate. No private player identifier enters the released analysis or training feature packet.

## Frozen learner and controls

Use the existing Qwen3.5-2B revision, selected for its established serving pipeline and prior book-to-movie behavior. This is the sole primary architecture. Use one causal pass over the complete original reading text without an appended question. Save native middle/final coordinates only at supervised word ends, preserving the visible prefix of every input. At gold pronouns compare a book-trained CorefE observer (the pre-existing zero-shot native study), a silver-trained surface/form observer, a silver-trained direct native observer, and one joint four-target observer. The lexical baseline includes the identity of the current pronoun, text position, prior repeated forms, count and distance of earlier capitalized name candidates and native word surprisal. Native observers add all middle/final coordinates with block-normalized variance as in the direct protocol. None takes neighboring human judgments, reader identities, future words, or gold chain IDs as predictors.

Use the same fixed source penalty of 0.01 and the title-balanced, task-masked logistic objective. The direct model uses only the silver reader-pair target. The shared observer adds the three SNaC book targets: unexplained character introduction, missing event or object reference, unclear pronoun referent. Each target gets absolute mass one quarter, each observed source document or book title equal weight within its target, and each observed word equal weight within group. Apply the previously specified signed low-rank penalty to the native coefficients and independent ridge to surface coefficients. Use source training words for feature scaling, with silver-only statistics for single-task fitting and all participating sources for the joint fit. Fit the same optional intercept-only correction on development silver for each game forecast by equating predicted and observed mean disagreement there. No gold responses enter fitting or calibration. Compare also to a constant from development silver. Fix model size, loss and scope before scoring any gold associations.

## What constitutes transfer?

The two co-primary quantities are within-document rank concordance with expert-collapsed observed disagreement and expected Brier loss for an actual pair of readers. Report paired differences and 95% document-cluster intervals vs the surface/form + surprisal baseline, for direct and joint fits. For Brier, compute d(1 − p)² + (1 − d)p² from the observed d. Report the mean forecast and observed event rate, signed calibration bias, and reliability bins defined solely by four development-score quintile boundaries. Also report all-prespecified same-form within-document ordering, source vs held-out genre, and the number of eligible players. The difference between shared and silver-only fits measures transfer from the three SNaC labels; report favorable and unfavorable directions. A model can be calibrated to average rates and still fail to rank ambiguous pronouns.
