# Sharing how studies can differ

A common latent projection forces heterogeneous studies to use identical coefficients. Giving every study a private projection discards the possibility that two studies depart from the common observation in similar ways. We test a single learned direction of variation per shared reading state. In a study j and state s the projection is W_s plus a_{js} times D_s, including a bias coordinate. W and D are shared, a is learned from the original responses to study j, and a centered Gaussian penalty on a decreases with the number of independent source families. D has a fixed Frobenius norm so the amount borrowed has an identified scale. Each originally permitted measurement still receives exactly its own ordered, count, survival, or continuous likelihood and only its measured positions. All parts are differentiated together; inference still requires one causal backbone exposure. This is a low-rank model of *between-study* deviations. It is possible for the observed data to prefer fully private coefficients.
