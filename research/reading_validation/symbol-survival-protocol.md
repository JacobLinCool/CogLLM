# Training a source's first-release time from its observed interval

The previous point and competing-source objectives rarely recovered both complete lifetimes. They treated many tokens from each definition as individually positive. The original annotations instead establish that a source's first description arrives somewhere in an interval. This follow-up fits that observation with its exact event-time likelihood. The previously examined Symlink and SymDef results have informed this change. All new coefficients and thresholds use the original 56 training and 15 calibration papers exclusively.

For a particular visible source let its causal nonnegative token intensity be λ(t). For a labelled first description in [a,b], its negative log likelihood is the integrated intensity before a minus log of 1−exp(−the integrated intensity from a to b). A fully observed source without a forward description contributes its total integrated intensity up to the end of the paragraph. Annotations give no point label inside an interval. Train using all proposed known positives and the actual observed earlier/censoring time. Limit abundant ordinary source negatives by deterministic sampling within the paragraph; account for the sampling ratio and balance training papers. Invalid or missing source proposals remain part of the final denominator. Input features are the training-only preceding contextual/surface heads, candidate salience and visible timing, safe current-token and preceding-region evidence, and the source's rank against currently eligible visible alternative names. Never use a later definition, final paragraph length, held annotation or offline peak to create running inputs.

A single immutable earlier entity remains open until its cumulative hazard crosses a training-calibrated decision boundary. Canonically identical competing span proposals share one entity; survival integrates the strongest current contribution in that group once, and the selected credited source is the largest current hazard when the group closes. Closure affects only that canonical identity. Keep the original incidence, source-span, cue interval and simultaneous-other-source conservation definitions. Calibrate the release threshold on the same equal-priority paired-lifecyle and individual-event harmonic criterion, reporting ordinary F1 and false alerts as before. Compare the interval likelihood to frozen prior factorized and original point-likelihood readouts on all three previously examined test groups. No threshold or loss may be selected using those test scores. Assess the external complete-lifecycle denominator (five pairs) independently of its more informative single-event sample.
