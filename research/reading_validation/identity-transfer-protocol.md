# External transfer of question-specific evidence attribution to MultiRC

We will apply the four already specified identity models to the entire public MultiRC version 2 release without using its annotations for fitting or model selection. Questions in this dataset draw on several sentences. Its annotators marked the sentences used to construct a question. The final marked sentence defines when every marked supporting sentence has appeared. The data leave the time at which an individual reader understood the answer unobserved. [Source release](https://cogcomp.seas.upenn.edu/multirc/) · [Primary paper](https://aclanthology.org/N18-1023/)

We parse the complete source passages in their original order, remove the HTML display frame and prepend two supplied questions. We consider questions marked `multisent` with at least two distinct valid sentence indices. A pair is eligible if the questions differ and neither question's final annotated supporting sentence belongs to the other question's support set. The question order and pair selection depend on a fixed hash of the paper ID and question index. A passage contributes one pair and at most 1,536 Qwen tokens. Both the official public training file and the development file serve exclusively as external evaluation data. We remove repeated normalized passage texts and check for exact passage or 12-word overlap against the papers used to train the identity readout. We will report any retained overlap and the disjoint subset. No answer option, supporting index, grade or future word is a model input.

The primary comparison is the proportion of passages where the correct question outranks the rival at both final supporting sentences, using the integrated conditional hazard within each sentence. Primary superiority requires the lower limit of paired passage-bootstrap 95% intervals to exceed zero against the released CogLLM and the jointly fitted lexical model. We also publish equal-question accuracy, per-question interval negative log likelihood, signed improvement against the position model and a content-word BM25 comparator (retrieval only), the question-display stratum and separate genre summaries. We will report lower-than-baseline results and all denominators. This analysis was specified before the QASPER model's test scores and before extracting or scoring MultiRC. The dataset is a new external study for this project.
