# A pointer trained on game choices finds a person’s name in unseen Wikipedia passages

The frozen reader-click pointer chose an earlier word inside the verified name on **64.4%** [61.6, 67.2] of applicable GAP examples. It could choose any earlier word and neither candidate name was marked. An equally trained lexical/POS observer reached 29.3%. The paired gain was **35.1 percentage points** [31.8, 38.4]. Once forecasts were fixed, comparing only the two annotated names yielded 79.4% [77.0, 81.8] correct preferences for the native observer and 47.8% for lexical/POS. The paired gain was 31.6 points [28.3, 35.0]. [Original GAP study](https://aclanthology.org/Q18-1042/) · [Registered transfer protocol](transition-pointer-gap-protocol.md) · [Full external results](../results/reading-validation-transition-pointer-gap/scores.json)

Whole-passage inputs covered 1,999 official test snippets, after removing one source-title overlap. No GAP examples entered fitting or calibration. The frozen Qwen3.5-2B and source-only pointer emitted an earlier-word distribution at 6,808 visible pronouns, totaling 284,697 candidate words. Primary scoring required both names to be fully earlier, their word spans to be uniquely identifiable, and exactly one verified referent. This left **1,107 comparisons from 1,054 Wikipedia articles**. Article groups were the units of paired bootstrap uncertainty. Many excluded examples contained a later candidate that a reader had yet to see. Source examples may have appeared in foundation-model pretraining. Summing probabilities over a whole name favors longer names when probability is uniform; this explains the uniform model’s 37.7% two-name result. When both names had equal numbers of words, the native observer chose correctly in 79.6% [76.0, 83.2] of 510 examples. An evaluation oracle that selects whichever annotated name is closer to the pronoun reached 45.6% across the main set. On 602 examples where the correct name was farther away, native two-name accuracy was 72.9% [69.3, 76.4], 52.0 points above lexical/POS [47.7, 56.4]. The masculine-pronoun and feminine-pronoun subset accuracies were 81.9% and 76.9%, respectively. These are linguistic form strata and do not measure reader or character demographics. [Subgroups and controls](../results/reading-validation-transition-pointer-gap/scores.json)

The source-selected .80 threshold retained 206 of 1,107 examples. Coverage was 18.6% [16.4, 21.0] with article-equal weighting. Precision was **82.0%** [76.5, 87.2] and false suggestions numbered 3.35 per 100 eligible pronouns [2.31, 4.46]. These examples explicitly have one named referent. A separate [all-action game audit](transition-pointer-results.md) measures what happens when readers can also reject a preceding referent. ## From the latest mention to the person’s name

Without another model call or any new fitted parameter, we recursively passed the probability assigned to an earlier pronoun back through that pronoun's own distribution. Across the same articles, open-prefix top-one name containment increased from 64.4% to 66.6%, a paired difference of **+2.23 points [1.28, 3.23]**. Correct-name negative log mass also decreased by .0074 [.0035, .0122]. The two-name preference increase was only .28 points [0.00, .66]. In the game the same transformation reduced literal top-one placement by 18.6 points because some readers had explicitly chosen an intervening pronoun. The observation a study asks for determines whether following the chain helps.
