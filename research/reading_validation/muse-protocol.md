# Independent German replication of within-reader mixture updating

A new, separately authored German dataset enables a prospective test of the English-derived response-mode method. Sterner and colleagues report 98 participants reading German sentence beginnings and 133 different participants hearing them. The authors’ cleaning script explicitly identifies visual anonymous code prefixes and auditory prefixes. The harmonized table records a sentence, participant, and corrected word without an item timestamp or presentation index. We can test prediction on disjoint word exposures from the same person. We cannot establish which particular response was actually entered earlier. No participant attribute or clinical measure will be collected for this analysis. All predictions use a single frozen German sentence encoding by the English study's original Qwen3.5-2B weights. Only original material text goes to the accelerator. [MuSe article](https://doi.org/10.3758/s13428-026-02993-3) · [Original open data and cleaning scripts](https://osf.io/ktnze/) · [English source model](reader-history-mode-mixture.md)

Use the 133 auditory participants as the German model calibration cohort. Their input was spoken; the statistical observer reads its published exact transcription. The primary independent endpoint uses all written-only sentence stems answered by the completely separate visual readers, with subject and target texts absent from model fitting. Each visual reader's measured responses on the other shared written/auditory stems may be supplied as history. Withhold all written-only stems from every reader's conditioning context and exclude invalid or missing code 999 and grammar code 777 under the authors' source policy. Prefer their orthographically cleaned literal response rather than the singular/plural replacement. Preserve the release's documented umlaut transliteration equivalences. Count corrected named choices, outside choices and omissions. No person profile, response or evaluation key is sent to the GPU.

Before opening human completions, define the German response space using the independent wordfreq 3.1.1 German corpus and the pinned native Qwen tokenizer. In fixed frequency order take the first 4,096 alphabetic German response spelling categories with at least one whole leading-space Qwen token in lower-case or initial-capital form. Map the authors' spelling variants ä→ae, ö→oe, ü→ue, ß→ss. When a distinct vocabulary word shares a selected release category, include all eligible disjoint casing tokens encountered within the top 100,000 German list. The final probability bin contains all other tokens or human spellings outside the named lexicon. This projects Qwen next-token probabilities onto known printed categories. A native token can also begin a longer compound, so it does not identify all possible continuations of that compound. Measure the human lexical coverage explicitly. Analyze exact identities conditional on a named category separately from its outside probability. Do not infer German-language population-wide proficiency from this alphabet.

Fit a four-coefficient source calibration of word probabilities using log native mass, log independent German vocabulary frequency, log printed word length and a residual-category indicator with an intercept-free softmax and weak quadratic regularization. Estimate the two German mode priors using the fixed English equations, grid, symmetric mass regularization and paired-observation concentration estimate. Fit only on eligible auditory participants’ corrected responses at the auditory sentence beginnings. Retain distinct-person workload rather than treating each source group aggregate as one respondent. Require convergence and normalized output. The all-German source fit, study mode grouping, lexical display map and all personal history selections must be locked before visual-only answers are read. The final test of this fitting procedure is independent of the English study, including its texts, readers, language, modality of calibration and dictionary.

The primary metric is mean response log-score gain of the correct person's response-mode estimate against the full distribution averaged over all other eligible German reading participants supplied with the SAME fixed number of their own answered shared stems. Use the maximum common number of history observations available to the person and a deterministic same-material-matched stranger. Require at least twenty answered shared stems and two other eligible people. Within a calibration set with unknown temporal order, order by fixed sentence-content hash. The other participants’ histories cannot include any written-only test material. Compare with that one stranger, the static auditory-trained German population, the four-coefficient head and native word mass. Report crossed participant-by-sentence uncertainty, literal named-choice versus outside effects and eligibility across both cohorts. A secondary comparison gives every included visual reader exactly twenty histories. Preserve any null or unfavorable personal effect. The target claim is cross-item response conditioning for this population. [English mechanism test](reader-history-results.md)
