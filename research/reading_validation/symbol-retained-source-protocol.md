# Keeping the visible source available until explanatory evidence arrives

A symbol-membership classifier removed 347 of 360 gold external source spans before linking and retained 13. The original grammar covered all 360. These external results and all earlier scans in both corpora are known. This is a mechanism follow-up on previously examined studies. The fixed encoder, complete paper partitions and annotations stay unchanged. The earliest annotated primary explanation provides a release interval. A missing later definition contributes the uncensored reader-visible prefix and a right-censored release label. Annotations measure what an author explains in text; individual reader understanding has a distinct endpoint.

A visible source remains eligible if it has either a committed structural form under the published text encoding or an independently detected term span. The relation model learns in three classes at a visible token: the first authoritative explanation of the first source occurrence, another actual author description linked to that concept, or no explanatory link. The latter includes unrelated sources at the same explanation, true null paragraphs and already redefined aliases. The first two classes jointly teach which source a particular cue concerns. Only the first class makes a first-release prediction. Author-supplied LaTeX and bracket representations are mapped to the same structural roles. Train on 56 source papers; select a release threshold only on the 15 calibration papers using the existing combined trajectory criterion.
