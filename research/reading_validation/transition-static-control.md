# A semantic control independent of contextual encoding

Before accessing the external benchmark test judgments, we fixed a CPU comparison that reads only the input embedding rows for subwords occurring in these articles. This control asks whether a readout's gain over text length and lexical overlap specifically needs a contextual representation. We use Qwen3.5-2B's pinned token embeddings, compressed by a fixed Gaussian projection to 64 dimensions (seed 513). Each source and target vector averages the projected embeddings of visible content-bearing subwords. The readout uses the four lexical controls, sentence position, the cosine, both mean vectors and their elementwise product. The same official training groups, binomial likelihood, 0.01 penalty and development false-alert threshold apply. This secondary control is independent of the prespecified primary pass/fail criterion. It consumes no GPU and never reads a future token's embedding when scoring a boundary. The full embedding matrix is never loaded into RAM.
