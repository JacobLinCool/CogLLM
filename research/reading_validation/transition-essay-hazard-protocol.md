# Starting each explanation mechanism from a validated surface risk

The earlier eight-topic essay experiment found that a 299-parameter binary head and seven unrestricted native heads generalized poorly relative to six lexical and surprisal predictors. This post-result study assesses whether shared linguistic mechanisms can improve that explicit baseline while preserving the baseline's scale. The same independently held essays provide a retrospective test. Fit and calibrate using the previous six-topic / one-topic / one-topic rotation.

First fit the registered surface-plus-surprisal Bernoulli observer. Convert its probability p to a nonnegative base hazard H = −log(1−p). Allocate H across the seven observed essay reasons in proportion to the source probability of each reason among all source reason marks, giving every source topic and essay equal mass. Each reason receives an optional multiplicative change exp(u_r) from the original single-pass causal representations. Standardize scalar features on source. Scale each of the five native feature blocks (four aggregate processing cues, current sentence, earlier context, their elementwise interaction, and the surface block) to unit root-mean-squared block norm on source. Give each block the same slope penalty budget. Each reason contributes an independent probability 1−exp(−H_r). For fully typed responses fit the observed seven Bernoulli outcomes. The one untyped negative-coherence observation constrains only the summed hazard. Use ridge .01 on the residual intercepts and slopes, predeclare zero residuals at initialization, and require a maximum absolute gradient below 10⁻⁶.

The calibration topic fits a single reliability α in [0,1] by minimizing binary log loss on an affine interpolation between the baseline hazard and the total typed-residual hazard. An α of zero returns the baseline exactly. This is a proper convex, one-parameter calibration with no threshold sweep for model selection. Fit F1-optimal thresholds on this same development topic separately for each three arms, as in the preceding evaluation. Include a secondary mode targeting at most 10% of source negative sentences flagged. Report the uncalibrated and calibrated residuals, source weights, true/false alerts, matched article measurements and all eight external topic results. The source corpus measures expert decisions about connections between adjacent stretches of writing. [Original cross-topic protocol](transition-essay-reasons-protocol.md)
