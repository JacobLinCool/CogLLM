# Which person does a Mandarin reader understand at an overt pronoun?

Zhan, Levy and Kehler obtained original Chinese passage continuations from three independent native-Mandarin cohorts. In one condition respondents freely continued a short two-person passage. In the other, one overt pronoun had already been supplied. Separate coders identified the person rementioned and whether the expression was overt, null or a name. The authors’ openly released response tables contain the exact characters each reader saw, and the original stimuli appendix preserves the Chinese. Use their eligible NP1/NP2 and named, overt or null continuations. The target is expressed reference in an elicited continuation. It does not measure reading time, unobserved mental load or spontaneous pronoun alignment during ordinary long documents. [Original study](https://doi.org/10.1371/journal.pone.0237012) · [Original stimuli and data](https://osf.io/t87my/)

Keep both variants of each pair in the same held family. For every external predicate, remove *every* source instance of this predicate, covering both source cohorts, both voice conditions, both prompting modes and the paired names. Thus programs issue 36 leave-verb-out fits and every external response is evaluated exactly once. No external cohort or held predicate can enter fitting, standardization or regularization selection. Source and target trials, participant codes, participant-written free text and annotations are never uploaded to the accelerator. Retain read states at the context end and averaged over the context, from the middle and last backbone layers, so an overt-reference prediction uses information already present before or at the original pronoun. The response is relative to the first and second *mentioned* person, an experimental design shared by these materials. This is not an open-domain Chinese resolver.

## Distinct observation losses on one referent/form distribution

For each bare passage x let n be +1 for the first and −1 for the second person, and let f be +1 for an overt expression and −1 for a name or a null expression in a free completion. Set the joint log utilities to n·a(x) + f·b(x) + n·f·c(x), where each function is linear in the same frozen passage features. A free continuation contributes the four-class cross-entropy on the observed (n,f). A pasted pronoun supplies f=+1 and its human completion contributes a two-class conditional loss on n given f=+1. The resulting overt interpretation odds are 2[a(x)+c(x)] on the log scale. Both losses are convex in the trained coefficients. Equal weighting gives each observation type one half the objective and each source predicate equal weight within an observation type. Use ridge .01 on slopes, unpenalized intercepts, and require maximum absolute gradient below 10⁻⁶.

Compare the coupled readout to an overt-only binary model fitted on the same original prompted responses and to a model that simply treats every remention, free or prompted, as an NP1/NP2 target. Use the same source-normalized feature groups for all objectives. The surface representation combines observable sentence form (被/把, character count, punctuation and overt-gender form) and cosine similarity of signed-hashed character unigrams/bigrams. The native representation averages this surface kernel with equally weighted cosine kernels for mean and final-context middle and final layer states. Use only the shared bare input when computing context features, so supplying a pronoun acts as the observed conditioning event. Use a separate researcher-information control with the published semantic verb class plus syntactic structure; it receives annotation unavailable to an unknown-passage observer. Report head-to-head differences among the coupled, independent and pooled objectives, without tuning the chosen kernel or regularization on the held experiment.

Primary outcome is individual pronoun-interpretation log loss in the entirely external cohort averaged over structures and verbs. Report choice accuracy, Brier score, calibration bias, source convergence, and the IC-1 minus IC-2 verb difference in first-person choices within each construction. Bootstrap whole predicates and independent external readers together. Secondary endpoints are the matched free-trial joint log loss and difference in rementions from the canonical active to 把 condition by verb class. Reproduce the published Bayesian, Mirror and Expectancy numerical controls against the released counts, clarifying that those methods observe same-item human free continuations. Report participant-written completions only as aggregate outcomes. Keep all results research-only for the Chinese writer interface.
