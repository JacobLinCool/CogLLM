# When can an editor trust a suggested antecedent?

This analysis was specified before any reader-click or GAP pointer forecast was inspected. The primary [reader-click experiment](transition-pointer-protocol.md) returns an earlier word at every eligible pronoun. An author could instead see a link only when the pointer concentrates enough probability on one earlier word.

For the fixed headwise native pointer and the fixed lexical/POS control separately, use the largest conditional probability of any earlier word as confidence. Break ties uniformly when evaluating whether a reader’s selected phrase contains the suggestion. Use thresholds 0.10, 0.20, …, 0.90 with inclusive comparison. Each threshold estimates the probability of matching an independently chosen reader’s clicked span, conditional on choosing a query where the pointer offers a link. Average readers within pronouns and pronouns within source works; compute precision as the resulting probability of a correct link divided by the probability of offering one. A large linked region counts only if the single suggested word lies inside that literal region.

Choose a threshold using released silver **development** articles only. Exclude thresholds with fewer than 15 linked pronouns or four independent development works. Over all remaining thresholds form a simultaneous one-sided 95% lower precision band using 10,000 whole-work bootstrap draws and the maximum centered error. In a draw with no suggestions assign zero precision for this conservative calibration calculation. Choose the largest source coverage meeting lower precision 0.70. If multiple thresholds yield the same coverage, take the larger threshold. If none qualifies, report the absence of a selected high-precision policy. Source and transfer documents differ in genre and publication history, so selection supplies a calibration experiment rather than a coverage guarantee.

Freeze the threshold before loading external clicks or name regions. Evaluate proportion of eligible original pronouns for which a link is offered, precision among suggestions, and false suggestions per 100 eligible pronouns as 100 times the probability of a wrong offered link. Report the absolute number of eligible and linked pronouns, reader clicks and articles and whole-article 95% intervals. Show always-suggest and fixed 0.50-confidence reference policies regardless of selection. Apply any selected silver threshold unchanged both to [independent game clicks](transition-pointer-protocol.md) and to [GAP's earlier human-verified single name](transition-pointer-gap-protocol.md). The latter asks whether the returned word is literally inside the annotated target name under a different observation protocol. A valid game link to another mention of that same referent can be a miss on GAP.
