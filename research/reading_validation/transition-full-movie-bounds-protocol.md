# Recovering all movie words under ambiguous human span locations

The earlier movie analysis discarded a complete annotation segment when one human character-reference span string appeared in several locations. This supplementary sensitivity analysis uses every eligible original movie word and the previously fixed Qwen and NER policies. It is retrospective. The earlier unambiguous scores and the public source are known. No model, threshold or candidate location is selected using its external score.

For every recorded CharE string, construct every literal occurrence in its own annotation segment using the existing Unicode normalization and overlap rule. Every released string in this sample has at least one occurrence. Treat each record as denoting one of its literal occurrences, with the binary outcome equal to the union of the selected word sets. Enumerate each segment's complete set of possible word assignments. A selected original span may cover several words. Reduce duplicates only when they produce identical word labels. If pooled votes chose different occurrences before release, the analysis is conditional on the one-location-per-record assumption. Also calculate unrestricted bounds where any matching words can be marked as long as guaranteed labels remain marked.

Compute the attainable minimum and maximum thresholded precision, recall, F1 and false-positive rate over all segment decisions by minimizing or maximizing the numerator minus a trial ratio times its denominator independently within each segment. Compute the exact positive-count envelopes at every distinct score across all possible assignments. Bound average precision with these envelopes and variable total positive counts, preserving exact tie denominators. Test implementation against exhaustive assignments on small cases with ties and duplicated locations. Compare models using conservative differences between their bounds. Report ascending-score and descending-score bounds without training or deciding among alignments. The ranges quantify identification uncertainty conditional on these 39 movies; they do not represent sampling uncertainty.
