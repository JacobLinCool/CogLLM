# Fixed-embedding control for the Spanish clue test

Before native feature extraction and before examining any human responses, add a comparator that uses the average normalized input embeddings of earlier native tokens, with the same Qwen tokenization and the same complete word positions. Its cosine with each prospective category or answer's onset embedding measures lexical co-occurrence without tracking contextual language states. Record it at each of the 21 printed word boundaries and at the end of the unmodified third sentence. Compare category selectivity and force-choice NLL with the contextual scores. A second explicitly local comparator computes the category's mean log probability across its actual native pieces once presented. Remaining studies and exclusion rules follow the primary protocol. The source lexicon lists some lemmas where both exposure and test used inflected spellings; preserve the literal cross-archive matching specification in the main study.
