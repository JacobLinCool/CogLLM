# Testing whether partial-span supervision depends on the human response type

Repeat the three marginal-loss fits on the original Qwen features for two additional recorded human response types. RefE marks an event or object introduced as if already known. CorefE marks an unclear reference. The source RefE strings rarely repeat, whereas the source CorefE strings often include repeated personal pronouns. The comparison tests whether the advantage is larger for the more heavily coarsened outcome. The original movie labels, the Gemma movie results and the annotation-format audit are known. This does not introduce a new independent reader sample.

Retain the same training titles, development cut, regularization, features, gradient checks and coarsened external log-loss metric as in the registered character study. For RefE enumerate literal exact occurrences. For CorefE require Latin letter or digit boundaries on an annotated string's alphanumeric edges. The label definition designates an unclear referring expression, so “he” inside “the” is ineligible. If any record has no admissible occurrence, exclude that whole segment for this outcome and report its fold and count. Use exact sets of word masks; collapse repeated placements that induce an identical word outcome. A union-of-bitmasks dynamic program computes the unique configurations without enumerating the Cartesian product of raw choices. Compare held-out word and broad identified outcomes on identical supports within each response type. Explicitly report unsupported solutions and sparse human word counts. Previously inspected movie scores are acknowledged.
