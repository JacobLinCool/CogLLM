# Does the same printed word change reader expectations differently across paragraphs?

The original Provo external scores, paragraph-controlled word-form predictions and English UCL within-word rankings are known. This additional observational assay asks a different question of the real multi-response longitudinal signal: given two occurrences of the identical case- and punctuation-sensitive printed word in different Provo paragraphs, can the model identify the larger measured increase in the disagreement of the next predictions? The same word can close off many continuations in one context and allow a wider set elsewhere. Holding its literal form constant rules out a fixed difficulty assigned by a dictionary. The contrast remains sensitive to earlier lexical and contextual differences. The result is a diagnostic in a previously evaluated corpus.

Use every originally denominator-verified adjacent pair, with the reported human change and the already fixed per-occurrence predictions. Do not fit another outcome head. Within each exact original word type construct all pairs across distinct original paragraphs. Order by the difference between the signed human updates (with a decrease treated as smaller than an increase). Exclude ties within 1e−10, both genuine and floating-point, and give predicted ties half credit. Average concordance within each lexical type, then average across types so a frequent function word cannot dominate. Primary benchmarks are .5 for a constant lexical score, the raw single-pass Qwen prediction and its source-fitted population calibration. Separately compare the previously fixed cross-fitted print-form predictors, with their learned response-free inference information. Include every qualifying repeated form and give a stricter sensitivity using occurrences where both the present and previous forms were clean lowercase alphabetic tokens under the previously registered segmentation. Report eligible pairs, types, paragraphs and unique occurrences. Use 4,000 paired Bayesian bootstrap draws with independent unit exponentials on lexical type and original paragraph. Each lexical type retains positive weight, and each pair gets the product of its two paragraph weights within that type. No new text, participant, language model call or fitting data enters this assay.
