# Observation-specific training for rewrite preferences

Let each item $i=(o_i,v_i)$ contain a source text and a candidate rewrite. For each aspect $a$ in simplicity, meaning preservation, fluency, and the separately measured overall-quality response, define a score $s_{ia}=x_i^\top\beta_a$. The source and candidate are encoded separately, with one causal Qwen3.5-2B forward per distinct displayed passage. The fitted score uses neither an annotator ID nor the name of the system that produced the rewrite.

The edit model measures word count, sentence splits, lengths, word frequencies, lexical and stem recall in both directions, sequential edit segments, and preservation of numbers, names and negation. The aligned model adds the mean and lower tail of contextual nearest-word cosine similarity in each direction, observed CompLex difficulty of retained and unmatched words, differences in the existing ReadMe++ predictions, and terminal-state similarity. The full model also includes 24 terminal principal-component coordinates, their source-to-revision signed changes and their absolute changes. The components are fixed from the earlier difficulty fit. Qwen token states are normalized and projected using a data-independent 96-dimensional orthonormal matrix. Only source words whose end matches a native token boundary enter the neural word alignment. Each candidate retains the same lexical edit measurements even if a word has no certified token end. [Feature implementation](revision_features.py) · [Native forward and coverage](revision_forecast.py)

For a grade in study $d$, let $y\in[0,1]$ be the original mean direct-assessment rating divided by 100. Its fitted logit is $z=s_{ia}+b_{da}$. For a comparison of $i,j$, use $z=s_{ia}-s_{ja}$. For a direct ASSET vote use the fraction preferring $i$, allocating half a vote to an explicit human tie. For the derived preference between candidates graded in one source family use $y=\mathbb{1}[\bar y_i>\bar y_j]$ with weight $\min(1,|\bar y_i-\bar y_j|/0.2)$, omitting ties. The fractional Bernoulli loss is a bounded-scale working objective. A single continuous rating is not a count of independent binary trials.

$$
L=\sum_h w_h\{\log(1+\exp z_h)-y_hz_h\}
 + \tfrac{0.012}{2}\sum_a\|\beta_a\|_2^2
 + \tfrac{0.006}{2}\sum_a\|\beta_a-\bar\beta\|_2^2.
$$

Weights give each eligible development source equal weight within its study, endpoint and observation type. If the same study supplies both grades and derived preferences for an endpoint, each type receives half the study–endpoint weight. A direct head for the overall-quality auxiliary study receives weight 0.35 relative to one unit for a directly matched endpoint, before global normalization. Continuous feature blocks are centered and scaled within the training fold, with a dimension-dependent ridge scaling for wide feature blocks. L-BFGS must report successful termination and a maximum absolute training gradient below $2\times10^{-5}$. We log each fitted fold including the full-data refit. [Fitting and forecast sealing](revision_fit.py)

For each aspect, five source-family holdout folds produce out-of-fold edit and full model scores. Choose $\alpha_a\in[0,1]$ to minimize the same paired loss on these development-fold predictions, then freeze $s_a^{*}=(1-\alpha_a)s_a^{\rm edit}+\alpha_as_a^{\rm full}$. This permits the human judgments in each task to determine the influence of Qwen features beyond the trained edit comparison. Fit the two models again on all development families before applying the frozen weights to SimpDA 2022. We record each fixed comparator and the mixing weights even if one weight reaches zero.
