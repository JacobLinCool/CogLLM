# Which previously introduced concept does the next explanation define?

The earlier causal experiment localized both early and late cues in twelve authored contrasts when given the span of the unclear concept, and in zero when given a whole automatically delimited sentence. This study asks whether concept spans and their own definitions can be learned directly from human-annotated textbook prose. A supplied-term setting isolates link accuracy; an article-only setting must also find the term. We test transfer to an existing experiment in which readers rated scientific terms before and after reading an abstract. DEFT annotators mark where a document explains a term. Guo's researchers observed changes in readers' familiarity at abstract level. Neither study measured the token at which a person felt relief. [DEFT](https://aclanthology.org/W19-4015/) · [Shared task](https://aclanthology.org/2020.semeval-1.41/) · [Guo et al.](https://aclanthology.org/2024.naacl-long.255/)

Remove the numbering added by the corpus, retain ordered visible tokens and punctuation, normalize inter-token whitespace and trace each source tag back to its character span. Count any malformed windows, missing or noncontiguous tags, lost cross-window relations, unusually long cases and duplicate normalized texts by reason. A positive link is a contiguous primary definition directly referring to a distinct earlier contiguous primary term. Fall back to no link annotation when the direction or entities are ambiguous. Glosses appearing before the term enter description separately.

## Models

Qwen3.5-2B reads the original text once with a causal mask. Store projected middle and final states and the native mean and maximum global attention between token positions. Use native offsets to align reader labels. The article-only span proposer evaluates contiguous one-to-eight-word spans when their final complete token becomes visible, using lexical information and the causal internal states. Train on exact annotated term spans versus negative spans, with source-balanced sampling and development-only regularization, and report how many true spans lie outside the allowed grid.

The second head seeks evidence that a later span explains a given earlier term. It observes a sequence of individual causal word-end states and their prefix relationships to the earlier term. Human definition labels define an **interval** in which supporting text becomes available; they give no gold mental event at the first or final word. Learn differences between a true term and a different previous term at its own definition, and between a definition interval and a comparable earlier or later interval without that definition. Fit on the training disciplines only. Include population position, phrase length and exact lexical recurrence as comparisons, alongside trainable context-free lexical and contextual models. For article-only evaluation, rank all eligible term spans and examine the highest-scoring proposed spans. Report exact span AUPRC and rank, linked evidence allocation and the rate of detected correct terms separately from the supplied-term result. Only an end-to-end matched term and definition can count as an article-only success.

## Decisions

Primary structural endpoint: for each held-out later definition with at least two earlier human-marked term candidates in the same window, does the model select the correct antecedent when the definition finishes? Evaluate the same queries with human-supplied candidate terms and with clusters of automatically proposed candidates. Secondary localization compares integrated evidence inside a real definition to a matched interval elsewhere in the same case for the same term. For the fully automatic primary, award exact-span credit only and report upper bounds from the span proposal stage. Bootstrap by textbook source file and report biology, physics, combined, sample size and the number of independent groups. A higher absolute score than the topical-position and lexical baselines plus a strictly positive lower paired interval is required to claim added contextual value.

External behavioral endpoint: within the same scientific abstract and reader, among terms with the same initial familiarity, ask whether the term receiving a higher peak of later explanatory evidence gains more familiarity. Ties in human change carry no ordering information. Score with pairwise concordance with model ties at half, average by paper, and obtain 95% paper-cluster bootstrap intervals. Compare to the term's proposal score at mention, a position/remaining-length control and the fitted DEFT lexical link model. Also publish independent-reader counts and an exact or bootstrap interval where supported; low eligible counts can make this secondary, reused-corpus test inconclusive. Do not equate correlation with the causal benefit of a rewrite. A historical cue replay will report correct-target localization without using cue labels for model selection. All positive and negative outcomes will be written to the evidence record.
