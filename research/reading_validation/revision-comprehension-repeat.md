# Reader variation on identical paragraphs

Five pairs of system conditions in five source articles presented byte-identical text for the same paragraph and the same three questions. This pilot-sized sensitivity check was specified after inspecting presentation text, before opening the participant answers. Across these fifteen question presentations, report agreement on correctness and on explicit availability of an answer, alongside the corresponding counts of disagreements. Exclude ambiguous duplicate system assignments. Identical text supplied to the frozen predictor must receive identical model scores. This small convenience sample can demonstrate between-presentation variability even with identical stimuli. It cannot estimate a human performance ceiling for the full study. The release lacks reader identifiers for direct verification of rater assignments. [Study design](revision-comprehension-protocol.md)
