# A reader may decline to link a pronoun to the preceding text

The directly observed pointer result is conditional on players choosing an earlier entity. An editor lacks that information when opening an article. Use the larger source-game population to check the already frozen .80 threshold without changing any weight, source threshold or decision rule. Conditional performance and prior raw gold-game disagreement counts are known. This is a retrospective applicability audit with previously unscored negative choices. [Conditional pointer](transition-pointer-results.md) · [Public schema](https://github.com/dali-ambiguity/Phrase-Detectives-Corpus-2.1.4)

For each certified visible personal-pronoun word with an earlier word, use the original game markable and the independent annotation mode. Require one visible unedited markable and at least four different eligible annotators who made an unambiguous literal choice. Keep discourse-old noun-phrase clicks (DO), discourse-new (DN), predicative (PR) and nonreferring (NR) answers. Drop a voter's conflicting repeated choices. Drop a location with a genuinely unmappable DO response or a nonpreceding proposed region and count exclusions. Count each original person once at a position. The absolute correctness of a suggested earlier word is the fraction of all such voters who chose a literal preceding region containing it. Non-DO voters count as incorrect for *any* proposed link. A pure non-DO location is retained. Never replace a non-DO vote by an artificial earlier word.

Compute precision, coverage and wrong suggestions per 100 eligible pronouns using the existing article-equal calculation, then resample distinct source works while grouping the Grimm excerpts. Separately report positions with any non-DO response and positions where a majority found no preceding referent. Give counts of all 757 forecast pronouns, the verifiable subset, independent people, placements, non-DO choices and false suggestions. For eligible-form occurrences without enough original evidence, provide sharp sensitivity bounds on overall precision and error frequency across the 757 positions by allowing each unauditable suggestion to be either correct or incorrect. These bounds use equal pronoun weights and therefore have a different estimand from article-equal observed performance. Retain the whole negative population even if this weakens the writer's scope.
