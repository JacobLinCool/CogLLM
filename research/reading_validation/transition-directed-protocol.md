# A directed compatibility judgment with a single causal encoder pass

The first Carter test exposed a weak representation-to-rating mapping. We designed a second candidate after seeing those Carter results. Its evaluation on Carter is retrospective. We locked its design before evaluating CoheSentia or DECOR responses. The original single-pass, article-only supervised transition model remains the primary candidate. The directed comparator presents additional fixed metatext to the model. Its psychological exposure therefore differs from the reader's.

One deterministic Qwen chat serialization exposes the original text in order. After each supplied sentence the input opens an empty assistant response with thinking disabled. At its last input token we take the difference between the tied-vocabulary logits for 'No' and 'Yes'. Blank responses contain no predicted token, no sampled word, and no human answer. One causal backbone pass covers every sentence in an article. Source text provided as intervening background and the study's title remain visible. A 2k-token limit is checked before execution. The full instruction, role delimiters and output-token checks are part of the forecast source. There is one prompt and there will be no prompt search. A one-coefficient logistic calibrator uses only the designated CoheSentia training families. Alert thresholds, comparisons and uncertainty follow the external protocol. We will retain the raw uncalibrated logit differences as an additional transparent diagnostic and publish the text-model and directed candidates separately. The latter never consumes the former's hidden states or scores at inference. If both candidates run during evaluation, each uses one independent encoder pass per article. No combined two-pass predictor is eligible for the single-pass claim.

During input-schema validation on training stories we found two annotator–story records with reason keys outside the authors' valid zero-based sentence-index range. We exclude an entire local annotator–story record when it contains any such key. The corresponding sentence boundaries remain eligible when another rater supplied a valid response. We will report exclusions in each partition. The DECOR rewrite file contains two original context–sentence pairs absent from the main detection file. The released rewrite records include their original text, so we process those exact source passages separately for the edit comparison.
