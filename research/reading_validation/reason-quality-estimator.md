# Predictive distributions for direct and comparative judgments of adequacy

From the two sources, reserve 15% of Darmstadt essay families and three Webis topics for choosing source distributions, plus 20% of Darmstadt families and four Webis topics for within-source test. Keep all 16 Dagstuhl expert topics out of these fits. Remove source debates whose materials occur under multiple topics, their incident comparisons, and any train–test sources sharing at least 20 normalized consecutive words. Assign groups deterministically using a hash fixed by this analysis. Source-absent expert external transfer is primary. Compare each new continuous score against all three experts' mean local-sufficiency score using Spearman correlation and concordance of distinct mean ratings within each topic. Report the non-independent differences using the same resampling of whole topics and treat the three named expert roles as a fixed panel. Bootstrap by topic, with a sensitivity grouping source materials by debate side. For a human reference, compare each expert with the other two on the same passages.

For each unmarked passage, retain the number, lengths, arrangement and lexical overlap of its visible sentences, marker words, hashed lexical features and their recurrence. Add prefix-derived surprisal and numerical states at each completed sentence, including its maximum and most recent evidential relation to an earlier sentence. Summarize mean, extremes and end state at the final observed paragraph boundary. Fit the directly observed binary votes using their aggregated binomial log likelihood. For an A/B/tie judgment, assign logits equal to half the difference of the two passage scores, its negative, and a learned tie intercept. Each passage can still be read in a single forward. Preserve the actual number of ballots, balance source essays/topics, and provide the registered controls with the same outcomes. Integrate two heterogeneous source likelihoods through a common coefficient, allowing a source-specific deviation, then compare with private coefficients. Standardize all dimensions on source training texts, and use fixed ridge shrinkage for each standardized predictor. Separately estimate how much to use each readout from its actual source calibration opportunities. Use the direct sufficiency direction for external testing. A high source probability means that similar original jurors found the reasons sufficient. No source probability equals a three-point expert score.

For the secondary study of adaptation, rotate four disjoint topic folds in the expert corpus. Use the remaining topics' actual ordinal votes to estimate two ordered cutoffs, a coefficient for the external source representation and a regularized adjustment for the local expert endpoint. Compare with the same model starting from raw article features alone and a calibrated source-score-only model. Report all three prospectively chosen measures. The whole-paragraph likelihood supplies no word-level evidence for where a reader got lost.
