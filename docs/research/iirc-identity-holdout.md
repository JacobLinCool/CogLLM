# IIRC evidence matching within the same passage

IIRC, the original linked-file held-out set contains 452 paths, measurable for evidence arrival time. It lacks pairings of different questions on the same file pointing to different evidence. A supplementary control was derived by extracting entire connected article families from 37 strict pairings of the original training material, yielding 33 held-out groups. A total of 114 paths were excluded, with 72 appearing in the 37 primary control pairs. The original official held-out 452 paths remain sealed. [Original evidence interval specification](iirc-linked-evidence-protocol.md)

For each group, the two paths read to the same link body, with the reading stop being completely identical relative to the link body start. The prefix and explicit anchor originate from different IIRC queries. The evidence segments marked by human annotators do not overlap, and their full-text reading stops differ. Scoring simultaneously checks both directions. The negative log-likelihood of the original evidence interval versus the swapped evidence interval is computed separately for each path's risk distribution. A lower average error in the original interval indicates that the model selects the corresponding evidence position based on the original path.

Re-fit three readouts from frozen Qwen features using 3,240 original training paths held-out. Perform 10,000 pair resamples across 33 article groups. Formal thresholds consist of two items: the explicit anchor readout's NLL reduction relative to the original interval's NLL must have a 95% interval lower bound above zero. the paired difference relative to the same-path body readout must also have a 95% interval lower bound above zero. Position matching retains the same reading stop and scale. Additionally report the proportion of 37 groups where both paths favor the original evidence. This comparison measures whether the original segment and anchor can help distinguish textual evidence. It still uses evidence segments provided by another batch of respondents.
