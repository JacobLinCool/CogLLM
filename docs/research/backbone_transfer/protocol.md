# CogLLM's three backbones single forward pass comparison

Fixed raw data, predefined observation positions, split and readout forms, comparing the current Qwen3.5-2B, LFM3-1.7B-Base, and Gemma 4 E2B. All three models read the same original text using their respective tokenizers, extract the current prefix state from the frozen text backbone, and re-fit their readout heads. A single forward pass retrieves all reading stops for the document. Additional truncation and post-processing computations serve only for causal validation and are not included in the formal content score. The full sequence is fed into the causal backbone without text generation or decoding. All three groups are executed on a Colab L4 instance. Official snapshots, software versions, and numerical precision are included in the execution manifest. The character-level reading stop is determined by the source. The main text is preserved verbatim. Each model first checks whether the reading stop falls at the exact token boundary in the full-text encoding and aligns with the independent truncated token prefix. CompLex additionally verifies that the tokens covering the target do not cross into other non-whitespace text. The split identity uses the original assignment, with the primary comparison fixed at the common position that all three models can precisely read out. The intersection is established based only on text and tokenization before reviewing results. PLABA's rewrite magnitude includes only groups where all aligned sentences are retained in both versions. Frick's full event path requires all validated reading stops. if any version lacks the required reading stop, that model's same-set comparison cannot be validated. Report the misaligned data volume and retained denominator for each model.

Frick subword preprocessing revealed that the LFM3 end-of-sentence token simultaneously covers two original line breaks between paragraphs, with the original character-level reading stop falling within that token. Two Frick readout types were never issued from text without reading and tokenizer priors: the first retains the original character-level reading stop, while the second samples after the same two line breaks for each backbone, requiring no consumption of the next non-whitespace character, thereby maintaining the original reading stop at the end of the sentence. Human reading stops, the original text, and the split version remain unchanged. Character-level reading stops from both groups are sampled together in each forward pass for every document, with independent fitting and reporting. The two contrast prefixes share identical information up to the last non-whitespace character. line breaks alter the representation and are interpreted separately. This rule is fixed by the original text's subword verification before obtaining any new model output.

Predictions from the three backbones utilize only human annotations or aggregations from the same training fold. Model training does not input test responses, answers, or document target values. Fitting for PLABA and CompLex follows their respective original scales, while Frick is fixed to the observation time window per document. All results rely on existing study data. thus, this constitutes a cross-backbone replication comparison. The held-out endpoints of the multi-source data have been scored and cannot be treated as a novel study or pretraining corpus clean-verification.

## Direction, effect, and interpretation

On the intersection, we compare each model's gain over the common baseline and the paired difference of alternative models relative to the current Qwen. We use the original material groups or reader × material re-extraction at the 95% confidence interval. PLABA compares the difference in scores between the vernacular version and the original version against the same-batch human alignment group. Frick applies the ±10 percentage point tolerance for the effect condition established earlier. We cannot substitute effect magnitude with direction, nor replace the per-item distribution with an average fit. RPS is the cumulative probability error of a five-level distribution, MAE is measured on the CompLex original 0–1 scale, and NLL is measured in nats. All three errors are lower is better. This round of comparisons freezes the same-structure readout under feature constraints, while separately verifying the peak memory, throughput, numerical precision, and failure status of each backbone.
