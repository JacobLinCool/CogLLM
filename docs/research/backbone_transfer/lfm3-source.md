# The weights and text forward pass of LFM3-1.7B-Base

The fixed-author version 7bca5038823c0d0f14efe06439109354a10e014c. Weights, original settings, tokenizer, and three native Python modules are all verified via SHA-256. The model backbone consists of 24 layers, with an hidden state width of 2,048. Among them, 13 layers employ causal short convolution, 5 layers use sliding window attention, and 6 layers utilize global attention. The readout utilizes the final normalized hidden states, with autoregressive decoding and KV caching disabled. The published configuration lists Transformers 5.12.1, but the model code requires a kernel decorator unavailable in 5.12.1. Transformers 5.17.0 provides the symbol. Its general configuration validator renames the author's `conv` to `linear_attention` and inserts top-level RoPE defaults even when each attention type already defines its own complete RoPE parameters. When loading the verified local configuration class, this study limits RoPE normalization to the two existing attention types, removes the automatically inserted top-level defaults, and checks the layer names with the author's architecture validator. Verify that the complete 24-layer order and both original sets of attention parameters match exactly before and after model loading. The author code files and tensor weights retain their original bytes. [Extraction and compatibility checks](../../../research/backbone_transfer/extract.py)

All candidate sealed snapshot states are forward-passed in FP32, retaining only a single forward pass result per paper. The LFM3 convolution width is 7. The author's implementation supports native Triton width-7 causal convolution when available. otherwise, it employs PyTorch depthwise convolution with a left-side receptive field. The execution runs offline with the Hub kernel load disabled.
