# Timkey word-by-word eye-tracking results

OneStop-calibrated CogLLM eye-tracking readouts showed that in Timkey's four pre-specified primary comparisons, three effects had the same direction as human but with smaller magnitudes, while the first-leave-back effect had the opposite direction. The negative log-likelihoods for all four sequential responses were higher than the control using only word length and position, and the 95% material resampling intervals for all four models minus the control were above zero. Each endpoint covers 72 matched pairs, with differences calculated as ambiguous minus control. Resampling by material ID retains observations of the same ID across constructions, with interval conditions restricted to the observed reader population. For each human effect, the interval is above zero. for each model minus human effect, the interval is below zero. Negative log-likelihood is computed per endpoint based on valid observations, where lower values indicate better fit. [Results by endpoint and construction](../../../research/results/union-observations-formal-l4/timkey/scores.json)

L4 performed a forward pass on each of the 339 OneStop documents, yielding 36,983 verified word-final prefixes. Eye-tracking head fitting was performed only on valid responses from the initial OneStop reading. the four endpoints yielded 472,694, 357,562, 115,132, and 115,132 observations, respectively. The final fitted maximum gradient was less than 3 × 10⁻⁸. When held-out in batches, CogLLM showed relative improvement in word length and position matching compared to the baseline. This held-out evaluation belongs to the eye-tracking head. Prior shared-state training utilized reading comprehension data from the OneStop family. After Timkey's 288 word positions were individually verified against the author's independently published word list, the Huang SAP shared material was retained in its extracted state. Timkey's responses were used for scoring only after the predicted sealed snapshot. Results indicate that the frozen shared state, combined with OneStop calibration, remains insufficient to replicate the inspection probability or extension magnitude for this set of unseen materials. This validation scope pertains to eye movement responses within classic syntactic ambiguity constructions.
