# Jointly trained ensemble human-validated sealed snapshot

This sealed snapshot is defined at the material family level. Inputs for training readout, model selection, weight determination, and data augmentation exclude all original texts, variants, new stimulus samples, and derived annotations listed in the exclusion list. A sealed snapshot indicates that the research purpose and source version are locked. Since the final scoring has not yet been executed, predicted outputs, scaling transformations, formal statistical thresholds, and non-overlapping manifests must remain fixed prior to reading the final sequential annotations. Published overall findings from existing articles can be used to select the comparisons to be tested. [Training Specifications](../training-protocol.md#全資料聯合訓練與關鍵效應封存)

The SAP author materials, job scripts, and Timkey post-processed eye-tracking RDS have been cached locally and verified against the author's SHA-256. Huang's classic garden-path construction trial files were downloaded from the author's publicly accessible Drive (as listed in the fixed Git changelog), and their SHA-256 was recorded. Anglin's stimuli, follow-up questionnaires, analysis code, and per-trial response files were verified against their existing SHA-256. the original author's OSF project specifies a CC BY 4.0 license. The Traditional Chinese MECO 52 presentation images, raw word-by-word tables, response data (RDA), and documentation were verified against the author's SHA-256. The word-by-word table enables unique reconstruction of 2,095 words across 12 main texts. The standardized main text hash is listed separately in the local sealed snapshot. The training set was constructed using positive registration of valid sources and endpoints, with additional exclusion based on this family list. Before formal model validation, family overlap verification will be performed on the actual complete text, and reader identity verification is limited to sources containing cross-trial linking keys.
