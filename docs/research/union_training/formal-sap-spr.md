# Position-wise self-paced reading transfer validation

We fit the region reading-time readout on Paape and Vasishth's English bidirectional self-paced reading data and use the fixed readout to predict Huang SAP English forward-only word-by-word reading times. SAP validation covers three classic temporary ambiguities: main verb versus reduced relative clause, direct object versus sentential complement, and transitive versus intransitive. Each construction includes all 24 matched ambiguous and disambiguated pairs. We compute condition differences for the same surface word at the authors' designated disambiguating word and the following two words. Each version supplies only text and observation stops. One causal forward pass extracts features at all registered stops. [Paape and Vasishth materials, measures, and analysis](https://osf.io/6uv37/) · [Huang et al., methods, Table 3, and Fig. 2](https://tallinzen.net/media/papers/huang_et_al_2024_jml.pdf)

The development endpoint is the first-pass region reading time, `FPRT`, from the authors' `data_brms.Rda`. We retained their `crit`, `spill`, and `final` labels and the open interval of 150–5,000 ms. We align display positions using the stimulus, preceding-context condition, disambiguation, and original region index. At each position we averaged valid readers' log reading times in milliseconds, then fitted a fixed ridge readout from the frozen joint model's shared `processing` state and log region word count. All retained positions receive equal weight. We center the target and features using their development means, penalize slopes only, and use a fixed penalty coefficient of 0.01 in the mean-squared-error objective. We compute `processing` using the original hidden-state normalization. We lock the readout after fitting and generate SAP predictions at that point only. SAP stimulus group assignments, questions, answers, annotations, and responses provide neither model inputs nor data for fitting the readout. [Authors' code and development data](https://osf.io/6uv37/) · [Joint readout](../../../research/union_training/fit_observations.py)

Position traces retain only the material and word position fields from the author's preprocessed data, cross-checked against an independent material table. The second spillover in NP/Z materials 14 differs across versions. this pair is excluded from the effect at that position, while all other reading stops are included. A sealed snapshot is taken for position-by-position prediction, model readout, inference setup, and data hashing. Subsequently, the SAP at the specified position is read out sequentially. Reaction times exceeding 7,000 ms are excluded from the original study, with values constrained to be finite and greater than zero in milliseconds. For each construction and position, the average log time of the ambiguous version is subtracted from the control version, then averaged with equal weighting across materials. Predictions use the same paired difference. development calibration values are used only for directional comparisons. [Author data and preprocessing](https://github.com/caplabnyu/sapbenchmark) · [Original study's time ceiling and log reading-time analysis](https://tallinzen.net/media/papers/huang_et_al_2024_jml.pdf)

The primary comparison is at the disambiguation word site, with three constructions reported sequentially. Two spillover effects are pre-specified diagnostic locations. Using 2,000 material family resamples with a fixed seed of 1729, the condition is reported at the 95% resample interval of the observed reader sample. When the human effect interval contains zero, that direction is retained as undetermined. otherwise, the model direction is reported as consistent or opposite. This test examines whether the readout can replicate direction and location across studies, preserving differences in bidirectional/unidirectional reading and multi-word/single-word measurement. Timkey's eye-tracking, SAP final interpretation, subjective load, and millisecond effect magnitudes require corresponding measurement and fixed procedures.
