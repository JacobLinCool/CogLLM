# Observation Models for 24 Human Data Sources

The revised joint-training pipeline integrates 24 sources and 62 observation blocks. The full development bundle contains 27,167 inputs and 164,220 Qwen observation stops. Each study's specification links to the original study and released materials and records where the observation occurred, its valid denominator, the likelihood used, and the shared projections it can update. [Sources one through twelve](observation-contracts-a.md) · [Sources thirteen through twenty-four](observation-contracts-b.md) · [Source registry](../../../research/union_training/observation_registry.py) · [Full bundle verification](../../../research/results/union-observations-l4/geometry-verification.json)

The PLABA ordinal sentence-rating head uses both the end of the rated sentence and the end of the full visible article. The original Frick keypress records yield 1,800 first-report trajectories, including censored trajectories, and 2,866 sentence-level judgments after the first report. For OneStopQA and RACE, the model derives the probability of a correct answer from the answer-choice distribution and the index of the correct option. For Rodger, it jointly fits the reader's ratings at two stops in the same stimulus and derives the change from the two predictions. The revised outputs also support recomputing 36 existing development effects from the same data for diagnostics. ## Independent verification

All 65 files in the full bundle can be rebuilt from source with byte-for-byte agreement. A CPU run with synthetic representations exercised the full observation dataset, and an independent implementation recomputed 169,025 prediction rows and the results for 57 blocks with development rows. Gradient tests covered all 62 blocks and confirmed that gradients reached only the registered shared projections and measurement heads. We also verified that the Frick first-event probabilities used only the observation stops the reader reached and that the PLABA retrospective ratings used both registered stops. [CPU verification](../../../research/results/union-observations-l4/cpu-smoke-verification.json) · [Gradient routing verification](../../../research/results/union-observations-l4/shared-routing-verification.json)

The initial full Colab session was lost during representation extraction. No verifiable weights were recovered, and release of that L4 was confirmed. We then used a deterministic sample that retained all 24 sources, 62 blocks, and their training and development assignments. The sample contained 939 complete observation rows, 688 inputs, and 1,074 observation stops. The second L4 completed the causal Qwen forward pass for each input and 12 readout-training epochs, totaling 192 updates. All 12 prefix checks passed. An independent implementation recomputed scores for 57 development blocks, and we verified artifact hashes and hardware release. The sampled scores verify the execution path only. [Full-run attempt](../../../research/results/union-observations-l4/full-run-attempt.json) · [Smoke test with Qwen](../../../research/results/union-observations-l4/l4-smoke/model-verification.json) · [Hardware release and artifact verification](../../../research/results/union-observations-l4/l4-smoke/run-verification.json)

This run computed endpoints at the resolution of the original measurements, including words, sentences, presentation stops, and paired conditions. The tests verified that multiple observation types could update their corresponding shared projections. The formal study-level holdout had yet to be scored at that stage. Frick records the first report of a contradiction. Testing the token-level resolution of the same spontaneous question in an article requires human observations that track that question over time.
