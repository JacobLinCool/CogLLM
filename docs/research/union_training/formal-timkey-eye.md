# Timkey word-by-word eye-tracking transfer validation

This validation uses Qwen3.5-2B and the frozen shared `processing` state from epoch 31 of joint training. Fit the measurement readouts using only English word-level eye-tracking from OneStop. Timkey and Huang use the same sentences, so their evaluations form one material family. Both the SAP and Timkey responses were held out from readout fitting, threshold setting, and model selection. This protocol fixes four eye-tracking endpoints. Huang's self-paced reading results follow their existing protocol. ## Four measures

OneStop retains `IA_FIRST_FIX_PROGRESSIVE=1`, `IA_SKIP=0`, and `IA_REGRESSION_OUT` as binary values and `0 < IA_FIRST_RUN_DWELL_TIME ≤ 2000` as word-level records. The final word of the paragraph is missing the next text region, so the readout excludes that position.

| Measurement | Only under which observation calculation loss | Readout and loss |
| --- | --- | --- |
| A retrospective view upon first departure. | All eligible first looks | `IA_REGRESSION_OUT`, Bernoulli negative log-likelihood |
| Forward reading time | Proceed forward upon leaving the word for the first time. | `IA_FIRST_RUN_DWELL_TIME`, the Gaussian negative log-likelihood for sub-milliseconds |
| Looking-back gazing time | Backward look at the first departure from the word | `IA_FIRST_RUN_DWELL_TIME`, the Gaussian negative log-likelihood for sub-milliseconds |
| Backward path time | Upon first leaving the word, the backview path latency is finite and at least equal to the word fixation latency. | `IA_REGRESSION_PATH_DURATION`, the Gaussian negative log-likelihood for sub-milliseconds |

We fit each readout using word length, word position, and the frozen twelve-dimensional `processing` state. We standardize continuous features using only fitting-fold means and standard deviations, and set constant dimensions to zero. The binary readout uses a logistic link. The reading-time readouts estimate means on the log scale and use development residuals to estimate one common variance per endpoint. We retain the fixed mean-loss scale and L2 coefficient of 0.01 and leave the intercept unpenalized. Both baselines use the same scoring and calibration. One is intercept-only, while the other uses word length and word position. Observed forward movements and regressions determine which conditional likelihoods can be scored. A single model forward pass returns the probability and all three conditional time distributions. ## Formal comparison and eligibility criteria

Timkey released the 368 reader files from the author's sealed snapshot, using the author's processing program's `0 < gz ≤ 2000`, `regout`, and `gp` definitions to mark and skip eye movements lacking time tags. Only the first three canonical constructions were evaluated, with 24 ambiguous/control pairs per construction for word-pair matching. Materials were identical to those explicitly specified by the author in Materials and Methods and fully matched with Huang. Disambiguation tokens and the following word used pre-fixed pairing coordinates. Each `item × cond × region` must first be verified against the structural index and relative position published by Timkey to ensure unique alignment. If the public independent position table is unavailable, verification should be performed using the author's released files, selecting only identifiers and design position fields. outputs and hashes from this step must exclude eye movement or correctness data. Endpoints that cannot be fully aligned are retained as unevaluated. [Timkey author program and data](https://osf.io/b6rqh/) · [matching materials and SHA-256](../../../research/union_training/holdout.json)

The primary positions are forward reading time and pre-regression fixation duration on the disambiguating word, and regression on first exit and regression-path duration on the following word. We generated and sealed all four predictions for each of the 72 matched stimulus sets before bringing in human observations. For each primary endpoint, report the ambiguity-minus-control contrast across equally weighted stimuli, expressing probabilities in percentage points and durations in milliseconds. Convert predicted durations back using the arithmetic expectation of the log-normal distribution fitted on development data. Report average negative log-likelihood for the model and both baselines on the same held-out observations. Use seed 1729 and 2,000 paired stimulus bootstrap resamples to form 95% intervals for the human contrast, for model minus human contrast, and for loss relative to the word-length and word-position baseline. The intervals condition on the observed readers. If the human interval includes zero, record direction as indeterminate. Report the construction-specific and additional-position estimates as secondary analyses. If either condition lacks usable support in any stimulus, report the missing cases, and leave the all-stimulus primary contrast for that endpoint unevaluated.
