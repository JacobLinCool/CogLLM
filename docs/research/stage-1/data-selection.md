# Stage 1 Training and Validation Signal Selection

This document records the verified existing human observations and their scope of application. The initial version retains the original scales and visible conditions for different endpoints. Reading time, comprehension response, comprehension self-assessment, and query selection are each counted separately. The article and reader background remain general inputs for the App. Question-answer endpoints are used only in the research control, providing questions and options according to each experimental setting. ### Recalculable D01 open-book observation

Filtered by the fixed-author version `human_experiments/prolific/qa.tsv`, selecting `source == 'Onestop'` and `trial_type == 'reading_comprehension'`, where `answer_response == '0'` denotes selection A. **1,567/1,940** responses were correct (80.77%). The advanced version achieved 774/970 (79.79%), and the basic version 793/970 (81.75%), with an observed difference of approximately +1.96 percentage points. This represents a weighted-trial descriptive statistic. To estimate the uncertainty of the version effect, the reader and original question/article assignment retained the group structure. ### Stage 3 parallel verification reading report data

- **ROAMM** involved 44 readers reading five English passages. Readers pressed a key when they noticed mind-wandering, then circled to select the start and end words. The public-facing page table reports 2,200 page exposures and 1,001 with reports. Raw key presses, backtracking spans, and post-reading comprehension can be used individually. The circled start positions are constrained by page boundaries. no report indicates no key press report. Self-aware attention interruptions can be evaluated, or the data structure can be used to cross-validate "reading stop + span." Semantic confusion and cross-sentence references require corresponding reader reports. OpenNeuro releases this under CC0. adapted texts have upstream source conditions. [ICML 2026 data paper](https://proceedings.mlr.press/v306/sun26ag.html) · [Methods and supplements](https://arxiv.org/html/2611.14814v1#S2.SS1) · [OpenNeuro 1.3.0](https://openneuro.org/datasets/ds007629/versions/1.3.0) · [Public page table](https://s3.amazonaws.com/openneuro.org/ds007629/derivatives/behavioral/roamm_page_level_reading_data.csv)
- **Cambridge Dictionary Look-Up** records which words second-language readers look up, allowing for the examination of word-search behavior in the presence of reader background. The study endpoint is actual word searching. resolution of all reading-related issues requires separate observation. Formal release requires application, with additional conditions for data redistribution and derivative work publication. This round did not access a model. [CoNLL 2025 Method](https://aclanthology.org/2025.conll-1.32/) · [Data and Usage Conditions](https://researchdatasets.cambridge.org/datasets/cambridge-dictionary-look-up-dataset)

R07/R08 share the same understanding response family. R09/R16 are initially processed as potentially overlapping, and R02/R03 are also initially treated as potentially sharing a common historical explanation. The original text, paraphrase, re-analysis within the same family, and answer-derived annotations follow the same segmentation. D01 and D08 can validate their respective understanding endpoints. formal cross-study held-out still requires specifying identical endpoints and visible rules. Outputs used for design or development retain usage documentation. Each family and the final scoring rules remain unsealed snapshots. [Methods and Boundaries](measurement-and-boundaries.md) · [Cross-Study Validation Specifications](../mathematical-formulation.md#真人效度)

In this round, no data were found that simultaneously cover **word-level reading stops, the same reader's query reports, any previously read phrase that the query refers to, and subsequent updates to the same query**, while also satisfying verifiable reuse conditions. Consequently, the first version of the App relies on sentence-level self-assessment and annotation as the initial verifiable layer. Interactive selection of the referred earlier text and stepwise resolution are integrated at the actual granularity of calibratable observations.
