## Reader background and endpoints

The primary endpoint was assessed via binary correct/incorrect judgments on post-reading comprehension questions. Participants first read a single-page text that allowed free look-back, then answered questions sequentially without returning to the main text. Domain questions were administered subsequently. Major and undergraduate/graduate enrollment status were pre-existing conditions at enrollment, serving as the sole reader input. Demographic questionnaires were completed post-experiment. Domain question correctness, comprehension scores from other trials for the same reader, and eye-tracking data were retained in the measurement phase. Additionally, 35 independent readers answered 1,260 questions without viewing the main text, achieving 330 correct responses. This procedure serves to assess item guessability and must be separated from the same reader's pre-test. [Original Study Procedure, Demographic questionnaire, Validation](https://pmc.ncbi.nlm.nih.gov/articles/PMC12208991/) · [No main text validation data](https://github.com/DiLi-Lab/PoTeC/blob/2742221e70cb9d2b38499bd080e079e6c0c1f5a3/participants/response_accuracy_online_survey.csv)

**Numerical cross-validation is operational.** Grouping by the same textbook volume, the 7 groups are `b0`, `b1`, `b2`, `b3–b5`, `p0+p3`, `p1+p5`, `p2+p4`. Stratifying by major × study stage, sorting by `SHA256("potec-reader-v1:" + reader_id)`, and cyclically assigning five-fold cross-validation. For each test cell of (volume × reader fold), training uses other volumes and other reader folds. The training cell accuracy is smoothed with Beta(1,1), and a descriptive comparison via equal weighting is performed across the 2,664 test responses. The overall NLL for the prior, text-only, and text × major × study stage (excluding the test fold) are **0.65760, 0.64477, 0.63802 nats**, respectively. No confidence intervals were computed for the differences. The three physical volumes belong to the same author series. therefore, this split-verification did not observe volume or reader effects, precluding the establishment of separate unseen author or discipline generalization. [Textbook source table](https://github.com/DiLi-Lab/PoTeC/blob/2742221e70cb9d2b38499bd080e079e6c0c1f5a3/stimuli/STIMULI.md) · [Numerical response raw data](https://osf.io/download/g5jds/)

If the main text rights are clear, the three models can be compared using the same double held-out split. The text model considers only the main text, the background model considers the main text plus major and minor subject, and the structural comparison uses discipline, stage, matching, and length. Each model uses the readout information specified for each condition, following the same cross-validation rule. The current frozen candidate only supports the default reader. it can first be used to self-evaluate the readout to test the overall PoTeC external ranking, with background comparisons pending fixed background readout. If error prediction is calibrated using the training fold, then report per-item probability and NLL. The accompanying per-word `FPReg` can evaluate which word initiates backscanning, and `RRT` can evaluate where readers subsequently linger. Question content, subjective load, and resolution time point require corresponding direct measurement.
