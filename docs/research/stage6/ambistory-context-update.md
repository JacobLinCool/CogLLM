# The semantic update of English narrative

Gehring and Roth's AmbiStory provides shared beginnings, ambiguous sentences, and two optional endings. Readers rate the plausibility of a single specified sense of a word on a 1–5 scale for one version. Scores for the same sentence under different endings can be used to test whether a model can link subsequent context back to the same word previously encountered. Each reader sees only one version of the story. the released data contains no sequential reader identifiers, allowing reconstruction of the distribution of sense judgments and their changes across groups. The story endings provide a known reading stop. the token at which a reader first becomes aware of the ambiguity or performs disambiguation is not observed in this dataset. [Research §3.2–4.2](https://aclanthology.org/2025.starsem-1.12/) · [SemEval original task](https://nlu-lab.github.io/semeval.html)

To retain the full three-version comparison of the story, stories were grouped into story families based on homographs, context, and ambiguous sentences. The original release includes one `base` family spanning training and test sets, with test data retained and overlapping training families excluded. Additionally, a training family was excluded because its author-target word differed in spelling from the original sentence. The final counts are 378 training, 98 development, and 155 test story families. The test set comprises 465 story versions, 930 sense-scoring items, and 4,663 votes. For each vote, the original five-choice options and the accompanying `nonsensical` flag were retained. Author-reported means and sample standard deviations have been verified. [Fixed Release](https://github.com/Janosch-Gehring/ambistory/tree/705f1a3784b62f1aa42435b9e107dba901547441) · [Construction and Source Verification](../../../research/stage6/ambistory_prepare.py) · [Audit Manifest](../../../research/results/ambistory-preparation.json)

The model text file contains only the original text, anonymized identifiers, and character-level reading stops. Each reading stop corresponds to the last visible non-whitespace character immediately preceding the target word, the end of the target word, the end of the shared ambiguous sentence, and the final sentence end when a conclusion exists. Using a fixed Qwen tokenizer, all 6,941 reading stops were verified locally without loading the model. The three versions of each story share an identical text prefix up to the end of the ambiguous sentence. only after this point do they diverge due to different endings, resulting in distinct model states. The end-of-sentence reading stop is defined as the sentence boundary after trimming edge whitespace from the manuscript. The original study used GPT-4o to generate the preceding text, humans to write the ambiguous sentences and endings, and tools to correct the text. Direct supervisory signals came from existing human ratings. ## Prediction and Validation Specifications

First, fix three conditions. Form control uses the target word, semantic description, and shared prefix. adding any suffix maintains the same distribution. The shared prefix condition freezes the state of Qwen3.5-2B at the end of sentence 4. The suffix condition uses the state at the end of sentence 5 from the same causal forward pass. For identical semantic readouts, the five-level distribution of each semantic meaning is output at each reading stop. Semantic descriptions or dictionary examples can be offline-encoded and interact bilinearly with the representation of each reading stop in the main text. This enables item-wise verification of the main text's single forward pass and no-decoding condition. The baseline is localization given two sense items. automatically identifying candidate words and sense items from the original text still requires additional confirmation.

We compute negative log-likelihood per rating on the original five-level scale and also report the SemEval rank correlation and accuracy within a standard deviation. For each story and word sense, we calculate the difference between the two endings separately from the human and model expected scores. The two primary metrics are per-rating negative log-likelihood and absolute error in the ending difference. For each metric, the 95% bootstrap interval clustered by homograph for the paired difference between the ending and common-prefix readouts must lie below zero. We also report the difference between model and human mean absolute update magnitudes. For its 90% interval, the prespecified equivalence margin is ±0.5 scale points, half of one response step on the original scale. We keep the complete rating scale for the primary analysis and use the `nonsensical` tag for a prespecified secondary sensitivity analysis. Testing uses only the fixed set of 155 held-out story families, whose responses stay out of development. The current candidate still needs a word-sense distribution readout, fitting, and archived predictions.
