# Causal readout under OneStop re-reading conditions

Use the OneStop General Reading group. Participants read the same article version twice within the same work session: after answering the first question, they received correctness feedback, then re-read to answer a second question. Analysis retains the ability to cross-check the release log against the article text, version, sequence, and existing response matching. The re-reading state describes this experimental experience. Familiarity with other topics, reader background knowledge, and the location of the first noticed query require separate observation. [ trial verification and re-reading priors](onestop-rereading-audit.md) · [original study Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC12727756/#Sec11)

The first two batches of articles and readers were matched. the 21st through 30th articles of the third batch and 60 readers were reserved for scoring. The group difference from the previous round's data verification has been recalculated. In this round, fixed comparisons, model inputs, data splits, and scoring are conducted prior to any model predictions. The full text is assembled according to the actual discourse order observed by the readers. Each distinct string undergoes one NVIDIA L4 FP32 causal forward pass, using Gradio's candidate Qwen3.5-2B fixed weights, the original tokenizer, and the same CUDA encoder. The reading stop annotation is retained at the end of each paragraph. During extraction, the two newlines separating each known original text segment are treated as visible. the same two newlines are appended at the end of the article. Each reading stop must exactly match the independently encoded visible prefix, with the token at that position not crossing into the next paragraph. Additionally, a small control is recalculated using truncated prefixes and modified subsequent text, allowing a relative vector difference upper limit of 0.0002. The main forward input contains only the body text and layout separators, excluding titles, options, background questionnaires, responses, or reader keys.

The readout utilizes the final layer state at the end of the sequence (2,048 dimensions), normalized by its L2 norm. Initial reads and re-reads are represented by 0 or 1, respectively, generating two conditional probabilities. The default reference condition for the main text is initial read. The primary comparison pre-fixes five readouts.

| Readout | Fitting information |
| --- | --- |
| Shared priors | proportion of correct answers shared across two rounds in the development set |
| Re-read the priors | proportion of correct answers for the initial reading and re-reading in the development set |
| Main text | End-of-segment state |
| Main text and re-read bonus | End-of-segment state, re-read state |
| Main text and re-read interaction | End-of-segment state, reread state, and their product |

Two priors are used $(x+0.5)/(n+1)$, where $x$ denotes correct responses and $n$ denotes total responses. Three body readouts use the sum of sequential Bernoulli NLLs plus $\frac{1}{2}\lVert w\rVert_2^2$, with the intercept unpenalized. Body dimensions and penalty coefficients are not adjusted based on held-out results. We separately fit weights for the sealed snapshot development and the two states' predictions, then append the held-out responses.

The primary metric is Brier score, ranging from 0–1, with 0 being optimal. Probabilities are grouped by comparable paragraph version × question number, squared against actual 0 or 1. Only groups observed in both rounds are included. within each group, equal weighting is applied to the two rounds, then equal weighting is applied across groups within the discourse, and finally equal weighting is applied across articles. The secondary report includes sequential NLL and human accuracy re-read differences with the same group weighting. Using 10,000 article pair resamples, random seed 20261121, with fixed readers and sealed snapshot predictions.

To determine whether the main text and re-read readout pass validation, its Brier score relative to the main text, re-read addition, and re-read prior must each have an upper bound below zero at the 95% confidence interval. Its re-read mean prediction difference must align in direction with the human difference, and the 90% hold-out resampled interval for article re-read differences (prediction minus human re-read difference) must fall entirely within ±3 percentage points. This allowable difference reflects the magnitude of re-read effect discernible in this dataset, suggesting that the current experimental precision may be insufficient. Results are reported by endpoint, retaining the main text and re-read addition findings.
