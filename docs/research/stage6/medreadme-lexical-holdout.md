# English word-by-word colored MedReadMe held-out

Fix the current Gradio candidate checkpoint's CompLex suffix readout. In MedReadMe's author's test split evaluation of full-sentence scanning, can the coloring order identify human-annotated difficult words and terms? Each input retains the author's published full sentence and original character coordinates. The model sees only the sentence, uses a single causal forward pass, and adheres to the interface's actual suffix alignment rules. [Source and Character Alignment Audit](medreadme-span-audit.md) · [Interface Implementation](../gradio_app/README.md#實驗性逐詞與疑問片語)

Retain items for which the source, text version, split, and original character sequence uniquely identify the passage. Remove all held-out records with duplicate normalized word sequences. Normalize using Unicode NFKC, case folding, and the app's word boundaries. Exclude sentences with the same word sequence as a CompLex training or tuning sentence. Also exclude items for which at least 25% of distinct five-word spans appear in a single CompLex fitting sentence. This reduces sentence duplication. The data lack article IDs that can be linked to the original text, so scoring uses the published source groups and their sentences.

The primary annotation marks interface terms that are fully contained within general-difficulty or specialized-difficulty terms. Medical proper nouns and two specific abbreviations are reported separately. The primary endpoint is determined by general-difficulty terms, general-difficulty medical meanings, and medical terms with two query difficulties. overlapping terms and those circled by other labels are excluded. Uncircled terms indicate that this annotation did not select that term. Additionally, report full-term coverage by original segment, retaining the denominator for single words and cross-word spans.

The primary comparison is within the same sentence: vocabulary scores displayed to two decimal places via the interface are averaged against the primary annotations, and an equal-weighted average is taken across sentences containing both annotated and unannotated words. Words that cannot be precisely aligned by the interface are placed in a tie at the last position in the candidate ranking but are still included in the control. The control uses the original character length of the same set of words and the reverse frequency of the CompLex fitted source. For both "candidate minus control" difference values, the 95% paired confidence interval lower bound must exceed zero, and at least 95% of the pre-determined evaluatable words must align. Resampling is stratified by publication source, with sentences resampled within each selected source, fixed at 10,000 iterations with seed 43. Tied scores are jointly included in the precision calculation using the same threshold. This control measures external term localization. the 0–1 score and the intensity of human cognitive effort still require separate calibration.
