# CommonLit CLEAR English discourse readability source audit

CLEAR tests how the fixed app candidate ranks the reading ease of English passages. The original study asked teachers to select which of two passages would be easier for students in grades three through twelve to understand. It retained 111,347 pairwise judgments from 1,116 teachers and combined them into one Bradley–Terry estimate per passage. Higher values of `BT_easiness` in the public table indicate that teachers expected the passage to be easier to understand. The scale is relative and has no grade-level mapping. The public file lacks trial-level choices, rater identities, and sentence-level judgments. It therefore supports comparisons of expected passage-level ease, while actual student comprehension, individual teachers' judgments, and the locations of reading difficulty remain unobserved. The original study randomly split the judgment trials in half and estimated scores separately, yielding a correlation of 0.63 between halves. [Crossley et al., original study, Study 1](https://link.springer.com/article/10.3758/s13428-022-01802-x)

## Scope of reuse

This study adopts the non-commercial research condition of the fixed GitHub README, and verifies each column's `License`. The held-out test uses only explicitly stated and version-complete single CC BY or CC BY-SA columns, excluding duplicates and cross-material overlaps up to 1,016 items.
