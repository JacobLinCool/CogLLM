# Blott end-sentence coherence held-out and query-tracking data verification

Data from Blott et al. can be used to independently validate whether the model can replicate the human behavior of making **sentence-final coherence judgments after semantic reinterpretation**. In the original study, a complete sentence was presented each trial, and readers were asked to use a key to judge whether the sentence made sense. Later, the same sentence frame was provided with semantic cues. the rate of answering "makes sense" was lower for the coherence version requiring reinterpretation. This experiment measured judgment outcomes, but within a single trial, the first detection of the question, the direction of the question, and the timing of successful reinterpretation were not directly observed. [Original study and methods](https://doi.org/10.1037/xlm0000936) · [Author manuscript](https://discovery.ucl.ac.uk/id/eprint/10101418/1/BlottRoddFerreiraWarren_JEPLMC_2020_AcceptedManuscript.pdf) · [Public materials and trial files](https://osf.io/hn3bu/)

## human endpoint and data reconstruction

The 48 English sentence frames in the original study each had four conditions. The allocation of the four material tables was balanced, ensuring each reader viewed only one version of a single sentence frame. After removing `bridge` by author condition, 96 readers covered 47 sentence frames, 188 versions, and 4,512 judgments (24 per version). The authors additionally excluded two eye-tracking regions for `log`. the sentence frame was retained for behavioral judgments. [Original research methods §§Materials, Data analysis](https://discovery.ucl.ac.uk/id/eprint/10101418/1/BlottRoddFerreiraWarren_JEPLMC_2020_AcceptedManuscript.pdf) · [Machine reconstruction and hashing](../../../research/results/blott-coherence-audit.json)

First, compute the difference in responses between the two coherence conditions for each reader, then average across readers. the reanalysis shows a relative difference of **−28.91 percentage points** compared to the no-target ambiguity condition. The original CSV contains multiple eye-tracking segments per judgment. The held-out score is counted once per trial. Using the original segment list as weights yields the reproducible author's full average across all 384 reader conditions. The key-value pair `BUTTON_PRESSED` combined with the corrected `expected.button.press` allows exact reconstruction of the author's analysis-based `accuracy`. The original `BUTTON_ACCURACY` contains 2,256 instances differing from this column. The authors observed higher revisits and longer dwell times in the subsequent segment of the following cue. This provides an additional observation window for local model variations. The study simultaneously indicates that humans may have re-read the same sentence before pressing "makes sense." When the model outputs a causal forward state per-token, the final score can be aligned with the final keypress, while interpretations of intermediate positions must still refer back to the actual measured eye movements or other responses at that location. ## Comparison of the fixed candidate model's held-out performance

Candidates are fixed to `74c26ff02569b2b3bc28ed291bf15fd2f85db5b4c93a3ad7bfc34f6a5d333ea0`. For 188 sentences, the end-of-sentence two-group 1–5 ordinal distributions are obtained via a single causal forward pass. The primary model readout is the self-assessed expected value, with readability expected value used as a secondary analysis. Blott's binary key differs from the subjective scale of the primary readout. this experiment compares their rankings and relative effects without calibrating ordinal scores to key reaction probabilities. Sentence frames, conditions, and responses are retained in the local scoring file. The sealed snapshot file must be verified against candidate ID, input, and predicted SHA-256 hashes, along with a single forward pass for each of the 188 sentences. [Data Preparation](../../../research/stage6/blott_audit.py) · [sealed snapshot input hash](../../../research/results/blott-coherence-audit.json) · [sealed snapshot scoring rules](../../../research/results/blott-transfer-protocol.json)

**Primary comparison** is the rank correlation difference between candidate comprehension scores relative to the baseline of "shorter, easier-to-understand" sentences. Within each sentence frame, six sentence pairs are compared across four model versions. A score of 1 is awarded if the model score ranking aligns with the proportion of human responses marked "makes sense," 0.5 for a tie, and 0 otherwise. Scores are first averaged within each sentence frame, then equal-weighted averaged across 47 sentence frames. The baseline score is the negative character count, requiring no fitting. All four versions across the 47 sentence frames share identical blank token counts. Additionally, individual results for six condition pairings and 15 sentence pairs with identical character counts are reported. Word length and character count matching retain differences in word frequency, semantics, and other morphological variants.

**Effect size** uses the mean for each of four conditions. The human outcome is the proportion judging each version coherent. Convert the model's expected rating to a fraction of the scale range using `(score − 1) / 4`. The ambiguity cost is the unambiguous coherent condition minus the coherent condition requiring reanalysis. Divide this cost by the coherent–incoherent difference in the unambiguous condition to express the ambiguity cost relative to the scale's discrimination of coherence. Interpret this ratio only for a positive denominator. If any bootstrap denominator is nonpositive, retain only the point estimate. The model's fraction of the scale range and the human proportion retain their respective meanings.

All intervals used 10,000 paired bootstrap resamples, with replacement sampling for 96 readers and 47 complete sentence frames. Within each resample, reader weights first determined the human ratio for each version, followed by aggregating candidate and control comparisons using frame weights. A two-sided 95% confidence interval lower bound greater than zero supports the claim that the candidate sentence length is closer to human ranking than the control. Other comparisons retain their original estimates and intervals for interpretation. The scoring rule and sealed snapshot format were fixed first, then model scores were obtained. ## Tracking the same reader's query

Extending the search beyond the previously reviewed TED-Q, INQUISITIVE, and Onea, we retrieved studies on reading aloud think-aloud, reader-generated clarification questions, and word-reinterpretation research. As of 2026-11-21, no new, model-ready data were found in the verified public repositories that could link a reader-generated question to an earlier text segment and track when the reader confirmed resolution in subsequent text. This is the conclusion of this targeted retrieval. TED-Q provides a two-sentence follow-up for the same reader, with both rights restrictions and truncation remaining applicable.
