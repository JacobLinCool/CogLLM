# PLABA open-book understanding correction evidence segments

The initial open-book analysis treated each sentence order in the response table as item evidence. Stage 2 verification found that 213 joinable old indices fell outside the range specified in the item table. This was recalculated using the complete evidence list from the item table. Human endpoints are post-reading open-book response accuracy. When during reading difficulty begins and which token provides sufficient evidence still requires validation with data measuring corresponding spatial and temporal quantities. [Stage 2 correction](../stage-2-data.md#plaba-eval-evidence-sentence-correction) · [Original data and item table](https://github.com/SDS-NLP/PLABA-EVAL/tree/153082e7d58b833d5e2f481b92fdcf9248c60d11)

Validation employed the existing causal final-order distribution and a fixed reader-article isolation five-fold cross-validation. The model ingested only the body text. The research team appended each author-specified single sentence or sentence cluster to the corresponding held-out fold, computed the expected value of the five-level comprehension self-assessment, and averaged across evidence sentences using equal weighting. The full-text baseline averaged all candidate sentences from the same pool using equal weighting, while the sentence-length baseline retained the original order from the position experiment and readout results within the same evidence sentence cluster. All three groups treated lower comprehension self-assessments as indicative of likely incorrect responses. Only trials with evidence sentences explicitly listed in the question table were included in the baseline. Scoring was based on the correctness of options provided by the author. [Fixed-out-of-fold prediction](../../../research/results/causal-plaba-ordinal/manifest.json)

The primary metric was the AUROC of incorrect responses per trial. Positive and negative trials with the same score were each assigned half a point. The primary paired comparison was the model's average relative sentence length baseline for evidence sentences, and the model's average relative overall average for evidence sentences. Resampling the existing 25 reader-article connected groups 10,000 times was performed, and the 95% two-tailed confidence interval of the paired difference was taken. The secondary metric was average precision, updated with precision and recall for the same group. The criterion for determining model improvement required both primary difference interval lower bounds to be higher than zero. The above represents the endpoint diagnosis of the development data, where the readout at the end of the sentence was not refit due to the rephrasing of the question. These ranking scores do not yet have corresponding calibration for the probability of incorrect responses.
