# CLEAR English readability held-out specification

Fix Gradio candidates to test whether sentence-level readability in English discourse provides ranking signals beyond common surface features. CLEAR labels are teacher-estimated discourse readability scores derived after reading entire texts, assessed against expected difficulty for readers from third grade to high school. Actual reader responses, sentence-level scores, and the point at which difficulty was perceived cannot be reconstructed from the selected open versions. The primary analysis employs the published Bradley–Terry point estimate, where higher scores indicate greater ease. [Materials and Licensing Verification](clear-reading-ease-source.md)

- Use the Excel spreadsheet authored by the sealed snapshot hash in the audit. The first round includes only source columns explicitly marked with CC BY or CC BY-SA licenses and specifying a version. Columns lacking authorization details, those listing other licenses simultaneously, and those with unclear sources are excluded from this comparison. - Compare full-text and consecutive 12-word spans across materials using Unicode NFKC, casefold, and the `[a-z]+(?:'[a-z]+)?` tokenization. If a span overlaps with an authorized material used in existing candidates by at least 30 consecutive words, exclude that document. Overlaps of 12–29 words are additionally recorded and treated as sensitivity exclusions. This verification covers available used materials. overlaps in model pre-training corpora cannot be confirmed.
- For exact duplicates after normalizing CLEAR text, keep the row whose original string ID is first lexicographically. Group rows in the same connected component if they share a resource URL, share a normalized author and title, or have at least 30 consecutive words of body text in common. URL normalization retains the path and query and removes the fragment, a `www.` prefix on the domain, and a trailing slash on the path. A shared homepage identifies only the platform. For URLs with neither a resource path nor a query, group using the author-title match or text-overlap criteria. Exclude the author-title key when either author or title is missing. Use the lexicographically smallest original table ID in each component as the component ID. Compute the SHA-256 of `clear-ease-v1:` concatenated with the component ID, convert the first eight hexadecimal characters to an integer, and take the remainder modulo 5. Values 0 and 1 assign the component to the holdout and the remaining values assign it to calibration. The split uses only materials, independently of their ease scores and standard errors.
- Align the original text to the formal App character specification, paragraph, sentence, and candidate model tokenizer. Process each passage sequentially in a causal forward pass, reading out each sentence fully using App readability metrics. Compute the continuous score for each passage as the weighted average of the blank token counts per sentence. The main analysis must fully align all non-empty sentence ends. If sentence ends cannot be aligned, record the missing values, and apply the same exclusion rules for calibration and held-out sets.

## Fixed comparison

Surface readout employs four numeric values: the natural log of the corpus blank count, the average blank count per sentence, the average number of letters per English word, and the proportion of English words with seven or more letters. The letter word metric follows the identical normalized formula above. Standardization relies solely on the mean and standard deviation of the calibration group. The constant column is removed in both groups. The three scores are as follows.

1. Fix the App discourse score, do not fit parameters.
2. Surface scores were fitted with a calibrated human Bradley–Terry score using intercept-included ridge regression.
3. Fixed App scores were added to surface readout, fitted with the same calibration set and identical penalty. The two ridge models used mean squared error with equal weighting per article, plus 0.01 times the sum of squared slopes, with free intercepts.

The primary endpoint is the held-out Spearman correlation of the third arm minus that of the second. Use 5,000 paired resamples of source components with seed 731503, carrying all methods together and keeping fitted calibration weights fixed in each resample. An improvement beyond surface features is supported only if the lower bound of the 95% interval is above zero. Also report the ranking difference between the fixed app and surface-feature readout, RMSE in the original units for the two calibrated models, separate literary and expository results, and a sensitivity analysis excluding overlaps of 12–29 words. With fewer than 100 held-out source components, report the primary result as descriptive for the sample. These intervals quantify uncertainty across source components.
