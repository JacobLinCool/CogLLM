# discourse event sequence interpretation update

Duff, Sasaki, and Altshuler varied when a short English text specifies which of two events came first. In Experiment 1, readers reported which event occurred first at the end of each text version and then rated the plausibility of the alternative. The three conditions shared the opening text and the two answer choices. Adding the cue replaced the boundary period with a comma followed by the disambiguating clause. The paper describes 60 stimulus sets, and the public stimuli and analysis files confirm 48. Each of 30 native English readers saw one version per set, with 240 ratings for each of the six versions. The authors first checked responses using two sets of trials with explicit connectives, excluded readers who scored below 80%, and removed two readers above the assignment quota. This analysis used the authors' released filtered data. [Paper §3, Fig. 1](https://journals.linguisticsociety.org/proceedings/index.php/SALT/article/download/35.029/5879/14161#page=7) · [Original stimuli](https://osf.io/download/ued98/) · [Original ratings](https://osf.io/download/6756ed091426ab8053563bbb/) · [Authors' filtering code](https://osf.io/download/6756ed0a651146d4f4661da0/)

In the ambiguous version, 181/240 judgments placed the later-mentioned event earlier in time. The proportion fell to 30/240 with a chronological cue, a difference of −62.92 percentage points. With a cue supporting reverse chronology, it was 233/240. Relative to the ambiguous version, chronological cues decreased reverse-chronology choices in 45 stimulus sets, left 2 unchanged, and increased them in 1. We also recomputed the authors' eight-point combined scale from the binary choices and four-point ratings. [Distribution and coding in the six conditions](../../../research/results/salt-discourse-audit.json)

Experiment 2 tested a separate group of 90 native English readers. The authors selected 24 stimulus sets based on Experiment 1, so the two experiments share a stimulus family. The first four regions of the late-cue variant in Experiment 2 match the chronological disambiguation variant in Experiment 1, followed by an added closing sentence. Each participant read one version of each stimulus set region by region, for 2,160 trials and 25,920 region reading times. The authors required at least 80% accuracy on general comprehension questions. The public analysis file also identifies the 1,730 trials with correct responses. In descriptive means recomputed from that file, the final region of the disambiguating clause took 77.48 ms longer to read in the late-cue variant than in the version with an earlier adverb. Each item used identical text in the two versions for that region. The paper's mixed-effects model estimated a difference of about 60 ms in the same region and reported a 95% posterior interval of [34, 82] ms. [Paper §4, Fig. 2](https://journals.linguisticsociety.org/proceedings/index.php/SALT/article/download/35.029/5879/14161#page=9) · [Region observations](https://osf.io/download/6756ed673430cda16f661498/) · [Authors' filtering code](https://osf.io/download/9mnpj/)

Aligning the response file and original test materials by version and item yields 540 planned event-order questions, of which 534 were answered. Postreading accuracy for the late cue, earlier adverb, and earliest connective conditions was 105/179, 116/176, and 136/179, respectively. In Experiment 1, each reader answered once per article. Experiment 2 recorded reading times by region and one response at passage end. The two datasets can test how cues change the group's distribution of interpretations and postreading outcomes across conditions. They provide no direct report of the token at which an individual reader noticed or resolved a question. [Original test materials](https://osf.io/download/9ef4x/) · [Region-level and postreading data](https://osf.io/download/6756ed673430cda16f661498/)

Each displayed segment and response file text was verified line-by-line against the actual output. The author-supplied Region table indicates that, across all 24 earliest connectionist versions, starting from the sixth segment, each segment's start point was shifted earlier by one word, totaling 168 instances. This verification was based on the displayed segments in the stimulus and the actual recorded positions. Neither OSF nor DataCite metadata listed data licensing information. In this instance, only the public supplementary files were used to re-run the author's experiment. the resulting files contain only aggregated and source hash values. [Author Region Table](https://osf.io/download/6756ed3f0eb8dba7d7f73a57/) · [Supplementary Files Repository](https://doi.org/10.17605/OSF.IO/C32K6)
