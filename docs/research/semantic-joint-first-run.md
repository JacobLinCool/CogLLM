# Joint training for three semantic tracking tasks

Joint training of the three tasks did not improve all three held-out endpoints simultaneously. Compared to their respective training, the shared group showed increased variance in word readout estimates, while the point estimates indicated by earlier text improved slightly. The error in answer intervals was slightly higher across all three stories. The experiment froze Qwen3.5-2B, updating only the adapters and endpoint readouts. The answer endpoint used public coordinate supervision for time intervals. [First three data endpoints](semantic-tracking-first-run.md)

## Interval loss and one-pass forward

Let \(h_{a,t}\) denote the probability that a problem opened at \(a\) is resolved by time \(t\), given it has not been solved prior to \(t\). Its survival probability is \(S_a(t)=\prod_{j=a+1}^{t}(1-h_{a,j})\). If the last confirmed unsolved item is \(L\) and the earliest marked as solved is \(U\), train using \(-\log[S_a(L)-S_a(U)]\). If no solution is observed, use \(-\log S_a(L)\). The computation is performed in log space, treating the interval endpoint as a readout rather than a per-token solution label. [Interval likelihood and readout](../../research/semantic_tracking/joint_model.py)

For each article, the backbone representation requires only a single causal forward pass. Given an activated question position, the prototype indexes via the anchor, scoring in parallel the survival probabilities of valid earlier text candidates and subsequent lines. The solution path is populated only at the end of provided lines. This round validates conditional tracing, where the question anchor is supplied by the observation or call endpoint. When multiple distinct questions exist within a single anchor, this interface lacks sufficient question representation to identify them. Therefore, this round is insufficient to attribute the readout degradation solely to answer supervision. ## Post-readout diagnosis

Reuse sealed probabilities and human keypresses from 3,313 single-word stops. Relative to single-task training, two-task sharing has a higher Brier score in 9 of 16 material families. All 16 leave-one-family-out differences are still positive, ranging from +0.00047 to +0.00162. On 144 stops with a human first lookback, mean predicted probability dropped from 13.47% for single-task training to 10.75% for two-task sharing and 9.27% for three-task sharing. Moving from two to three tasks, stops with an observed lookback contributed +0.00084 to the overall Brier difference, and stops where readers continued forward contributed −0.00031. This descriptive diagnostic uses the same evaluation set and supports retaining the single-task lookback readout as a reference. ## The next round of body text evidence cross-reference

First, we test whether pre-activated specific questions can yield higher answer scores upon reading relevant text. We prioritize QASPER. Questioners review only the paper title and abstract to formulate questions requiring full-text evidence. A second batch of annotators reads the full text to select evidence supporting the answer. For each paper, we verify usage conditions, sources, and official splits, selecting single-paragraph evidence that uniquely aligns with the full text. If a reading length limit is required, it is first fixed according to article length rules, then verified against the observable range of the evidence. Evidence is segmented by article, maintaining reading order. [QASPER experimental method §2.2](https://aclanthology.org/2021.naacl-main.365.pdf#page=3) · [Ai2 public data](https://huggingface.co/datasets/allenai/qasper)

Maintain Qwen3.5-2B's single causal forward pass and independent readout. Compare the readout using only position and elapsed-time baselines, versus readouts incorporating the current visible body text and a specified query, and versus swapping the same body text and same reading stop for a different query within the text lacking prior readout annotation evidence. The primary comparison is the held-out article's evidence interval negative log-likelihood, and whether the same reading stop can correctly match a query with textual support. The body text group must outperform both the time and query-swap baselines to justify incorporating this textual signal into joint training. QASPER's specified queries are used solely for this study's baseline, with the acceptance criterion being textual evidence arrival. The original asker's subjective observation of the moment of answer comprehension requires separate human observation.
