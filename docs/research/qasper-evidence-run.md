# Locating textual evidence in QASPER

On 23 held-out papers, incorporating the body text reduced the paragraph localization error for annotated evidence. After swapping the same question within a paper, scores approached those under the condition of using the original question. On the same reading stop, the model correctly identified which of the 41 question pairs had been read to the annotated evidence in 21 pairs. ## Data and Scoring Design

QASPER's questioners can see the title and abstract and are asked to formulate questions that require reading the full text to answer. Another group of readers can see the full text, mark evidence sufficient to support an answer, and prioritize earlier paragraphs when multiple pieces of evidence are adequate. Only questioners who did not read the paper beforehand are included in the first round, along with single-paragraph evidence that can be uniquely aligned and where all published annotations agree. Following the official train/test split for the paper, 151 questions from 60 training papers and 55 questions from 23 test papers are selected. Each full text maintains its original order. the cutoff is determined by three upper limits: 14,000 characters, 32 full-text paragraphs, and 6,000 native tokens, after which evidence is checked to see if it falls within this range. Current results cover this class of textual evidence. [Original Study §2.2](https://aclanthology.org/2021.naacl-main.365.pdf#page=3) · [QASPER Public Data](https://huggingface.co/datasets/allenai/qasper) · [Build Program](../../research/semantic_tracking/qasper_prepare.py)

Fix Qwen3.5-2B. For each paper, include the title, abstract, and original-ordered paragraphs, averaging the end-of-segment state from a single causal forward pass and the states between two reading stops. Questions are independently encoded with the same backbone for readout research, with each paper's questions sharing a single document representation. Content features for each reading stop rely only on current and previously read text. Freeze Qwen's state and train a linear readout with an L2 coefficient identical to the backbone. [Causal Features](../../research/semantic_tracking/qasper_extract.py) · [Readout](../../research/semantic_tracking/qasper_fit.py)

| Conditions | Visible content |
| --- | --- |
| Positional Baseline | Paragraph order, visible character count, and current segment length. Assign identical scores to all questions within the same article and same reading stop. |
| Body + original question | Incorporate the in-corporation status and its interaction features with the original query representation. |
| Body + Exchange Questions | Reuse the same readout, maintain the body text and reading stop, and evaluate the evidence interval of the original query against another question from the same article. This comparison does not refit nor re-execute the article's backbone. |

The text is segmented by paragraph. Reading the title and abstract constitutes position 0. When all labeled evidence is present in paragraph \(e\), the training interval is \((e-1,e]\). Given the conditional probability \(h_t\) at paragraph \(t\), the survival probability is \(S(t)=\prod_{j=1}^t(1-h_j)\). Taking \(-\log[S(e-1)-S(e)]\), a lower value indicates a higher probability assigned by the model to the labeled evidence interval. Earlier prefixes may contain unselected cues. thus, this event represents only the arrival of the adopted labeled evidence. [Interval Fitting](../../research/semantic_tracking/qasper_fit.py)

We compare all questions against the corpus baseline and the position baseline. The three matched groups cover 41 question–answer pairs from the same paper, with each pair comprising two distinct evidence paragraphs. both directions of the question swap are included. Additionally, at the same reading stop where earlier evidence arrives, we check whether the model assigns a higher probability of "readout" to that question, counting ties as half-points. Sampling units are papers, using the same fold, prediction, and trial. Test evidence is retained in the local machine. inference input contains only unmarked text, reading stops, and the mapping keys between articles and questions. Before scoring, we verify the predicted sealed snapshot. [Scoring and Pairing](../../research/semantic_tracking/qasper_score.py)

## held-out results

| Incorporate the same 41 pairs of questions and 82 scoring directions. | Evidence interval average NLL (nats, lower is better) |
| --- | ---: |
| Positional Baseline | 3.2670 |
| Body + original question | 3.1061 |
| Body + Exchange Questions | 3.1294 |

The NLL difference relative to the baseline of the original question's position within the main text is −0.1610 nats, with a 95% paired confidence interval [−0.2869, −0.0431]. Relative to the same main text under the swapped question condition, the difference is −0.0234 nats, with an interval [−0.0822, +0.0343]. When no question pairing is performed, the main text and position baseline NLLs for the 55 questions are 3.0370 and 3.2273, respectively, with a paired difference of −0.1904 [−0.3104, −0.0752]. [Scores and Paired Intervals](../../research/results/qasper-evidence-first-run/scores.json)

In the same document, a fixed reading stop was placed at the end of the earlier evidence segment, yielding identical scores for both the position baseline and the readout. The readout achieved a hit rate of 50% under the half-scoring scheme. For the main text group, the cumulative probability ranking of readout versus evidence was 21 wins and 20 losses, reaching 51.2%, which is 1.2 percentage points higher than the position baseline, with a 95% confidence interval of [−11.8, +14.7] percentage points. Considering only the conditional probability of the current segment, the hit count remained 21 wins. While main text features aid in locating the annotated evidence interval, the comparison between the original query and the swapped query is insufficient to confirm whether this readout correctly identifies which query it is answering. This round did not meet the previously established joint training inclusion criteria. ## Execution and Reproducibility

Colab L4 retrieved 83 papers and 206 questions, totaling 222,272 non-padding tokens and 2,214 alignment reading stops, with no token alignment exclusions. 12 prefix positive/negative controls passed. Retrieval and readout took 95.05 seconds. the in-process timer recorded 2.03 seconds. peak CUDA memory retention during retrieval was 9.45 GiB. Configuration confirmation to issue the stop request took 202.41 seconds, and release was confirmed. The account had concurrent other activity assignments, with the overall balance decreasing from 760.86 to 760.49 CU.
