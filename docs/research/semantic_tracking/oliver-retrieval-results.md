# Vocabulary extraction responses for the same reader held-out

On 14 unseen target words and 728 vocabulary extraction trials, the Qwen3.5-2B state extracted from the definition endpoint did not improve the held-out probability of complete response generation. The model replicated the direction of two human effect sizes, with both 90% confidence intervals failing to fall within the pre-specified ±5 percentage points. All three readouts received no answer or no key press from the reader at that moment, predicting the joint probability of all possible paths generated from the definition endpoint. ## human events and sources denominator

52 readers each viewed 44 items, yielding 2,288 initial–retest paired comparisons. Of the 1,272 initial trials, 15 seconds were held. 245 were keyed as KNOW. All initial trials included post-reveal yes/no confirmation, with 1,163 keyed as "yes." Raw data lacked pre-reveal oral transcripts, so KNOW responses are treated as reader reports. The post-reveal binary key asks whether the displayed answer equals the reader's intended target. No new text coordinates were provided after reading the definition. these trials offer a connected report from the same reader in a guided lexical extraction task. [Original study §§3.2.2, 4](https://doi.org/10.1525/collabra.200) · [Source audit](../../../research/results/oliver-retrieval-source-audit.json)

The definition column for one item in the table was merged and missing. Excluding the 52 instances of this item, the model fitted 1,508 instances across 29 targets and tested 728 instances across 14 targets, with both definition versions grouped together. The test and fit materials were non-overlapping, using the same reader population distribution without personal identification or response history included in the model. Retest was grouped by the definition actually used during the session. Across all original trials, the retest re-report rate of TOT was 68/269 for the same definition and 53/259 for the alternative definition. ## Execution and Reproducibility

Using the same Qwen backbone revision as the Gradio candidate, run one FP32 causal forward pass on Colab L4 for each of 86 source definitions. The 1,556 input tokens yielded 86 exactly aligned definition endpoints. All 12 additional prefix-consistency checks passed. Forward passes and readouts took 1.20 seconds, and model feature extraction took 40.58 seconds. The L4 release was confirmed. All four CPU scoring outputs were byte-identical on rerun. An independent program reproduced all point estimates, with a maximum discrepancy of $7.33\times10^{-15}$. Original responses and vectors remain in the working cache.
