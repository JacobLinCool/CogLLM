# Core Vocabulary source audit

The public release identifies when readers first guessed a masked word correctly across six possible sentence exposures. It contains **4,680 reader × target trials from 195 readers across 96 targets**, with 1,356 trials ending without a correct guess. The release omits the sentence selected for each reader at each exposure. It supports a group-level first-correct analysis across exposure ordinals. An assay that gives CogLLM the exact text each reader saw requires the missing stimulus IDs. [Wang et al., Experiment 1](https://doi.org/10.1525/collabra.160142) · [Released trial data, revision 1](https://api.osf.io/v2/files/68cba1d89141552d3c53d86f/versions/1/)

## What the experiment observed

Readers saw one new sentence at a time and could still see the earlier sentences. Five full-block characters masked the same target word in each sentence. The task asked readers to guess after every exposure. It stopped after the first accepted guess or after six attempts and then revealed the answer. The authors randomized one sentence from each of six predictability bins and presented the bins from lowest to highest predictability. Readers could see their previous guesses. The endpoint is an accepted answer to a prompted lexical task. Its time axis is the number of exposed sentences. [Experiment 1, Procedure](https://doi.org/10.1525/collabra.160142) · [Author demo, sampling and trial code](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/main.js#L20-L48) · [Author demo, cumulative presentation and stopping](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/main.js#L378-L441)

We retained rows with `exp == 1` and `stim_set == Original` in the 68,424-row trial release. The 4,680 retained rows contain unique `(subject, trial_num)` and `(subject, target)` pairs. Each reader has 24 retained rows. Trial ordinals 10 and 20 are absent, as expected from the two unanalysed catch trials in the Methods. Each target has 31–59 reader trials. `correct == 1` records a first correct guess at `guesses`. All rows with `correct == 0` have `guesses == 6`, so we treat them as right-censored after the sixth attempt. [Experiment 1, Participants and Procedure](https://doi.org/10.1525/collabra.160142) · [Author survival analysis](https://osf.io/download/9wm7d/?revision=1) · [Released trial data](https://osf.io/download/pbcx6/?revision=1)

The conditional probability of a first correct guess is the first-correct count divided by trials still at risk at that ordinal. The cumulative event-free probability multiplies one minus that conditional probability over observed ordinals. Censoring follows the event count at ordinal 6. The risk sets sum to 19,943 attempted positions inferred from the terminal trial summaries. The release has one summary per trial. [Released trial data](https://osf.io/download/pbcx6/?revision=1)

The paper defines a number-of-guesses outcome for successful trials and uses event status in its survival analysis. The released per-target column `meanGuesses` averages the observed terminal ordinal across all trials, including six attempts for each right-censored trial. Recomputing those means agrees with all 96 target rows under the all-trial denominator and with zero under the successful-trial denominator. The pooled mean terminal ordinal is 4.261 over 4,680 trials. The pooled mean first-correct ordinal is 3.552 over 3,324 successful trials. These are separate estimands. ## Why the individual prefixes cannot be recovered

We matched all 3,456 stimulus keys in the released sentence pool to the fixed author demo inventory. Each target has 36 sentences in six bins of six. All 576 bins contain six distinct masked strings. The author demo's mask exactly replaces one occurrence of the target in each source sentence, with case ignored when checking the replaced words. The audit finds zero duplicate strings across the pool and within targets both exactly and after NFKC normalization, case folding and whitespace collapse. It checks exact and normalized equality only. [Released corpus sentence pool](https://osf.io/download/rp2zg/?revision=1) · [Pinned author stimulus inventory](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/csv/stim.js)

For the lexicographically first target, the first two stimulus keys in bin 1 correspond to two different valid first clues of 80 and 65 Unicode characters after HTML entity decoding. Complete either path with an identical legal sequence from bins 2–6. Both paths follow the published randomization. A hypothetical terminal summary retaining the target, first-correct ordinal and correctness would have the same fields under both cue paths. The available files give no rule that selects one rendering for a reader. The demonstration uses pool membership only and assigns neither clue to a participant. [Pinned author stimulus inventory](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/csv/stim.js) · [Pinned author sampling implementation](https://github.com/andreww3/codewords/blob/bf8c249a688211f4085db2905a1e8e09804a9d8a/main.js#L29-L46) · [Released trial schema](https://osf.io/download/pbcx6/?revision=1)

The demo client defines `trial_num`, `target`, `guess` and `stimulus` for each attempt. The public Experiment 1 summary contains no `stimulus` or individual `guess` record. The 20,772-row BERT response file contains stimulus-indexed response aggregates from Experiment 2, which used one guess per trial. It provides no link from Experiment 1 participants to a stimulus sequence. The minimal missing export is a deidentified subject key, trial number, within-trial exposure ordinal and stimulus ID. The released trial summary can supply the event label if the original subject and trial keys join exactly. A model that conditions on the reader's visible history of guesses would also need the recorded guesses. ## Use in CogLLM

Retain the observed survival curve as a group-level endpoint over randomized cue exposure. Testing a model at that level would require averaging its forecasts over the documented sampling design. Such an analysis would compare distributions of first-correct ordinals. Exact localization in an observed reader's history requires ground truth at the realized prefix. This study solicits a lexical guess after each sentence, so its observed support is sentence exposure in a prompted task. [Experiment 1, Procedure](https://doi.org/10.1525/collabra.160142)
