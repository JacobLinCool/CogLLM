# The next sentence is judged consistent. does this imply the original query has been resolved?

Frick and Schüler's sentence-by-sentence task requires readers to judge whether the **current sentence** contradicts the preceding context. After readers press the contradiction key `D` on the target sentence for the first time, both conditions exceed 92% in pressing the consistency key `K` on the next sentence. This transition occurs during the judgment of another sentence. If `D → K` is directly treated as the same question resolution, the model would achieve a high surface resolution rate but lack confirmation of the original contradiction. ## Directly verifiable same-question data

TED-Q has integrated the original questioner, the query, and subsequent ratings. A reading stop occurs every two sentences, allowing estimation of the interval until a query first achieves "at least partially answered." When the threshold is not reached, tracking terminates and the analysis is treated as a censored observation at the actual observation time. Once the threshold is reached, tracking ceases, and a complete answer requires additional observations. The analysis can first be fixed by holding out speeches, checking whether the same visible text improves the prediction of the first-to-threshold interval for correct queries relative to other queries swapped in.
