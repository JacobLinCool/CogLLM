# Frick's earlier text manipulation sentence localization results

Across 20 held-out comparisons, adding Qwen's suffix representation failed to meet the relative position literal source sentence localization threshold. Sentence 5 in the text represents the manipulation position for 19 groups, with a top readout hit rate of **95%** for all. Group 18 actually modified sentence 6. Regardless of consistent or inconsistent versions, the Qwen group ranked sentence 5 first. Across all earlier sentences, the Qwen group's probability of selecting the true source was 1.73% and 0.60%, respectively. NLL is the negative log-likelihood, measured in nats per target, where 0 is ideal and lower is better. The final column uses position-plus-literal as a baseline. positive values indicate that the Qwen group assigns higher probability to the true source. The Qwen group outperforms the absolute sentence-order frequency for all earlier sentences, with an NLL improvement of +0.1131 [+0.0641, +0.1536], which remains below the threshold relative to a pure position baseline using available relative distance. Each candidate set contains 40 target sentence instances, covering 160 and 504 candidate groups respectively. Each outer fold held-out two versions of the same story, with sampling units at intervals of 20 story groups. This result constrains the questions that the Frick control material can answer. When the position is almost always the 5th sentence, a 95% hit rate can be explained solely by sentence order. For the same target sentence, the human's first contradiction key can still validate the effect of prior conditions on report position and probability. To verify the earlier text pointing shown to the user, variation in source position and records of the same reader identifying the earlier text are required. This batch of human keys only provides a negative judgment for the current sentence. When verifying 928 prefix-candidate pairs, features and predicted log probabilities remained identical after truncating the un-read suffix.
