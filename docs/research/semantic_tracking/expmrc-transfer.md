# Freezing readout transfer of ExpMRC RACE+

Using the ExpMRC RACE+ open development set, we evaluate whether the QASPER readout, previously trained on academic papers, can distinguish in English test articles which of two specified questions from the same passage requires which evidence. ExpMRC annotators select short spans visible in the full text that are sufficient to support the answer, and these are verified for sufficiency by a separate group of raters. The dataset comprises two reference spans per question. The primary endpoint is the point at which a human-annotated complete span becomes visible. The point at which respondents first identify the evidence is not recorded. sealed snapshot: 167 texts, 561 items, and 1,122 reference spans. Cross-checking against the QASPER corpus yielded no substantial text overlap, with two items partially overlapping with previously evaluated RACE materials. These two items (`0c4f08f3`, `1b332837`) were excluded from primary scoring, and a full sensitivity analysis was conducted on the remaining set. The inference package contains only verbatim text, prompts, and IDs. options, answers, and reference spans are reserved for the scoring stage. We adopted the frozen Qwen3.5-2B FP32 causal backbone proposed by Gradio, performing a single forward pass per text. Leveraging the English Punkt segmentation from the sealed snapshot, we truncated sentences to independently reproduce the native token state at their ends, with the complete final sentence serving as the last reading stop. If a sentence end cannot align, it is merged into the next alignable reading stop and logged. We utilize segment-level token projections interacting with the existing log-mean-exp. Each item is encoded separately, sharing the article's text state. This experiment employs a control design with known prompts to estimate the visibility of labeled evidence within reading prefixes.

We adopt the four readouts (projection, geometric scale, coefficient) and the original QASPER sealed snapshot. The four groups correspond to position, stem, paragraph interaction, and per-token interaction. The latter two groups utilize the weights from the original QASPER experiment that incorporated ranking supervision. The fixed file SHA-256 is `5bf54b491e1d1be375a12fa1e2e1dbc8c5c5127ed242d203465f1c1fee679ec7`. We employ the same state and coordinate reuse for both the main text readouts, without updating weights using the ExpMRC dataset. Each human evidence is readout to the first reading stop that covers its end character. For each reference evidence, the interval NLL and cumulative Brier per reading stop are computed, then the two reference evidences for the same question are given equal weighting. The NLL is the negative log of the probability assigned to the labeled interval, where 0 is optimal. The cumulative Brier is the mean squared error between the probability of having read the complete evidence and the binary label, ranging from 0–1, with 0 being optimal.

Pairwise matching requires that both reference documents for two questions can be fully ordered with non-overlapping scopes. The comparison cutoff is the reading stop of the first document covering the earlier question. at this point, no complete document for the later question should be visible. For the same text and reading stop, compare the cumulative probabilities of the two questions: the earlier question receives one point if its probability is higher, and half a point for a tie. Score the reference intervals of both questions using their respective and swapped probability distributions, calculating the average original question minus swapped question NLL per pair. With article-group pairwise resampling 10,000 times, seed 20261121, retain the article's question and pairing within the same sampling. Report the per-token readout difference relative to position, stem, and paragraph readout. Support evidence for cross-corpora distinguishing different interrogatives only if the 95% pairwise confidence interval lower bound for the relative position and stem improvement of the same reading stop ordering is greater than zero, and the upper bound of the original question minus swapped question NLL is less than zero. Additionally, report the overall interval NLL, Brier score, and the agreement rate of the two marked end positions.
