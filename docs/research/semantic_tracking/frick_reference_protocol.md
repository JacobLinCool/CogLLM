# Frick Contradiction Source Sentence Localization Specification

This retrospective experiment tests whether the model can identify the earlier sentence manipulated by the researchers when it reaches the target sentence. Retain the 20 text-only story pairs from Frick and Schüler's Experiment 1. Each pair has two versions with the same target sentence and a change to just one earlier sentence. That sentence defines the manipulation location and maps exactly to the source text. The consistent version has the same location, allowing both versions to be scored. A reader's keypress reports whether the current sentence is inconsistent. The study does not identify which prior sentence a reader relied on. This endpoint measures localization of the experimental manipulation separately from human first reports. [Original data and alignment](frick-consistency-source.md) · [Human first reports](frick-signals-results.md)

Before model scoring, we verified that the manipulated sentence appears at position 5 in 19 story families, and at position 6 in the remaining family. This establishes absolute sentence order as a critical control variable. For the current sentence $t$ and the previous candidate sentence $j<t$, we constructed three sets of nested features. The position set includes log sentence distance, its square, individual indicators for 7–10 sentences, and log absolute sentence order, its square, and indicators for positions 5 and 6 for the candidate sentence. The literal set additionally incorporates shared lemma features. The Qwen set further includes the two final-position representations from the same forward pass, along with the cosine similarity between them and the adjacent final-position difference vector. All features are derived solely from the read prefix. no other story version, independent single-pass forward, conditional, or actual target position is used. Additional absolute sentence order frequency contrasts are computed only over the manipulated sentence orders within the training family, with each candidate normalized by adding 0.5 to its count.

First, use all earlier sentences as candidates, then fit a control-range constraint using independent weights. The control range retains only sentences within 7–10 positions earlier. all four distances are covered by the same experimental design, allowing direct comparison of pure distance and content features. Fit linear softmax to both ranges and three feature groups. Training uses the researcher's target sentence and manipulation position, minimizing the sum of negative log-likelihood across 38 training versions with equal weighting, plus $0.05\lVert w\rVert_2^2/2$. Estimate column centers and scales from candidate columns in training queries, with equal weighting across columns and equal weighting across candidate columns for the same query. Set constant column scale to 1. Fix the penalty coefficient without additional model selection. Perform 20-fold cross-validation, holding out both versions of the same story. For held-out folds, compute candidate probabilities for all valid reading stops starting from the second sentence, take a sealed snapshot, and score by taking the target sentence and manipulation position. Exclude reading stops lacking candidates in the control range from scoring.

The primary endpoint was the source sentence negative log-likelihood of the first 7–10 sentence group. For the Qwen group, improvements over position-plus-literal, pure position, and absolute sentence order counts must each have a 95% story matching bootstrap confidence interval lower bound greater than zero. All earlier sentence groups were re-evaluated with the same comparison. Additionally, report the exact first-hit precision, mean reciprocal rank, and results conditioned on the prefix, while isolating the result for sentence 6, which differs from other families. For tied NLL scores, use the original probability. for ties in hit and reciprocal rank, take the expectation over the tied permutations. Both versions were first averaged with equal weighting within stories, then across 20 stories with equal weighting. Bootstrap 10,000 times with seed 735972, using the same story weights across both conditions and all models. No key results were included in the estimation. the sampling unit was the story.

Verify the features and probabilities under fixed weights for complete and truncated prefixes, the coverage of reading stops on held-out stories, the training version details, and the data and weight hashes with reproducibility. The materials have been used in other endpoints by Frick, and the results constitute a retrospective validation. Even if both groups pass the ranking thresholds, the new materials must include a sufficient number of source sentences from different positions to enable testing of localization and its contribution to the distribution and magnitude of human first reports.
