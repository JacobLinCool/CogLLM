# The first disambiguation cue at the readout when encountering the term

The original experiment has sealed snapshot in-sentence ordering results. This study performs a retrospective supplement on the same material, measuring whether the first prompt, when ignoring subsequent text, falls exactly on an author-marked position or appears too early. Each position retains the original logit from the word-level model. Candidates are compared against a fixed threshold, with current and later words undergoing no common normalization. The end of the first word strictly exceeding the threshold is retained. If no word exceeds the threshold, it is recorded as no prompt. [Word-level readout specification](blott_word_protocol.md)

Adopt the 2021 five-fold word-order cross-validation. When the test fold is $k$, use the next fold $(k+1)\bmod 5$ for calibration, and fit the remaining three folds using the original specification. For each calibration sentence frame, take the highest score among all evaluatable words preceding the author cue across two coherent versions. There are $m$ calibration sentence frames, with the threshold set to the $\lceil0.9(m+1)\rceil$-th highest score in ascending order. If this rank exceeds $m$, the threshold is positive infinity. Using the sentence frame as the calibration unit, a sentence-frame-level false positive is counted if either version triggers an early hint. Under independent and identically distributed or exchangeable sentence frames, this order statistic constrains the risk of early triggering prior to the mark. The effect is first averaged across two versions in unseen sentence frames, then averaged across all sentence frames. Compare the literal, state-change, and full-state methods of the original specification, each having its own threshold. The full-state method shows improvement in exact hinting rate relative to the two control conditions. its sentence-frame pairing resampling 95% confidence interval lower bound must be greater than zero for all. Additionally, check the sentence-frame-level early-hint proportion for the full-state method, where the two-sided 95% Clopper–Pearson upper bound must be less than or equal to 10%. Use 10,000 resamples with seed 735972.

In 2023, no fitting or calibration was performed. Calibration was conducted using the 2021 fold 0, while the remaining four folds underwent full fitting. The comparison utilized the same threshold as the previously used 44 2023 sentence frames. In 2023, the cue position shifted from intra-sentence to sentence-final. this group reported only cross-study retrospective results. The statistical unit for both studies was the stimulus cue placed by the researcher. The time to first generate a query or confirm understanding remains to be validated separately via human data.
