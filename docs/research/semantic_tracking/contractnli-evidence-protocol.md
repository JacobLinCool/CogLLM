# ContractNLI hypothesis evidence independent held-out validation

We examine whether per-token readout scores trained on QASPER can shift to another group of corpus evidence when the specified hypothesis changes, using English materials not used in readout training. This experiment employs 47 EDGAR confidentiality agreements and 17 fixed hypotheses from the official ContractNLI test split, totaling 799 hypothesis–corpus combinations. Evidence selection is manually annotated and visible in full text, allowing spans to span multiple sentences or list items. The experiment evaluates the model's probability of text position and the readout of the annotated segment, without corresponding human detection or resolution time. [Original Study §2.1](https://aclanthology.org/2021.findings-emnlp.164.pdf#page=2) · [Source, Split, and Alignment](contractnli-evidence-source.md)

## Freeze readout and source coordinates

Using the Gradio candidate Qwen3.5-2B snapshot `15852e8c16360a2fea060d615a32b45270f8a8fc` and the four readouts from the sealed QASPER snapshots `position`, `question_only`, `pooled_rank`, and `token_rank`. The entire corpus is forward-passed once, and each hypothesis is independently forward-passed once while sharing across documents. Each document reading stop uses only the prefix available at that time, with no generative decoding. No ContractNLI adapter or calibration parameters were applied. First, predictions are made using the sealed snapshot, followed by merging with human results. [QASPER weights and scores](../qasper-factorial-run.md) · [prior independent transfer](expmrc-transfer-results.md)

Retain the full complete text, selecting only the longest 8,192 model token retrieval condition. This covers all 47 articles. Candidate positions are taken from the half-open character range provided by the author, removing pure whitespace items and skipping trailing whitespace at the end of each paragraph. Retain the rest of the original text and the full end of the text, verifying each reading stop individually against the prefix of the separately tokenized word. Uncountable candidates that cannot be aligned are counted separately. Sorting only evaluates alignable candidates. positive examples must align with all author-marked evidence. Each proposition compares candidates only within the same article, and the full text end is used to define the remaining probability. [Author Section Index](https://stanfordnlp.github.io/contract-nli/#dataset-specification)

Four readout outputs are the probability of reading stop, ranked using the current segment's hazard. Additionally, a BM25 baseline is constructed over all candidate terms in each document. NFKC normalization, casefolding, and Unicode number-word conversion are applied, followed by term deduplication. IDF is computed only within the candidates of the current document. Fixed parameters are \(k_1=1.2\) and \(b=0.75\). Both BM25 and the four readout groups use the same candidate set. `pooled_rank` and `token_rank` share identical training supervision and parameter count, differing only in whether local readouts are represented by segment-averaged features or token-level interactions. ## Ranking and effect

- **Average Precision (AP).** For each document and each hypothesis, sort candidates by score in descending order and compute the AP for labeled evidence. Apply a threshold jointly for scores tied at the same level. AP ranges from 0 to 1, with higher values indicating greater concentration of labeled positions in the prefix. Report support and rebuttal separately.
- **Same-document hypothesis matching.** For each document, select exactly one supporting hypothesis and one refuting hypothesis, ensuring the complete sets of human evidence for both hypotheses are non-overlapping and alignable. For each hypothesis, compare the average score of its entire evidence set against the average score of the opposing hypothesis's entire evidence set. Assign 1 for a win, 0 for a loss, and 0.5 for a tie. Average these scores across both directions, then apply equal weighting within the document. This endpoint measures whether the position of the higher score shifts when the hypothesis changes.

Each endpoint first averaged within-file by rated or paired items, then averaged within-file groups, with equal weighting across groups. Resampled 10,000 times with seed 735972. All readouts used identical resampling to compute 95% percentile intervals. Primary acceptance criteria `token_rank`'s AP and paired-item matching scores relative to BM25 and `pooled_rank`'s four-item difference interval lower bounds are all above zero. Effect magnitudes and intervals are reported on the original scale. Samples allow different items from the same contract to share evidence, and may exhibit similar writing templates. File-group processing verified identical body text and source URLs.

## The probability of readout evidence

Post-report NLL, the probability of the final reading stop, and cumulative Brier after the entire set of marked evidence has been read. For propositions marked by the author as present and fully alignable, the observation point is the last marked candidate end. For propositions marked by the author as not mentioned, the remaining probability is assessed at the end of the text. Sequentially apply four groups of raw hazards, four groups of sealed snapshots via ExpMRC calibration, and QASPER-mixed human-labeled calibration with sealed snapshots for time and tail remaining calibration. The model estimates the probability that literal evidence has occurred. Multi-segment may represent repeated evidence. the final marked position cannot be interpreted as the point where sufficient information was first available. This set of probability metrics serves as supplementary comparison, distinct from the primary rank acceptance test.
