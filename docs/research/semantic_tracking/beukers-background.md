# Reader practice history and story clues

Beukers et al. exposed readers to the same number of fictional coffee shop stories across two ordering conditions. Each group read 160 stories initially. the block condition switched shops every 40 stories, while the interleaved condition switched shops after every story. The final 40 stories were randomly selected from coffee shops common to both groups. In each story, readers chose one of two candidate events at two predictable transition points. This experiment tests whether CogLLM, when given a known practice order, can replicate the magnitude of choice shifts driven by prior contextual cues on independent readers. [Original Study Fig. 3 and Methods](https://gershmanlab.com/pubs/Beukers24.pdf#page=4) · [Replication Study Pre-registration](https://osf.io/ebxfa/) · [Fixed Data Version and Recalculation](written-reference-update-source.md#beukers-reader-background-experiment)

## Data and held-out

Using the published data following the author's attention filtering, we fitted the original experiment and independently re-ran the held-out samples. Both the baseline and Qwen conditions utilized `story` 160–199 two-predictable transitions, with the second transition requiring a first reading stop and the actual subsequent event. Each split included only identical person names, visible paths, candidate events, and left-right order present in both groups. Text was reconstructed from a fixed template in Methods and CSV fields for person names, coffee shops, and paths. Verbatim records of the original images were not published. Both groups had encountered the same story structure. acceptance criteria were replicated on the other group of readers without estimating generalizability to new story structures. Responses from the re-run samples were integrated only after the fit parameters were sealed in a snapshot. [Stimuli and Presentation Procedure](https://gershmanlab.com/pubs/Beukers24.pdf#page=12) · [Author-published sealed snapshot](https://doi.org/10.5281/zenodo.10695055)

## Single forward and comparative

Using the same frozen Qwen3.5-2B and 128-dimensional projection as the current Gradio candidate, perform FP32 causal forward passes on each unique visible prefix. The candidate refers to options displayed at the time of the experiment. Each unique candidate sentence is independently encoded and shares representations, with tokens in the prefix not continuing the candidate text. The readout retrieves the vector at the end of the coffee shop clue sentence and the prefix end from the same forward pass, and performs interaction with left and right candidate vectors. The first sentence introduces the character, and the second provides the coffee shop clue. All models are fitted with the same data to estimate the probability of selecting the right-side candidate.

- **Qwen main text**. Using left-right candidate vector difference, coffee shop clue sentence end and candidate difference per-dimension product, prefix end and candidate difference per-dimension product, and corresponding cosine difference. Both positions are processed with the same fixed projection.
- **Qwen additive**. Additionally, include independent coefficients for known blocks or alternating groups to control selection bias that does not vary with content.
- **Qwen interaction**. Additionally, allow the group to alter the weights of the above Qwen features for selection. Groups are assigned based on pre-test reader testing.
- **Qwen probabilistic calibration**. Use the frozen logit from the main text, add a group offset, and allow the group to scale the main text signal via a single coefficient. This approach can determine whether more elastic interaction terms exceed the results achievable through global strength calibration.
- **Structural interaction**. With visible coffee shops, node paths, and candidate identities combined as category controls, report the performance achievable by simple finite-condition statistical estimates. These categories are derived from the author's experimental markers as diagnostic baselines.

Minimize the readout equal-weighted binary negative log-likelihood with group equal weighting and fixed L2 penalty 0.01. Qwen's base vectors are scaled by fixed projection dimension, without held-out data normalization. Select intercepts are unpenalized. Calibration controls also use raw samples, and finally the sealed snapshot fits all parameters. Early individual responses are reserved as candidates for subsequent validation of actual knowledge. the main analysis uses only the previously assigned order.

## The fixed held-out threshold

1. **Sequential selection.** In trials where both groups share identical prefixes and left/right options, Qwen's interactive NLL must decrease relative to Qwen's baseline and additive NLL. With readers as the sampling unit, performing within-group resampling 10,000 times, the upper bound of the 95% confidence interval for the paired difference must be less than zero. NLL is measured in nats, where lower values indicate a higher probability assigned to the human-selected candidate.
2. **Early text effect.** Fix the first detection read at `NODE11`. For each reader with trials available in both stores, calculate the proportion difference of choosing `NODE21` in Deep Ocean minus Jungle. Take the mean of the block and interleaved group readers. The block minus interleaved effect difference should be positive, and the lower bound of the 95% confidence interval for the interleaved readout must be greater than zero. The human difference in each group must fall within ±15 percentage points in the 90% confidence interval, and the human difference between the two effect differences must fall within ±20 percentage points. The magnitude tolerance was pre-set as the experimental threshold of this study. the original paper's inference did not use these tolerances.

The full set must meet the threshold to pass this controlled endpoint. Differences from global probability calibration and structural baselines are reported separately to avoid interpreting overall confidence shifts as independent adjustments to each text cue. In this experiment, the reader background is the researcher-assigned practice order, and the endpoint is the researcher-specified next event selection. General article background knowledge intensity, first stuck position, and resolution of the same query must have corresponding observations.
