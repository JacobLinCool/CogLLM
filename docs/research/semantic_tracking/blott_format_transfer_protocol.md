# Cross-study held-out specifications for Blott's re-interpretation of the term "semantic blott"

Test whether the existing Qwen3.5-2B Gradio sentence-end comprehension score reproduces the lower rate of “makes sense” responses when a word must be reinterpreted. Use the 2021 data to fit a keypress-probability readout. The holdout consists of coherent written sentence pairs displayed in full in Experiment 1 of the 2023 study. Each pair has a version requiring reinterpretation and a version without the target ambiguity. The primary outcome is the Sense keypress on each trial. Following the author's analysis, retain trials with response time greater than 250 ms and then pair readers' responses for both versions displayed in the same format. Exclude a 2023 pair in advance if either version shares a normalized sentence, a frame with the critical noun and cue masked, or a critical noun–cue combination with the 2021 materials. Record standalone shared five-word spans separately. Use the public within-study IDs for readers and stimuli. [2021 data](../stage6/blott-coherence-holdout.md) · [2023 study, Experiment 1](https://doi.org/10.1080/23273798.2022.2159992)

Fix the model to Gradio candidate `74c26ff02569b2b3bc28ed291bf15fd2f85db5b4c93a3ad7bfc34f6a5d333ea0`. Use the original sentence as the only input and make one causal forward pass per sentence. At sentence end, obtain the expected 1–5 ratings for self-rated comprehension and reading ease. Reuse 47 sealed coherent sentence pairs, 94 sentence ends, and 2,256 binary keypresses from 2021. Both keypress readouts use the same mean trial-level binary negative log likelihood plus $0.05\lVert w\rVert_2^2/2$ on nonintercept coefficients. The surface control uses the log character count and log whitespace-delimited word count of the whole sentence. The model arm adds the standardized fixed comprehension score and constrains its coefficient to be nonnegative. Center and scale each column by the mean and standard deviation with equal weight per training sentence. Omit ambiguity condition, reader background, and correct-answer features. Exclude 2023 responses from model selection. Keep the uncalibrated comprehension and reading ease scores as separate rank-only comparisons.

The primary metric is the surface-level contrast reduction model's binary negative log-likelihood, measured in nats per keystroke, where positive values indicate improvement. Following the sentence frame equal weighting approach, the average of paired readers is computed within each frame. Additionally, the difference in the ratio of senses requiring re-solution for unambiguous reduction is evaluated. The directional threshold requires the lower bound of the 95% confidence interval for both the model and human to be greater than zero. The magnitude threshold requires the 95% confidence interval of (model minus human) to be fully contained within ±5 percentage points. Furthermore, the lower bound of the 95% confidence interval for the primary NLL improvement must also exceed zero. All three criteria must be met to support the readout's generalization of this human behavior across study conditions. Cross-validation is performed using shared sampling weights for readers and material families, with 10,000 iterations and seed 735972. The report includes the hit rate for the human's harder version, controlled by fixed understanding and difficulty, and contrasted against negative character count and negative word count. Ties are counted as half-points. Only the independent scores for the two versions are presented in the main text, without paired comparisons.

In 2023, manipulation and substitution of earlier key nouns and final words occurred, with variations potentially existing before the final word. If readout scores are extracted from the single prefix immediately preceding the end-of-sentence cue, and the paired difference is reported, the character and word-length features must be derived from the prefix at that time, without using full sentence length. Any final-word coordinates provided by the design are solely for alignment and scoring. Human judgments were provided as binary decisions after viewing the complete sentence. the data included end-of-sentence cue coordinates but did not include first-person observations of ambiguity resolution, anaphora resolution, or word-by-word confirmation of resolution.
