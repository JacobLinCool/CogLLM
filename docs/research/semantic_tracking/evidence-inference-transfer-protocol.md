# Can the body text evidence for a specified question be located across genres?

In the English contract held-out set, fusing the vocabulary score with the Qwen score (after subtracting shared-position scores within the same document) improved full-document evidence ranking and same-document hypothesis matching. This experiment used the complete English paper of Evidence Inference 2.0 to test whether these two improvements could transfer to scientific main text and distinct question sets per document. The observed results were the evidence intervals selected by physicians after reading the full text. This data contains no per-token uncertainty, resolution time, or cognitive load score. [Contract held-out results](contractnli-rerank-results.md) · [Paper data source](https://aclanthology.org/2020.bionlp-1.13/)

## Materials and held-out

Sample only from the official test split of the fixed source version `a661e8c14f973398380c8865cf2f27a535aaaf6d`. Compute SHA-256 hashes by concatenating `cogllm-evidence-inference-transfer-v1:` with PMCID containing only digits, then sort by hash. Sequentially include papers that explicitly permit reuse, pass authorization checks, retain full author text, and contain at least two distinct valid questions. Each paper-body and each question individually must not exceed 8,192 Qwen tokens. Scan sequentially, skipping items that exceed the remaining 145,000 token budget, including a maximum of 24 papers. During sampling, use only source identifiers, text, questions, and authorization. Exclude specified queries known by authors to be erroneous or format-invalid. Equivalent questions from the same paper are deduplicated via NFKC normalization, whitespace merging, and casefold, retaining the minimum author PromptID. Questions use the same format `What was reported for {Outcome} when comparing {Intervention} with {Comparator}?`. Evaluation does not follow the original study's clinical outcome groups nor predict clinical outcomes. [Data, Version, and Coordinates](evidence-inference-source.md)

First, sentence boundaries are segmented from the original text using the English Punkt tokenizer provided with the candidate checkpoint. The original full string tokenization is compared against the independent prefix tokenization at each sentence end. only sentence ends that can be fully aligned are retained as candidates. For each document, the complete reading stop of the validation file is also verified. Positions that are blank or cannot be aligned are excluded as candidates. All predictions are first sealed in a snapshot and then combined with the evidence from the same document. Human evidence is restricted to approved answers and justifications, where the original half-open character interval can fully reconstruct the annotation of the original quote. Each valid annotation retains an independent interval, even if different annotations map to the same interval. If any non-blank character of a valid annotation does not align to a candidate, it is recorded as unassessable. Missing annotations are not counted as negative examples.

## Freeze readout

Qwen3.5-2B employs both fixed snapshots and QASPER token sorting heads, performing a single causal forward pass per article. Each known external problem is independently encoded once. At each sentence end, the original per-token head hazard logit is used, reapplying the contract experiment's subtracted shared score rule. This shared score is the average logit of all qualified problems in that article at that reading stop. Vocabulary scores use the average candidate length within the candidate range of already-read text, identical word segmentation, contract data, and fixed BM25 parameters (k_1=1.2), (b=0.75). The contract IDF variant maintains the original setting, with an additional version where each identical word IDF is set to 1. Both vocabulary score groups take \(\log(1+\mathrm{BM25})\). Fusion coefficients, feature standardization, and contract vocabulary statistics are loaded as-is, with SHA-256 set to `8dbd9e3fdc1a538f90736d55e7b793835692ef7276a4908a4562aab5516160fe`. The entire batch of papers held-out is not tuned. ## Scoring and thresholds

For each annotator, the selected span is mapped to all candidate sentences covering it. For each evaluable annotation, all mapped candidate sentences are listed as positive examples, and AP is computed. equal weighting is applied across annotations within the same task, tasks within the same document, and documents across all annotators. In case of ties, the original order is used to break them.

For each unordered problem pair where the same-article matching includes cases with valid annotations, all valid intervals map completely, and the evidence candidate sets of the two items are completely disjoint. Under each question formulation, compare the average score of its own evidence against the average score of the other item's evidence: award 1 point for a win, 0.5 points for a tie, and apply equal weighting across both directions. First average within-article, then average across articles using equal weighting. Perform 10,000 paired resamples with seed 735972, and compute the 95th percentile interval.

Determine whether the readout is successfully transferred across the held-out domain, which requires that all three difference values have a 95% confidence interval lower bound greater than 0.

- BM25 that fuses AP higher than contractual IDF.
- BM25 with AP fusion exceeding unit IDF.
- BM25 with integrated document pairing exceeding unit IDF.

Report the original Qwen score, subtract shared score, report Qwen-only fit, and report vocabulary-added Qwen original score. Jointly verify authorization and length exclusion, count of evaluable annotations and matches, candidate coverage, and causal prefix checks. This experiment's pass range is limited to evidence ranking for pre-specified questions.
