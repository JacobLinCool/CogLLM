# Sentence-by-sentence contradiction report and first-position verification for Frick and Schüler

Verify whether a single frozen Qwen3.5-2B model can reproduce the human report discrepancies caused by consistent and inconsistent prior context when reading sentence-by-sentence to the same target sentence. Additionally, examine the position where readers first press the contradiction key across the full text, and retain the probability of not reporting by the end. Both endpoints derive from existing explicit judgment experiments. [Original Experiment 1, Materials, Procedure, Tables 1–3](https://doi.org/10.3758/s13421-026-01900-7) · [Data and Observation Audit](frick-consistency-source.md)

## Materials, reading stops, and held-out

Using only the plain-text condition from Experiment 1 `01` (consistent) and `02` (inconsistent), comprising 20 dual-version story pairs. Each pair features a change in only the earlier sentence, with the two versions being identical word-for-word in the target sentence. Both versions are processed together using 20-fold leave-one-out cross-validation, with 19 groups fitted per fold. A total of 180 readers appear across folds. readers, conditions, and researcher-specified altered sentences and target sentences are excluded from model input or fitting features. Readers' responses indicating the first sentence as consistent are used only as visible text, excluding their keystrokes. The primary endpoint retains all original keystrokes and 1,800 traces, while the target sentences filtered by the author's reaction time rule are reserved for observational verification. [Worksheet and trace denominator](frick-consistency-source.md)

The original text is presented in chronological order, with the character `reading stop` appearing immediately after the last character of each sentence. The model performs a single causal forward pass per full text, retaining the 2,048-dimensional FP32 state at the end of each sentence. Only the current sentence's contrast uses each unique sentence independently encoded once. Both `held-out` and `fitting` utilize the same frozen candidate. The `reading stop` must be verified via independent prefix tokenization. For each group, the original text prefix before the modified sentence is identical, and the body state of these `reading stop`s must have an L2 error relative to the prefix smaller than 0.002. Annotations are separated from the original output. the model's extracted packet does not include keys, subjects, conditions, or target data.

## Two readouts

The first readout estimates the probability that each sentence will be read by `D`, using all keys from the second sentence onward. The second readout estimates the probability that a reader who has not yet pressed `D` will report this sentence for the first time $h_t$, fitting only with `D` reading stops that have occurred previously. The probability of the first event occurring at sentence $t$ is $h_t\prod_{j<t}(1-h_j)$, and the probability of no report by the end of the text is $\prod_j(1-h_j)$. Both models use the same readout architecture and the same held-out material, fitting the observed labels separately.

| Comparison | Visible features |
| --- | --- |
| Literal | Features are the current sentence's log1p character and whitespace-token counts, its log1p sentence index starting at one, the log1p cumulative whitespace-token count before the current sentence, and the proportion of its word types already seen in the preceding text. Compute the proportion after Unicode NFKC normalization and case folding, using word types with at least four Unicode letters or digits. Use 0 when there are no such types. |
| Literal and contextual Qwen | The same literal feature plus the independently encoded L2 unit state of the clause. |
| Literal and prefix Qwen | The same surface feature, plus the L2 unit status of the current sentence within the complete prefix. A single forward pass of the full story provides all states. |

Each fold employs a grouped Bernoulli negative log-likelihood with equal observation weights, where the coefficient penalty is fixed at $0.10\lVert\theta\rVert_2^2/2$ and the intercept is unpenalized. Each scalar feature is standardized using the training mean and standard deviation. Each vector block is centered by the training mean and then scaled by the square root of its weighted L2 norm. Both versions utilize the same readout. For each fold, predictions are aggregated and compared only after a sealed snapshot, without selecting target positions or hyperparameters based on held-out performance.

## Endpoint and fixed acceptance

The observation difference is the inconsistent version minus the consistent version. For each story pair, both versions are estimated separately, then averaged using equal weighting across stories. In each resampling iteration, 20 story pairs and 180 readers are resampled with replacement using a fixed seed of 735972 for 10,000 bootstrap samples. Across resampling iterations, all methods share the same weights for stories and readers, with fitted coefficients held fixed. Additionally, confidence intervals are reported for fixed stories with only readers resampled. Effects are presented as probability differences, allowing for a fixed margin of error of ±10 percentage points.

| Endpoint | State distribution and localization | Pre-fixed validation |
| --- | --- | --- |
| When the sentence report | The Bernoulli NLL at the end of every sentence, measured in nats per sentence. and the rate difference at the same target sentence under `D`. | The prefix Qwen's NLL difference interval upper bound relative to the in-sentence Qwen is below zero. the target sentence's model effect interval lower bound is above zero. and the model versus human effect difference 95% interval is fully contained within ±10 percentage points. |
| First report | The first-order n-gram unigram NLL, measured in nats per document. and the log-likelihood ratio of the first occurrence of the report event exactly at the target sentence. | The prefix Qwen's NLL difference interval upper bound relative to the in-sentence Qwen is below zero. the target sentence's model effect interval lower bound is above zero. and the model versus human effect difference 95% interval is fully contained within ±10 percentage points. |

The NLL is a minimum of 0, where lower values indicate that the model assigns higher probability to the human response in that turn. Two additional versions are listed: the probability of the first event occurring before the target, at the target sentence, after the target sentence, and in the absence of a report. When the sentence report and the first report use different denominators. Both validations are restricted to explicit contradiction judgments under turn-by-turn prompting, requiring separate human data for the intra-sentence trigger time and the subsequent resolution of the same question.
