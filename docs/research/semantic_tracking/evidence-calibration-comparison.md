# Evidence-to-readout symmetric calibration control

The first analysis of ExpMRC found that per-token readout ranks evidence ordering for same-text questions better than the prompt baseline, but yields lower absolute probabilities. Subsequent backtracking analysis recalibrated per-token readout while preserving its paired rank order. In this study, we use the same materials and five-fold split, applying the identical calibration elasticity to each baseline group to examine whether per-token representations still offer additional value. [Original analysis](expmrc-transfer-results.md) · [Original backtracking calibration](expmrc-calibration-results.md)

Position, stem, paragraph, and per-token interactions comprise four groups, each initialized with frozen QASPER predictions from the same group. For each group, we minimize the interval NLL with equal weighting across two reference endpoints across four folds, using identical two-parameter monotonic logit transformation and optimizer, then evaluate on the held-out fold. We analyze the original corpus of 165 documents and 555 items, stratified by document. Parameters estimated across all 165 documents for the four groups are fixed and archived for independent validation on other corpora. The in-sample performance of all fitted parameters does not constitute evidence of generalization.

The primary comparison is the calibrated per-token minus calibrated stem interval NLL, requiring the 95% article group paired interval upper bound to be below zero. The secondary comparison is the calibrated per-token minus calibrated paragraph interval NLL and four cumulative Brier scores. Additionally, we verify whether the 698 cumulative intensity rankings for identical text and reading stop change under the transformation. We retain the original ExpMRC 10,000 article group resamples and seed. This retrospective evaluation assesses when the reference evidence for a specified question becomes complete. Improvements in the time users self-detect their query and their understanding remain unobserved via human data.
