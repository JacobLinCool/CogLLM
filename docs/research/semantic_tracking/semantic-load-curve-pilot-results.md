# per-token curve first-round results

2026-11-21. Qwen3.5-2B can generate per-token curves using a single forward pass with causal prefix and subsequent readout. The common prefix across three model groups remains consistent. Among 12 continuation sets, the joint three-task analysis only replicated the difference where "sudden topic shift" exceeded "foreshadowing resolution" at the end of the text. declines at earlier foreshadowing resolution and answer clues, and retention at the topic shift point, all failed to reach significance. After direct pairing with their respective training sets, the confidence intervals for all four curve difference values included zero. Additionally, three human held-out endpoints did not confirm gains from joint training. ## Execution and Scope of Application

The Qwen3.5-2B official weights were run on FP32 in a Colab L4 instance, processing 584 public texts and self-generated baselines, totaling 79,575 native tokens. Each text underwent a single formal backbone forward pass across 113 batches. independent truncation and post-processing validation were conducted via 12 additional comparisons. The L4 instance consumed approximately 187 seconds, confirmed as released. The backbone forward pass and representation extraction took 34.0 seconds, with peak retained memory usage of approximately 7.35 GiB. Readout operations utilized the same batch of representations, with original and replayed score outputs remaining consistent across files. Using a single confirmed L4 account rate multiplied by the configuration time, the estimated cost is approximately 0.101 CU. The account balance shown in this segment remains at 734.00 CU. [ sealed snapshot representations and scoring manifest ](../../../research/results/load-curve-l4/receipt.json) · [release and usage verification](../../../research/results/load-curve-l4/run-verification.json)

The curve utilizes human-selected openings and manually derived continuations. The opening reference head is trained at the end of tokens, with inference applied to all native tokens, and candidate quality computed using opening suppression from the first five tokens. Per-token high/low and position in this round are model-estimated. The public human corpus still lacks word-level openings and unmasking trajectories for the same reader and same question. The continuation contrast demonstrates technical causal consistency, while also revealing that current readouts lack reliable discrimination between answer timing and interruption.
