# Can Qwen's per-token expected value and prefix attention improve first-pass contradiction report prediction?

Frick and Schüler's text-only experiment presents one complete sentence at a time, and readers judge whether it contradicts the preceding text. The two versions of a story share the target sentence and differ only in one earlier sentence. The existing seven-feature readout underestimates the difference in first reports at the target sentence. This comparison tests whether per-token predictive distributions and attention statistics derived from the same Qwen forward pass improve the **sentence-end** first-report rate and the distribution of first reports over the passage. [Original Experiment 1](https://doi.org/10.3758/s13421-026-01900-7) · [Original pairing and endpoint](frick-consistency-source.md) · [Seven-feature holdout results](frick-conditional-results.md)

## Model input and signal

Use the 40 complete English stories, the identical Qwen3.5-2B checkpoint, tokenizer, and FP32 SDPA inference. The researcher-specified target sentence, modification position, prefix conditions, and human data are excluded from the readout. Perform a causal forward pass on each corpus, and additionally validate using a shortened prefix, suffix replacement, and prefix consistency check. Align each token to the original half-open Unicode coordinate. Define each original sentence boundary using the tokenizer certificate from the previous sealed snapshot, and re-verify this on the GPU.

For the original token at position $t$, multiply the final layer state from position $t-1$ by the model's shared input and output vocabulary weights. Retain the surprisal of the current token and the Shannon entropy of the entire predicted distribution, both measured in nats. The first token has no historical prediction. store a zero value and exclude it from the aggregation of predicted quantities. Compute the vocabulary projection in chunks, and the model does not generate text.

In the final full-attention layer, reconstruct the causal softmax for eight heads using identical forward queries and keys, then average across heads. For each query position, first sum the attention quality of all preceding tokens within the current sentence, then subtract the uniform quality of visible prior tokens. A second feature is computed per read sentence as the actual quality minus the sentence's uniform quality, taking the maximum signed difference. The denominator for each uniform term is the count of visible tokens at that position, including the current token. Both terms are zero when no prior sentence exists. Retain the end-of-sentence states to verify original extraction. [Attention and Output Definitions](../mathematical-formulation.md#2-一次因果前向運算)

## Readout and validation

Adding five features to each sentence consists of the mean and maximum of sentence surprisal, the mean of predicted entropy, and the mean of each of the two attention differences. The main group adds all five to the original seven features. Each subgroup adds either three lexical signals or two attention signals for ablation. Each group retains the original pairing feature direction, training material, loss, and weight selection rules. We use 20 outer story folds and fixed four inner material folds. Each fold normalizes features and selects weights using its own training data. Both versions are held out together. During held-out prediction, each article is evaluated only on its own body prefix.

For the primary group relative to the original seven features, the target sentence's first report absolute error must decrease. the improvement in reader-story cross-validation must have a 95% confidence interval lower bound greater than zero. The relative increase in the full-text first report NLL must have an interval upper bound smaller than 0.05 nats/sentence. Additionally, the two conditions of target effect magnitude and early report are applied with ±10 percentage point thresholds. The 10,000 cross-validation iterations use seed 735972. When comparing the three new feature groups, the decomposition results are reported separately. [Pairwise fit and original threshold](frick-conditional-protocol.md)

This is a retrospective comparison across existing story families. The model generates signals at each token, yet the report for this human data remains only at the sentence end. If a sentence exhibits higher surprisal, the research observation can verify the probability difference of the same-sentence report, but it cannot yet identify which word the reader first noticed as contradictory.
