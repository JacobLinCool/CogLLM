# Independent transfer validation of practice order

Beukers et al. placed the first 80 items in either the early, middle, or late phase of learning, with the remaining items interleaved. The final 40 items in each group were randomly selected from two story types according to the same rule. Both the original experiment and an independent replication observed superior performance in the early-insertion group compared to the other two groups. This validation fixed the previously fitted CogLLM to test whether providing only "block practice at the beginning" could replicate this difference. This background coding represents the transfer hypothesis to be validated. ## Fixed scoring and threshold

Each condition independently selects two shared layouts. Layouts are assigned equal within-group weighting, with repeated trials of the same layout splitting the layout's weight equally. The two groups' human accuracy rates, the model's probability of assigning correct events, and the three groups' readout human NLLs are compared using the same weighting. NLL is averaged across the two groups with equal weighting, measured in nats. Correctness is consistent across layouts within the same condition. the model's effect between background and body text should be zero. Within each study, 10,000 independent exponential multipliers are sampled for each reader and each layout. Human accuracy and NLL use the product of these multipliers with the original trial weights, with re-normalization per group at each iteration. The model's expected accuracy is re-weighted only by the shared layout multipliers, maintaining the same layout distribution across the two groups. Readers from the early group appearing in both conditions and the same shared layout share the same multiplier from a single sampling instance. [Cross-group multiplier method](https://arxiv.org/abs/1106.2125)

All four contrasts must include at least ten control subjects and ten early readers. The effect direction for human and initial block readout must both be positive, with the 95% confidence interval lower bound exceeding zero. The model-reduced human effect 90% confidence interval must fall entirely within ±10 percentage points, corresponding to a maximum difference of one correct response rate per ten specified choices. The original paper used full-trial intervals only for directional and magnitude reference. The initial block relative null-background paired NLL difference must have a 95% confidence interval upper bound below zero. All other comparisons are reported separately. All conditions passing support this transfer. The experiment's endpoint remains the specified next-event choice, distinct from the spontaneous question intensity and resolution point during reading.
