# Frick causal peak calibration specification

On the 20 sets of English Frick stories that have been analyzed multiple times, we compare whether calibrating to only the current and earlier readout endings reduces the magnitude of the first contradiction report error. We retain the original 1,800 trajectories, 40 story variants, and 584 evaluated reading stops. The original readout's contradiction report probability under the inconsistent version is 30.73%, while the human baseline is 59.14%. In 17 out of the 20 story sets, the original readout's inconsistent version target logit exceeded all prior reading stops. These two observations are retrospective motivations. For each risky reading stop $t$ in every document, let $z_t$ be the original attention readout logit and $d_t=\max(0,z_t-\max_{2\leq j<t}z_j)$. Set $d_t$ in the second sentence to zero. The two new readouts are $a+bz_t$ (affine) and $a+bz_t+cd_t$ (peak). $b,c\geq 0$. Parameters for single-document prediction are fixed. the prefix contains only scores from the current document and earlier ones. $\sigma(a+bz_t+cd_t)$ can be computed upon reaching the current sentence. The earlier report rate is the product of the no-report probabilities across each reading stop. The target label, another story version, and the human button participate only in training or evaluation.

Both calibrations use the same finite convex objective. The complete first-event negative log likelihood weights story versions equally and uses all reading trajectories from each version as its denominator. The objective adds binary cross-entropy at the target sentence with weight 1. For each version, the denominator at the target sentence is the number of readers who have yet to report. Use the observed positive and negative proportions within each version and weight stories and conditions equally. This term supervises the **absolute** hazard in both conditions. Both calibrations add $0.01\lVert(a,b,c)-(0,1,0)\rVert_2^2/2$. The affine calibration fixes $c=0$. No further calibration weights are selected.

Each outer fold retains one story family. The remaining 19 groups are cyclically split into four calibration folds according to the original family ordering. For each story in calibration fold $V$, the basic readout is fitted by removing the entire group $V$ from the outer remaining 19 groups. The original `lambda/gamma` adjustment is also performed separately within this smaller training within-group, split into four folds. Calibration is conducted by jointly fitting the basic logits from these four sets, which are unseen to their own family and the outer family. The outer prediction reuses coefficients from the original sealed snapshot basic readout. Recalculate the training-specific direction and outer logits to verify that the basic readout aligns with the original sealed snapshot value. The outer prediction first applies the sealed snapshot, then combines it with human counts.

The primary endpoint is the inconsistency minus consistency difference for the first report falling on the same target sentence. The absolute error improvement relative to the original attention and affine groups must each have a 95% bootstrap lower bound greater than zero. The NLL difference for the entire first report relative to the original attention and seven-feature readout must each have a 95% confidence interval upper bound less than +0.05 nats/document. Both early-report biases in the foreword must each be fully located within ±10 percentage points. Retain the effect direction, the model-minus-human magnitude difference within ±10 percentage points, and the original prefix/global readout comparison. Report the absolute target probability per sentence in the risk set. Continue using the same 10,000 story-reader bootstrap resamples with seed 735972, with each method sharing sampling weights. This is a retrospective comparison of the same batch of research materials. the human key remains at the sentence end, with no intra-sentence time or same-question resolution observations.
