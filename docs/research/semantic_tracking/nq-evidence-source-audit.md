# Independent evidence interval validation for Natural Questions

The Natural Questions development set retains five independent human references per question. Each reference selects an HTML segment containing sufficient evidence or one lacking sufficient evidence. Segments are recorded simultaneously by source token and UTF-8 byte position. A Wikipedia version containing different questions can be used to check whether the model distinguishes different evidence within the same prefix. The data is licensed under CC BY-SA 3.0 as officially published. [Author Release and Licensing](https://ai.google.com/research/NaturalQuestions/download) · [Original Measurement and Annotation](https://aclanthology.org/Q19-1026/) · [Hugging Face Repository](https://huggingface.co/datasets/google-research-datasets/natural_questions)

Fixed Hugging Face version `e8103d566bef4154c2c12b17c6095ec5275840cc` with seven validation shards. After querying required fields per shard, we obtained 7,830 questions and 7,369 Wikipedia source versions. Among these, 365 versions contained at least two distinct normalized questions, yielding 627 duplicate question pairs. A data feasibility check revealed that 352 pairs had at least two non-empty long answers each, with 112 pairs having all non-empty long answer intervals strictly separated by original token coordinates. When selecting inference material, an independent unlabeled index was used. the latter two statistics only indicate whether paired ranks can be verified.

To avoid overlap with the IIRC page already used for CogLLM, normalize and compare Wikipedia titles against the original titles and visible link titles from IIRC training and development data. Among 365 multi-question variants, 5 matched original titles and 90 matched link titles, with some overlap. After exclusion, 273 variants and 610 question records were retained. when retrieving full text, each record's actual text must be verified. In the first sampled multi-question variant, the complete HTML of two questions and 7,962 source tokens were identical value-for-value. Index reconstruction was bit-for-bit consistent. In four raw samples without manual selection segments, 31,225 source tokens and 507 candidate support segments were cross-verified. The model generated text following the author's non-HTML token order, with the coordinate program verifying byte boundaries segment-by-segment and reconstructing the Unicode character range of the original text from the same batch of tokens. Neither the raw HTML nor the human-generated answers were input into the model. Results after flattening tables and lists into text must be reported independently. This data measure assesses how many tokens are required to answer a known question. For the same question, five equal-weighted reference segments are used to compute error. When human does not select a complete support segment, scoring is based on the remaining probability after the observation window. The same document, question, and document retrieval are confirmed via version identifier and actual visible tokens. After a sealed snapshot prediction, scoring is performed against reference segments. The fixed ExpMRC four sets of parameters can be directly transferred to evaluate whether their probability calibration generalizes across corpora. Human spontaneous questioning and awareness of the answer from the document require another form of observation.
