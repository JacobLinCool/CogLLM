# Sensitivity of the word-guessing result to the path sampling of the clue path

Wang et al.'s trial-by-trial guessing data are identifiable for the first exposure step at which a correct response was made, but lack the sentence ID of the clue item seen by each individual reader. The original Qwen experiment estimated the group-level correct response distribution using eight possible paths per target word. This study fixed the same checkpoint, readout, held-out target, and human data, then examined whether Qwen's held-out gain maintained the same direction after switching to a single set of pre-sealed, non-overlapping complete paths. [Source](core-vocabulary-source.md) · [Original Qwen experiment](core-vocabulary-qwen-results.md)

## Materials and visible information

Maintain four original study conditions, each with eight held-out targets, totaling 32. For each target, based on a sealed snapshot seed, perform uniform sampling without replacement to select 32 paths from the 46,648 paths excluding the original eight complete paths. Each path consists of six sentences. All 1,024 new paths and 6,144 reading stops undergo tokenization verification prior to extraction. Different complete paths may share earlier cue sentences. The public trial can be used to compare group responses for the same set of targets, yet it remains unknown which sentence was truly presented to which reader. [Stimulus Generation](../../../research/semantic_tracking/core_vocabulary_disjoint_panel.py)

Perform a causal forward pass along a single path, reading six end-of-sentence tokens from the same Gradio candidate's 128-dimensional projection readout. The remote side receives only masked corpus with the reading stop token present in the original text. Keep the target, condition, group table, and human response on the local machine. For steps, surface form, and surface form plus Qwen, use the original coefficients and training feature normalization. First, convert each path's hazard into a seven-class first-correct distribution, then take an equal-weighted average over each target's path, and combine with the human held-out trial only after sealing the predicted snapshot. [Original readout specification](core-vocabulary-qwen-protocol.md)

## Comparison and evaluation

We primarily compare the condition using only 32 new paths while retaining the original 32 targets, based on 1,603 human trials. For each trial, NLL is reported under equal weighting across targets. lower values indicate that the human's actual outcome received a higher predicted probability. For Qwen, improvements in both step count and surface form must be positive simultaneously, with both paired 95% confidence intervals entirely above zero, to replicate the original directional significance. The cumulative accuracy deviation thresholds for sentences 1, 3, and 6 are each maintained at ±5 percentage points. Using 10,000 resamples and seed 735972, we resample targets across four material conditions and additionally report the resampled confidence intervals for readers and targets in a cross-validation setting.

The same set of target paths was resampled to report the NLL difference relative to the original eight paths, as well as the change in surface form gain. Additionally, 40 merged paths were recalculated with equal weighting as a sensitivity result. The 40 equal-weighted paths represent the set of extracted paths. If calculated using all paths from the original sampling design, the excluded eight paths account for only 8/46,656, which could alter the cumulative correct probability by at most 0.0172 percentage points. This bound does not encompass the error arising from sampling only 32 paths from the remaining paths. Both path sets share the human trial. this comparison estimates the sensitivity of path sampling.
