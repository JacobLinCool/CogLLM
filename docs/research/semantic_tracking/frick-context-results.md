# cross-sentence word form and representation features did not improve, contradicting the first report

In Frick's 20 held-out story sets, adding seven cross-sentence features reduced the model's first report condition difference at the target sentence from **18.95 to 15.94 percentage points**, with human at **48.27**. Relative to the original seven feature readout, the absolute error in target sentence magnitude increased by 3.01 percentage points, with a cross 95% interval [1.38, 5.08]. [fixed-spec](frick-context-protocol.md) · [sealed-snapshot results](../../../research/results/frick-context-ablation/results.json)

The two groups retained the same Qwen3.5-2B causal suffix state, seven original features, and nested family held-out. Additional metrics included word overlap up to the present, old sentence distance, and the current suffix's vector relationship relative to the previous suffix. Both groups selected models using the same objective function and weight range. The fourteen feature readout target sentence difference interval was [+10.26, +22.58] percentage points. early report bias failed to pass the equivalence threshold in both conditions. The overall NLL increased from 1.5939 to 1.6050, with a difference of +0.0111 having an interval of [−0.0387, +0.0690]. The upper bound exceeded the non-inferiority threshold of +0.05 nats/paper. [Comparison and two group prefix distributions](../../../research/results/frick-context-ablation/results.json) · [Two within-group layer selections](../../../research/results/frick-context-ablation/fits.json)

Seven features readout fully reproduce the previous round. Sequentially truncating un-read suffixes for added features, all 544 comparable reading stops retain identical feature values, including word-form statistics, with the maximum logit difference approximately \(1.78\times10^{-15}\). After removing target and response information for held-out materials, 584 predictions are completely identical. Two CPU reruns took approximately 3.2 seconds, with peak RSS around 110 MiB, without reloading Qwen. This verification confirms the first contradictory report of the same experiment sentence-by-sentence, without measuring when the subsequent resolution of the original question occurs.
