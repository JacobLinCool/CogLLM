# GUMBridge cross-sentence context localization

This experiment evaluates whether the causal representations of Qwen3.5-2B can locate manually annotated antecedent positions within the read text when encountering a new reference requiring understanding from earlier text. For instance, "door" may refer to the door of a house mentioned earlier. GUMBridge's manual endpoints bridge the reference to its antecedent entity. The original data readers did not report difficulty during stepwise revelation, nor is there a record of resolution for the same query. [GUMBridge definition and annotation §3](https://aclanthology.org/2026.lrec-1.543.pdf#page=4) · [Antecedent position and salience corpus analysis §4](https://aclanthology.org/2026.codi-1.7.pdf) · [Unconstrained candidate antecedent positioning](https://aclanthology.org/J18-2002/)

## Materials and evaluable positions

Annotated with GUMBridge using GUM v12, fixed to UD English GUM r2.19. Formal evaluation retains the complete `test`, `dev` for diagnostics. Grouping by release source URL, ignoring fragment. If cross-splitting occurs with the same source URL, retain the official test discourse, then the development discourse, excluding from training and any article with the same source URL in either original held-out set. Both held-out sets are used for scoring only after the training weights are sealed in a snapshot. The primary subset requires that the new reference and preceding phrase fragments each fall entirely within identifiable body paragraphs, with all acceptable preceding positions located in earlier paragraphs. The full segmentation preserves the reading order of the same material. Counts of annotations that cannot be aligned, intersect the current segment, or fail to confirm natural paragraph boundaries are excluded. The corpus includes written text and verbatim transcripts. [Original research splitting and manual annotation method §3.1](https://aclanthology.org/2026.lrec-1.543.pdf#page=4) · [Fixed version format and license](https://github.com/UniversalDependencies/UD_English-GUM/tree/e92f501b037ebd38387d7479b99aa2a0c45b779e)

The model input consists only of the main text and the universal readout coordinates for each original token. For each main text, GPU performs a single FP32 causal forward pass, extracts the 128-dimensional projection from the frozen Gradio candidate backbone and the IIRC head, and outputs unit vectors coordinate-wise. The reading stop must be identical to the independently encoded visible prefix. Human coordinates and relationships are connected only during CPU fitting and scoring. Analysis treats the end of manually created new reference segments as the control reading stop indicating where the preceding context originates. A candidate is a token end that is already read and fully located before the start of the new reference and aligns with it. Scoring retains valid candidates within the current segment. therefore, cross-segment main results must hold under full prefix competition. Multiple human reference targets are allowed, and the score is the total probability assigned by the model to any correct endpoint.

## Pre-fixed comparison

| Readout | Available information |
| --- | --- |
| Distance | The readout rank, ordered monotonically decreasing by distance. |
| Literal | Distance, segment span, word length, initial capitalization, visible prefix word frequency, and literal overlap with new reference phrases. |
| Literal and Qwen | The same literal feature, as well as the causal vector cosine between the new reference suffix and the candidate word suffix. |

Both fitting readouts employ identical conditional softmax, optimized by article equal-weighted negative log-likelihood plus a fixed 0.05 L2 penalty. All cases fully alignable at both token and reading stop levels are retained. Each method uses the same set of candidates within a single case. The primary endpoint is the average equal-weighted negative log-likelihood per article, measured in nats, where lower values indicate higher probability of assigning the human-labeled endpoint. Acceptance requires an official `test` of at least 20 articles for evaluation, with the literal and Qwen minus literal-only 95% article-paired bootstrap upper bound less than zero. Whether the first hit matches the human position and average reciprocal rank serve as auxiliary metrics. All paired intervals are fixed with the article as the resampling unit. Precision reading stop coverage, candidate count per group, and multi-label denominator are checked across each split.

The starting point of this experiment is determined by the scoring program. Even if the main comparison passes, it only validates whether the reader can resolve a reference to the manually selected preceding text after encountering this annotated phrase. For example, a reader might smoothly connect "door" and "house," experiencing no difficulty throughout the passage. This data does not contain scores for subjective stuck time or question resolution strength that can be inferred.
