# ExpMRC achieves the calibration of the reachability rate

This experiment tests whether a single monotonic transformation reduces the absolute probability error of the sealed token-level readout on ExpMRC while preserving the ranking of questions for the same passage and reading stop. It uses the previously scored primary ExpMRC analysis set, retaining 165 passages, 555 questions, and 1,110 human annotations and carrying forward the exclusion of the two RACE-related materials. The fixed comparisons are the original token-level readout (`token_rank`) and the original question-only readout (`question_only`). [Original scoring protocol](expmrc-transfer.md) · [Sealed predictions](../../../research/results/expmrc-transfer-l4/seal.json)

The cumulative intensity of the model at the reading stop $t$ is denoted as $A_t=-\log S_t$, where $S_t$ represents the predictive probability that complete evidence has not yet emerged. Only the global two-parameter transformation $A'_t=\exp(a)A_t^b$, $b>0$, and $A'_0=0$ are fitted. The discrete transition probability is recovered from the difference in adjacent reading stop intensities, based on the model output already accumulated at that reading stop. For any two items within the same article, the same set of transformation parameters is used, and the same reading stop rank should be preserved.

First, sort the string `expmrc-calibration-v1:` concatenated with the article ID by SHA-256 hash, then cyclically assign to five folds. For each fold, the two parameters are estimated only from the remaining four folds. Fit by minimizing the average interval NLL of the two reference endpoints with equal weighting, using L-BFGS-B starting from $(a,\log b)=(0,0)$, with $a$ constrained to $[-12,12]$, $b$ constrained to $[1/4,4]$, and `maxiter=300`, `ftol=1e-12`, `gtol=1e-8`. No additional adjustment is made based on article length, question type, or ending text.

The primary endpoint is interval NLL per question. We compute two paired differences by subtracting the original token-level and original question-only readouts from the calibrated token-level readout. The secondary comparisons use the same question-level cumulative Brier score. We also compare the mean predicted probability at the first stop with the proportion of reference annotations indicating an event there. NLL is measured in nats, and Brier scores range from 0 to 1. For both measures, 0 is best. We resample passages 10,000 times and report the same two-sided 95% descriptive intervals as the ExpMRC scoring protocol, treating the fitted out-of-fold predictions as fixed. We also check question rankings and wins, losses, and ties at the same stop in the 698 prespecified pairs.

The analysis specification was established prior to this computation, with existing ExpMRC human annotations already utilized for the previous transfer scoring. The current provision of article-grouped retrospective out-of-fold estimates indicates that further probabilistic validation requires new articles and human observations.
