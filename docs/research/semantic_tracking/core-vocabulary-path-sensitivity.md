# Core Vocabulary archived-path sensitivity

The fixed Qwen readout retains a positive held-out log-score advantage over both controls when any one of the eight archived paths is dropped independently for each of the 32 held-out targets. Under the most adverse such deletions, the gain is 0.00257 nats over position and 0.00253 nats over the surface readout. Both corresponding 95% paired target-bootstrap lower bounds stay above zero. Dropping two paths retains positive worst-case point estimates, with both lower bounds below zero. This is a post hoc stress test of the released forecasts on the same historical outcomes. No model parameters were fitted again. [Original holdout result](core-vocabulary-qwen-results.md) · [Stress-test receipt](../../../research/results/core-vocabulary-path-sensitivity.json)

## Deleting sampled paths

We take the six sealed hazard logits for each path from the original forecast artifact and convert them into the seven first-correct or censoring probabilities. For each held-out target and retained path count $k$, we enumerate every $k$-of-8 subset. We average path-level probabilities over the subset, then compute its negative log score against that target's historical outcome distribution. Position uses its original training-only probability vector. The surface and Qwen forecasts use the same retained paths. The reported gain is the control's NLL minus Qwen's NLL, in nats with equal target weights. [Frozen forecasts](../../../research/results/core-vocabulary-qwen-l4/forecasts.jsonl) · [Original readout fit](../../../research/results/core-vocabulary-qwen-l4/fit.json) · [Marginal scoring rule](core-vocabulary-marginal-protocol.md#distribution-and-score)

The choice of subset can differ for each target. For a given comparison, summing per-target minima and dividing by 32 gives the exact minimum point gain across all joint choices. The maximum follows the same procedure with per-target maxima. For the bootstrap, we preserve the archived material order, stratify 10,000 paired target draws by the four author conditions and use the original seed 735972. An individual bootstrap mean has nonnegative weights on all target gains. Choosing a minimum for every target therefore minimizes every bootstrap replicate at once, which gives the lowest attainable 2.5th percentile across the archived subsets under those fixed resamples. The subset that minimizes the position comparison can differ from the subset that minimizes the surface comparison. These are adverse sensitivity summaries conditional on the observed readers and archived paths. The all-eight calculation reproduces the original paired interval for each comparison. Archived states cover on average 4.59 of the six possible first cues and 7.34 of the 36 possible two-cue prefixes per held-out target. Only one of 32 targets has complete first-cue coverage, and none has complete coverage at later exposures. The path deletion check measures dependence on the cues already evaluated. Estimating performance over the author distribution of 46,656 full paths per target still requires causal states for additional independently selected paths. The existing readout supports a research claim about group-level first-correct distributions for prompted lexical guessing. Applying the same interpretation to an individual prose sentence would require corresponding reader observations at that sentence. ## Independent readers in Experiment 2

The same paper's Experiment 2 has 664 analyzed reader IDs, with no shared ID with the 195 analyzed in Experiment 1. Each reader saw one sentence and made one guess per target. The public trial file gives correctness and target, which supports a separate reader-cohort test of first-attempt accuracy at the target level under the Experiment 2 sentence distribution. It lacks the stimulus ID per reader trial and contains no repeated exposure for the same target. [Experiment 2, Participants and Procedure](https://doi.org/10.1525/collabra.160142) · [Public trial table](https://osf.io/download/pbcx6/?revision=1)

The stimulus-indexed BERT file tabulates incorrect response types with available BERT predictability. It contains no response equal to the target. The Original set records 24,327 such response occurrences, compared with 31,191 failures in the trial table. The MatchedPred set records 9,157 occurrences, compared with 12,154 failures. The file supplies useful distributions for the included alternatives, but subtracting their counts from the per-stimulus trial denominators would count unreported incorrect answers as successes. Exact per-sentence accuracy would require full counts or the original trial-to-stimulus join.
