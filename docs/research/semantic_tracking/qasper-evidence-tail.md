# QASPER has evidence of joint acceptance with unanswerable

In the independent evaluation of Natural Questions, calibration parameters estimated from evidence-based data overestimate the arrival probability when human references lack marked support spans. This experiment investigates whether jointly using evidence-based intervals and explicit "no-answer" annotations improves the fit for the fully held-out corpus. Using the official QASPER v0.3 text and human response data, we freeze the original QASPER readout and the Gradio candidate Qwen3.5-2B backbone. [Previous failure and denominator](nq-evidence-transfer-results.md) · [Original annotation method](https://aclanthology.org/2021.naacl-main.365/)

Excluded overlapping article IDs and normalized titles from all previously used articles in the prior QASPER experiment. Sorted by SHA-256 hash of article ID prefixed with `cogllm-qasper-censor-v1:`. Retained up to 45 articles and 75,000 article-question tokens from the official train set, and up to 40 articles and 65,000 tokens from the official test set. Preserved full published text, title, and abstract. Each article limited to 16,000 Unicode characters and 6,144 Qwen tokens, without truncation. For each split, selected the prefix of the first batch of qualifying articles. stopped when exceeding the budget. Both tokenizer pre-checks must pass. for each selected article, the model readout used a single causal forward pass with frozen parameters. The final inference file contains only the text and question.

Each response is scored based on the explicit "unable to answer" or fully supported segments in the original data. For positive examples, the final end point of all verbatim-supported segments is taken and mapped to the first encompassing certified reading stop. Missing evidence, charts, non-unique mappings, and other items that cannot be converted to the aforementioned endpoints are flagged separately, retaining independently verifiable references within the same question. Each question receives equal weighting, and each question's valid references also receive equal weighting. Explicit "unable to answer" is scored using the remaining probability at the end of the full article.

Let $A_t$ denote the cumulative intensity of the original frozen readout. Time calibration employs $C_t=\exp(a)A_t^b$ and $b>0$. Readouts incorporating residual probabilities utilize $S_t=\pi+(1-\pi)\exp(-C_t)$, where $\pi$ is a constant jointly estimated from training tasks. Compare the performance of the same base readout under no $\pi$ versus joint fitting $\pi$, with both groups employing identical human-annotated mixtures. Maximize the likelihood with respect to the mass of interval $S_{t-1}-S_t$ and its endpoint $S_T$. Also score the original readout alongside the original ExpMRC fixed calibration. [Original calibration and weights](evidence-calibration-comparison-results.md)

The primary validation is the per-token readout joint estimate $\pi$ minus the per-item average NLL difference calibrated only to time, with the 95% confidence interval upper bound from the article-level resampling being below zero. Reported are the cumulative Brier, event, and no-issue NLLs, the endpoint remaining hazard, and any reading stop order changes sharing the same text and reading stop. Parameter fitting and model comparison are conducted outside the used articles, still limited to textual evidence from specified items. The point at which readers spontaneously notice their doubts remains unobserved directly.

Additionally, the parameters of the newly trained QASPER sealed snapshot can be directly applied to existing Natural Questions predictions to recompute the NLL of held-out unlabeled and positive examples. Since Natural Questions results have already been used to motivate this method, this constitutes a retrospective transfer comparison.
