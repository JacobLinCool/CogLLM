# Gradio vocabulary coloring professional news held-out

Using the CWI 2018 official English News test split, evaluate whether the vocabulary scores observed by authors and editors in the full-text interface can rank words with different human selection proportions. Fix the existing Gradio checkpoint `74c26ff02569b2b3bc28ed291bf15fd2f85db5b4c93a3ad7bfc34f6a5d333ea0` and its CompLex suffix readout. Inference input contains only the original sentence from the data release. Data includes HIT groups, with no verifiable cross-sentence ordering. In-sentence Qwen vocabulary scores use a single causal forward pass, adopting the actual two decimal places from the interface. [Author data and endpoints](https://aclanthology.org/W18-0507/) · [Gradio usage guide](../gradio_app/README.md)

## Source and Alignment

Retain candidates that are exactly one complete interface word, with character coordinates identical to the listed data. When identical-source candidates exist, deduplicate only if the repeated content and vote count are identical. Exclude normalized sentences appearing in multiple HITs to reduce material reuse during resampling. Maintain the original text unchanged, applying NFKC, casefold, and interface word splitting solely for duplicate and source overlap checks. Exclude sentences matching materials already fitted to the CompLex model, CompLex held-out, or prior CWI experiments, while recording similarity criteria and auditable sources. All data cleaning is completed prior to model scoring. [Prior CWI experiment materials](../core-features-first-run.md)

The human difficulty for each candidate segment is calculated by summing the circled votes from two groups of 10 annotators and dividing by 20. A zero vote indicates the candidate listed in the data was not circled. Terms not appearing in the release file are excluded from the denominator. Existing candidates that cannot be aligned via the interface are retained in the scoring. interface-sorted items are uniformly appended at the end alongside all other unaligned terms, allowing pairwise comparison. Predictions are first sealed in a snapshot, then combined with vote counts.

## Scoring and thresholds

Within each sentence, compare only pairs of candidate terms with different human votes. Assign 1 if the ranking direction is the same, 0 if it is reversed, and 0.5 if the scores are tied. First, average all valid pairs within each sentence. then average across all evaluable sentences within the same HIT. finally, apply equal weighting across HITs that have at least one evaluable sentence. Perform 10,000 bootstrap resamples of HIT pairings for each readout using the same resampling index, with a fixed random seed of 735972, and report the 95th percentile interval.

Compare three no-fit control conditions on the same word pool, where longer length indicates greater difficulty. Lower word frequency in the frozen CompLex fit word list indicates greater difficulty, with unseen words assigned a frequency of 0. For the merged character control, compute the average rank for both length and inverse word frequency across all valid words in the same sentence, then sum these ranks. words with tied ranks share the average rank. Require the interface score to cover at least 95% of candidate words, with the lower bound of the difference interval relative to each of the three controls greater than 0. Additionally report HIT, sentence, candidate, and matching denominators, the count of interface ties, and descriptive statistics for the two background groups. This experiment validates the relative difficulty ordering of given candidates but lacks a common metric for absolute cognitive effort or understanding difficulty intensity.
