# Initial evaluation of the token-level reading readout

The model receives a document's body text and optional background and runs one causal forward pass through Qwen3.5-2B. At each token, the readout uses the available representations and attention to positions already read. It outputs local candidate questions, their references to earlier text, and their estimated unresolved mass. The experiment compares a frozen backbone with Q/K LoRA in layer 24 on the same texts. The primary observations are first inconsistency reports from paired human reading trials and textual evidence for specified questions. Each observation uses its own scoring unit. The interface test uses a single sealed checkpoint to produce the curve over the original text, model-proposed spans, and onset and resolution intervals that map back to character positions. [Token-level formulation](../mathematical-formulation.md#每個-query-對已讀位置的關係) · [Prior readout diagnostics](../union_training/localization-results.md)

## Data and source isolation

- **Frick first explicit inconsistency reports.** We use two plain-text versions of each of the original experiment's 20 story families, covering 1,800 human trials. Training uses 16 families and 1,416 trials. Evaluation uses families 8, 10, 11, and 14 and their 384 trials, as in the previous model selection stage. Each pair changes an earlier sentence and holds the target sentence identical. Under the original instructions, participants press K at the first sentence. From the second sentence onward, we record the first D and right-censor trials with no report by the end. The experiment presents whole sentences and collects responses at that level. Reusing the four families evaluates the new readout on the same earlier development materials. [Original procedure, exposure, and alignment](../semantic_tracking/frick-consistency-source.md) · [Prior retrospective thresholds](../semantic_tracking/frick-conditional-protocol.md#scoring)
- **ExpMRC textual evidence for known questions.** We reuse 27 test articles. Comparing them with 66 previous training-source articles identified two copied texts. Each shared 202 or 364 distinct contiguous twelve-word windows with a test article. After removing both, 64 training articles remain. Each article presents two questions with distinct, nonoverlapping human-annotated evidence windows. The model sees the questions. The answers and evidence locations stay in a separate scoring file. Annotators read the entire article and identified passages that supported the answers. The available results concern this auxiliary task with specified questions. The annotation identifies textual support and does not timestamp the reader's first moment of confidence. [Prior dataset, license, and results](../semantic_tracking/same-question-results.md#human-annotated-evidence-and-observed-reading-responses)
- **Newly sealed continuation triplets.** We authored 12 expository passage families, each with an early cue, a late cue, and no cue for a shared previously read anchor, yielding 36 texts. The three versions have identical text and tokens before an answer can appear. The late and no-cue versions share the intervening passage. The early and late versions use the same answer sentence, and all three have the same total token count. We retain the coordinates of the complete answer sentence and the end of its final answer word. The agent authored the stimuli and set scoring before the first forward pass. These stimuli have no accompanying human responses. [Dataset construction and seal](../../../research/token_readout/data.py)

Dataset construction pins the tokenizer by SHA-256. Each `stimuli.jsonl` row contains only `id` and `text`. The local `design.json` contains source hashes, cutoffs, splits, response counts, and authored control windows. Text locations are half-open Unicode intervals in the original text. Independent prefix encoding verifies every endpoint that defines visible text. The `receipt.json` seals both outputs and the twelve-word overlap audit. ExpMRC uses the source's CC BY-SA 4.0 license. Frick uses existing public supplemental materials, with the original source and historical audits recorded in the research files. ## Model and scoring specification

**First report.** The readout aggregates all causal tokens within a sentence to produce a sentence-end first-report logit. It models the sequence of presented sentences using an event distribution with censoring at the end of the document. The position-only baseline pools training trials at each presentation position. With $d_s$ first reports and $r_s$ readers still at risk on sentence $s$, its hazard is $(d_s+0.5)/(r_s+1)$. The distribution over new trials follows from multiplying by the preceding survival probabilities. The baseline starts at the second presented sentence and uses only training counts and sentence position. The model and baseline use the same held-out stories and all their trials to compute full-path negative log likelihood (NLL). We report the error in pre-target reports, the difference in target-sentence first-report rates, and the target-sentence difference among readers still at risk, separately by condition. The development criterion keeps the existing target-contrast and premature-report tolerance of ±10 percentage points. We report individual results for the four families and their differences from the position baseline. These development families measure progress in this implementation. Generalization requires independent story families. [Original Frick scoring specification](../semantic_tracking/frick-conditional-protocol.md#scoring)

**Textual evidence.** The interval likelihood for each question combines survival to the start of the annotated support window with the event mass inside the window. For the same article and time window, we pair the earlier-supported question with a different question whose evidence has yet to appear. Where available, we also compare the same question across a preceding window with equal token length. We leave unavailable matched windows missing. We weight articles equally when reporting the direction of the paired contrast, the observed interval NLL, and the baseline fitted on training data with the same token-position exposures. This endpoint tests which question has the earlier annotated textual support. [Data and matched-length controls](../semantic_tracking/same-question-results.md#human-annotated-evidence-and-observed-reading-responses)

**Authored triplets.** We compare the resolution curves for the same anchor in the shared prefix of all three versions. Dividing `anchor_unresolved` by the opening probability yields the conditional probability that the candidate remains unresolved. Resolution probability is its complement. At the same token positions, early resolution should diverge from the no-cue condition in the early window. Late resolution should diverge from the no-cue condition in the late window. We report the first separation and the sign and magnitude of the differences at both cue ends. The separation threshold is 5 percentage points, following the previous analysis. Differences in the shared prefix must fall within the numerical tolerance. The diagnostic measures localization inside the authored window and uses the same anchor across conditions. The interface and model diagnostics also retain the unconditional unresolved curve for the whole document. [Prior use of first separation](../semantic_tracking/same-question-results.md)

**One checkpoint for inference and the interface.** Token scores, visible anchors, Unicode spans, and timing windows all map to the original input. We verify the forward-pass and interface-selection call counts separately. The planned final scoring requires shared-prefix checks under truncation, suffix replacement, and right padding. We seal predictions, the fitting settings, and data receipts before linking them to local scoring annotations. Dimensions with insufficient evidence remain open for validation.
