# Comparing token-level readouts across backbones

This experiment compares frozen Qwen3.5-2B, LFM3-1.7B-Base, and Gemma 4 E2B. Each formal forecast comes from a single causal forward pass. Each backbone provides intermediate hidden states, final hidden states, and relationship summaries captured from its native global attention layers. The causal readout can use hidden states alone. Use of native attention as a relationship input is explicit. We fit each backbone's readout independently. [Pinned model snapshots](../../../research/backbone_transfer/models.json) · [Previous single-forward results](../backbone_transfer/results.md)

We compare the same texts, original-character windows, and visible prefixes. Each model retains its tokenizer. The position baseline uses exposures counted with each model's tokenizer on training data. The Frick endpoint uses a survival likelihood for first inconsistency reports at sentence boundaries. ExpMRC uses an interval likelihood for human-annotated support for a known question. The paired Frick terms compare two contexts for the same target sentence. The paired ExpMRC terms compare which question the same window supports. Each dataset defines its intervals from its original observations. [Original measurements and initial experiment](design.md)

We fit two readouts for each backbone. The point readout primarily uses a bilinear match to a single-token anchor. The span readout matches subsequent cues using a local representation that ends at the anchor and a nonlinear pairing signal. The two variants use the same update order, loss, and resource limit. We reserve a development split from the previous training set by Frick story family and ExpMRC source article family. We select weights by equally weighted development likelihood across the two endpoints and use development data to estimate the span readout's output scaling and resolution bias. The calibration preserves causality and equal scores on shared prefixes. Final test annotations stay local until predictions are sealed.

In addition to Frick human trials and human-annotated ExpMRC evidence, we evaluate the previous 12 authored early-resolution, late-resolution, and no-cue passage families and a new diagnostic with two issues in the same prefix. We measure first separation using common intervals in the original characters and check whether a cue distinguishes the two anchors. These diagnostics add no human observations. We choose the release candidate using development endpoints. Final scoring reports generalization, with the measured results and original receipts retained for each endpoint.
