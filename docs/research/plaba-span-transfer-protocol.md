# Cross-corpus diagnostics for PLABA-EVAL issue spans

This experiment checks whether IIRC-fitted and fixed phrase readouts can recover reader-identified difficult phrases within the PLABA-EVAL sentence boundaries provided by the authors. During the first round of reader scoring, the full text was reviewed. Among the free feedback, 89 items passed manual semantic verification and character-level unique alignment. After merging identical half-open character segments from the same corpus, there were 94 targets, originating from 70 sentences, 19 source families, and 12 reader connectivity groups. [PLABA-EVAL study](https://aclanthology.org/2026.readi-1.4/) · [Source and segment audit](../../research/results/plaba-explicit-span-audit.json)

The main text, reader, and sentence-level readability and comprehension self-assessments from PLABA-EVAL have been used in CogLLM development. Structured difficult responses were also utilized for sentence-level difficult readout, while open-book answering was employed for the development of data and comprehension endpoints. Some main texts are already available for interface demonstration. This time, only the original IIRC's two sets of weights and fixed projections were loaded. Readout included no PLABA fitting, threshold adjustment, or interface sentence selection. This represents a free feedback endpoint on existing PLABA material that was not used for fitting, with conclusions limited to cross-corporal diagnosis. ## A single forward and positional contrast

The remote input includes the plain text of all 40 first-round articles and their 323 author-defined sentence boundaries, spanning 8,273 Qwen tokens. Because all texts are included, selection provides no indication of which sentences received positive feedback. The manual audit code contains the identified words, so the remote job uses only the explicitly listed source-code bundle. Original feedback, local ratings, identified spans, and audit code remain local. [Transfer implementation](../../research/semantic_tracking/plaba_span_transfer.py)

Freeze Qwen3.5-2B, performing a single FP32 causal forward pass per document. Both groups share the original IIRC's one-to-eight consecutive candidate span and non-overlapping preference rules. For each sentence, retain only candidates fully contained within that sentence. The form features for both groups are computed from the prefix of the original text up to the end of the sentence. The Qwen group additionally uses causal vectors from the same prefix, specifically the candidate phrase's head and tail tokens. The author's sentence-end position must align one-to-one with the token and offset of the independent prefix tokenization. The original extraction program additionally performs sampled checks for truncation, right-padding, and post-text replacement. ## sealed snapshot and scoring

The denominator includes all 94 distinct positive spans. For each span, we recorded separately whether the top-ranked candidate or any of the top five candidates reached a character-level intersection-over-union of ≥0.5. We also checked for exact start and end offsets at both cutoffs. All four hit rates are proportions. Higher values indicate retrieval of more spans explicitly identified as difficult. The primary comparison is the top-five overlap hit rate. We used 10,000 paired resamples of the differences, keeping spans from articles connected by shared readers in the same resampling group. We report absolute rates for both methods, their differences, 95% intervals, and the maximum achievable with the candidate set. The 12 material groups limit interval precision. Sentence boundaries are supplied. The release lacks usable negative labels for unmarked text. The spans named in feedback do not specify when difficulty arose during reading or its intensity.

Decompile unlabelled packets to `inputs`, and decompile raw packets to the execution directory. L4 executes only prediction, saving predictions, the sealed snapshot list, and the extraction and causal check files. Execute the second instruction locally only after acquiring the sealed snapshot. ## Colab L4 transfer results

With 94 segments identified by human annotation as the denominator, freezing the IIRC Qwen readout, 52 segments were retrieved in the top five candidates with an intersection-over-union of 0.5. The form baseline retrieved 19 segments, a difference of +35.11 percentage points, with the reader connected group resampling yielding a 95% confidence interval of [+20.83, +50.00]. The precision boundary is 31/94 versus 9/94. When the first candidate is a complete hit, both groups equal 4/94. The results support finding multiple candidate phrases given sentence boundaries. This batch of feedback contains no negative examples or first occurrence times.
