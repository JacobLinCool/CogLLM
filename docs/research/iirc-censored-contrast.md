# IIRC ranking supervision with right censoring

Retain the same frozen Qwen3.5-2B state, the original 3,240 training paths, and 114 paired held-out paths. The 37 dual-event pairs in the held-out set were used in prior experiments. This round serves as a retrospective diagnostic, with scoring applied to this dataset. [Original dual held-out results](iirc-linked-shared-head-results.md)

Training was restricted to cases with identical body text and relative reading stop across two paths but belonging to different source families, where manually annotated support ranges did not overlap. For one path, complete evidence was observed. for the other, evidence remained right-censored at the observation endpoint. The analysis selected the earliest common reading stop at which evidence first appeared completely for the fully observed path, with the ranking term encouraging higher cumulative arrival probability for this path relative to the other. A total of 15 groups and 13 original article families were included. The later path provided negative signals only within its observed range. Negative controls utilized events or likelihoods inherent to both paths or their censoring. [Original ranges and reading stop](iirc-linked-evidence-protocol.md)

Both groups employed the same set of features with explicit anchor readout, averaging negative log-likelihood intervals of 0.012, the original L2 coefficient, and the same optimizer. The ranking group added 0.5 times the pairwise average logistic ranking loss, where the score represents the log odds of the cumulative event probability. The other group had a ranking weight of zero. The third group used previously published weights. Fitting was performed on a normalized 128-dimensional cache that had passed validation, on CPU. Records from the original training release were retrieved by key using the training path of the sealed snapshot, with paired held-out labels read only after model prediction was generated.

We primarily compare the cumulative probability rankings of the same-text two-path at earlier event reading stops, with ties broken by half-points. We also report the exchange interval minus the original interval's negative log-likelihood and the original interval's negative log-likelihood. Higher ranking accuracy is better. A positive value for (exchange interval minus original interval) indicates that assigning the readout to the manually annotated interval has a higher probability. Lower original interval negative log-likelihood is better, with 0 being optimal. We perform 10,000 paired resamples by article group, retaining only the range of 37 groups. Both groups' held-out sets have already been evaluated. results from this round are used only to check whether the 15 training control groups can improve known failure modes.
