# Adaptive joint training on public human reading data

This experiment compares fixed and adaptive source weights. Both arms start from the same CogLLM span-readout checkpoint and use the same 24 existing sources, 62 observation blocks, and token-level Frick, ExpMRC, and IIRC tasks. The two Frick readouts share one source budget. Each method uses seeds 1729 and 2718. The paired arms share initialization, data ordering, exposure, update budgets, development stopping rules, and evaluation procedures.

Each study retains its likelihood at its original exposure point and on its original scale. The verified observation likelihoods cover ordinal ratings, classification, answer choices, first reports and censoring, continuous ratings, and reported standard errors. Each block uses its effective response denominator. We allocate total weight by source and divide it evenly across that source's blocks. The token-level tasks retain the original interval or censoring terms for in-text anchors and evidence spans, with paired terms where available. Human observations supply training signals. Issue opening and resolution curves are model estimates. [Observation specification](../union_training/observation-results.md) · [Token-level protocol](../token_readout/transfer-protocol.md)

We reuse 164,220 sealed final-layer states from the same Qwen revision. Projecting them in batches into the new final-layer readout's 48-dimensional space avoids 27,167 repeat forward passes and transfer of the 2,048-dimensional matrix. For each document in the token-level tasks, we capture intermediate and final hidden states and native attention in one L4 forward pass. A trainable 48×48 linear residual feeds both the observation heads and the token-level curve. We fold it into the existing final-layer projection at export and verify score equivalence. The Qwen weights and both original projections are frozen during fitting.

The fixed arm uses a multiplier of 1. The adaptive arm tracks each endpoint's loss and gradient magnitude on the shared residual using previous microbatches. It scales progress using the endpoint's own warm-up loss distribution and then aggregates progress by source. Larger shared gradient norms lower the multiplier. Sources making slower recent progress can receive higher multipliers. Each optimizer step retains the same total weight as the fixed arm, with multipliers bounded to [0.35, 2.5]. The same backward pass supplies the gradient norms. The method draws on multitask gradient balancing and uses lagged statistics with bounded scaling. [GradNorm](https://proceedings.mlr.press/v80/chen18a.html) · [Uncertainty weighting](https://arxiv.org/abs/1705.07115) · [Gradient projection](https://papers.neurips.cc/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html)

We select models on the designated development set with equal weight per source. We remove the four historical Frick story families in the token-level test set from all observation-training annotations and route the older observations for the token-level development families to development. The complete SAP, Anglin, and Traditional Chinese MECO holdouts stay outside fitting and checkpoint selection. Their earlier results are known, so this evaluation is retrospective. We seal the fixed and adaptive forecasts before scoring effect direction, magnitude error, and predictive loss against each study's original observations. We also compare pre-update gradient norms, clipping rates, variation across seeds, backward passes, and measured runtime. The experiment uses existing public data and recruits no participants.
