# Explainable sentence-level readout versus last-layer LoRA

PLABA-EVAL provides sentence-level readability and comprehension self-assessments for biomedical abstracts alongside expert vernacular paraphrases. It builds upon the original 39 source families, 78 stimuli, 609 sentence-endings, 1,826 paired-rater ratings, and 265 source/paraphrased sentence clusters. It retains the 25 connected components formed by the intersection of article families and readers, along with five-fold cross-validation, preserving isolation of materials, readers, and paraphrase alignments. For each fold, only the training scores and paraphrase alignments from that fold are used for fitting. After collecting out-of-fold predictions, the full PLABA-EVAL dataset is used to fit two models, which are then transferred to the existing Kerwer study. ## Training and convergence

Fix Qwen3.5-2B revision, vocabulary table, and Transformers version. use English abstracts as pure text input to read causal sentence endings confirmed by independent tokenization. Both models share sentence-level readout. Each scale outputs five-class probabilities via linear softmax heads. Forward input consists of the final RMSNorm vector normalized to unit length, plus the log1p of character length and token count standardized only by training folds. Length features are divided by √2. Neither arm inputs text version, study condition, or reader identity. [Model and package registry](../../../research/backbone_transfer/models.json)

The sentence-level loss weights sentences equally and uses cross-entropy against each human five-level rating distribution. At each alignment provided by the authors, first average the expected ratings of multiple sentences within each arm. Then subtract the original from the plain-language version. During training, average this contrast across alignment positions and add the squared error against the mean human training effect for each of the two scales, weighted by 1/2 each. Apply L2 regularization to non-intercept readout parameters with a coefficient equal to the reciprocal of the number of training sentences in the fold. Fit the readout to convergence with the backbone frozen, then use that readout to initialize the LoRA arm. LoRA uses rank 4 and alpha 4 and applies only to down_proj in the final MLP. Fit both low-rank factors with the same L2 coefficient. Use two fixed seeds, 12 and 29, to initialize A. Initialize B at zero. Select the converged LoRA fit with the lower regularized training objective. Both seed selection and convergence checks use only the training objective for that fold. [Fitting program](../../../research/expository_lora/fit.py)

Use one Colab L4. Cache the gated input X to the last MLP and the state Y before final RMSNorm at all sentence ends across 102 articles in FP32. At the selected LoRA location, replace Y exactly with Y + X Aᵀ Bᵀ, then apply the original RMSNorm. The remaining computation operates independently at each position. Fit the small parameter set with full-batch FP64 L-BFGS and a strong Wolfe line search, with no repeated backbone forward passes or stored backbone backward graph. Convergence requires all three conditions on the full-batch calculation. The largest absolute gradient is ≤ 3×10⁻⁷, the gradient L2 norm is ≤ 10⁻⁵, and the relative objective change between checkpoints is ≤ 10⁻⁹. Check the frozen arm every 40 iterations up to 720. Check LoRA every 80 iterations up to 12,000 per seed. The initial LoRA run in the original coordinates stopped at 720 without converging. The rerun used a thin SVD of the training-fold X to parameterize A in its row space and scaled by each singular value relative to the median. The orthogonal complement adds only to the existing L2 penalty. The objective remains equivalent to the original loss. Convert the A gradient back to the original coordinates for acceptance. In the second run, L-BFGS with this preconditioner alone still exceeded the gradient tolerance at 12,000 iterations for fold 0's first start. The third run added joint Newton–CG, and the maximum gradient still exceeded the threshold after 20 updates for fold 0's first start. The fourth alternated exact Newton steps on block A with the original joint Newton–CG. The first two folds passed, while the first start for fold 2 still exceeded the threshold. The fifth used joint Newton–CG preconditioned with the exact A block. Four folds passed. For fold 4's first start, the gradient increased as the objective decreased. The final solver uses at least 1,200 L-BFGS iterations and switches when relative objective change is ≤ 10⁻⁹ and the gradient L2 norm in original coordinates is ≤ 3×10⁻³. If A contributes at least 90% of the full gradient L2 norm and the remaining gradient L2 norm is ≤ 10⁻⁵, prefer exact block Newton updates for A, up to 24 times. Joint Newton–CG uses the exact A block, the positive-definite readout diagonal, and the L2 curvature of B as preconditioners. It allows at most 64 steps and 256 Hessian–vector products per step. Armijo backtracking uses the same regularized objective. A joint trial point's gradient L2 norm in original coordinates must stay below the larger of 1.25 times the previous norm and 3×10⁻⁶. Allow up to eight attempts within one refinement phase, then resume L-BFGS from the accepted point. Across phases, share the budget and the original convergence tolerances. In the sixth run, the guarded procedure passed folds 4 and 3, while fold 2 missed the threshold. In the formal run on one L4, first fit fold 4 with the guarded procedure. Use the joint procedure that passed folds 0–3 as the first attempt for the other four folds and for the full data. The joint procedure starts without damping, following the original order, and allows one refinement phase per start. If a start fails to converge, refit that split within the same run using the other verified procedure. The assignment and retry use training convergence records only. Both procedures share the data, model, regularized objective, initialization, convergence criteria, and training-objective seed selection. If neither procedure passes a split, retrieve the completed sealed outputs and record the missing split. Full scoring requires all splits to pass. Seal only after all three original convergence conditions are met. Record actual iterations, objective evaluations, and the gradient and objective at every checkpoint. The LoRA criterion is evidence of a stable stationary point. [Training and forward verification](../../../research/expository_lora/run_l4.py)

Both arms re-ran predictions for all sealed snapshots using the actual model. LoRA was applied as a low-rank update directly on the final Linear layer. Each text underwent a single causal forward pass within each model to output all predicted end-of-sequence tokens, with no autoregressive decoding. The maximum absolute error between the final prediction and the cached per-token probabilities must be ≤ 5×10⁻⁵. Additionally, frozen and full-data LoRA were used to verify that truncation or replacement of the text does not alter the hidden states of the common prefix, with the maximum relative RMS difference required to be ≤ 0.001. The Colab worker received and released this L4 within a 36-minute total deadline.

## Scoring and Interpretation

PLABA-EVAL reports readability and self-assessed NLL and RPS for identical paraphrases, where lower values are preferable. It also reports the magnitude of author-aligned rewriting and its gap with human alignment. LoRA with frozen matching re-samples the fixed paraphrase prediction across 25 connected groups. Per-sentence probability scores and rewriting effect magnitude are interpreted separately.

Kerwer has 12 sets of paired summaries with/without annotations, identical in body text. Each model score averages only the end-of-text self-assessment at the same body position, equal-weighted and linearly mapped to the study's 1–8 scale, preserving the annotation's causal influence on the text. The estimated difference in end-of-text self-assessments (with vs. without annotation) is weighted by DOI for both human and the two model groups, with DOI and reader resampled simultaneously for human uncertainty. The absolute differences between each model and human are estimated, as well as the error difference (LoRA minus frozen). The existing magnitude equivalence range of ±0.5 points is maintained. Kerwer human scores remain in the local machine. neither training nor sealed snapshot predictions read these scores. This study previously served as an external diagnostic for frozen models. this round of comparison assesses whether the newly added LoRA improves this existing external endpoint. PLABA-EVAL scores are visible in full text, while Kerwer scores are end-of-text self-assessments. End-of-text outputs support comparison of these observable responses. neither study design measured per-token cognitive load curves.
